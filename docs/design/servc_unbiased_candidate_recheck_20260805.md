# 용역 모델 기각 후보 편향 제거 재검증

> **작성일**: 2026-08-05
> **최종 갱신**: 2026-08-06
> **버전**: v1.1.0
> **상태**: 운영 배선·재학습·쌍대 검증 완료, 승격 미실시
> **측정 스크립트**: `scripts/eval_servc_candidates_unbiased.py`

---

## 1. 목적

전량 재적합 결함 수정 전에 기각했던 점 추정 `num_leaves` 127·255와 기관 이력
지수감쇠 반감기 20건을 다시 평가했습니다. 과거 판정은 홀드아웃 실험과 서빙
모델의 학습 범위가 달랐으므로 새 전제에서 그대로 유지할 수 없습니다.

## 2. 평가 계약

| 항목 | 값 |
| --- | --- |
| 데이터 | `data/feature_store/dataset_Servc.parquet` |
| 불변조건 | 917,629행 × 28컬럼 |
| 학습 | 2015~2024년 765,150행 |
| 검증 | 2025년 96,141행 |
| 특징 | `src/ml/features.py`와 `src/ml/trainer.py::TRAINING_FEATURES`의 운영 34개 |
| 모델 | LightGBM Huber, 기준 리프 63 |
| 재적합 | 내부 시간순 80/20에서 트리 수 선택 후 2024년까지 전량 재적합 |
| 판정 | 같은 공고의 후보-기준 오차 쌍대 비교, 절대 t값 2 이상 |

모든 후보는 검증 연도를 학습하지 않습니다. 지수감쇠는 기관별 과거 낙찰률을
0~1 비율로 계산하고, 같은 개찰시각의 결과를 서로 보지 않도록 시각 경계를
적용했습니다. 기존 실험 스크립트의 32개 평가 특징 대신 운영과 같은 34개를
사용하고, 결측 대체도 `build_feature_frame` 단일 경로를 통과시켰습니다.

## 4. 판정

과거의 세 기각 판정은 새 학습 구조에서는 유지되지 않습니다. 세 후보 모두
기준보다 유의하게 우세하며, 현재 최선은 `num_leaves=255`와 반감기 20건
지수감쇠의 결합입니다.

2026-08-06에 학습·서빙 양쪽에 지수감쇠를 단일 정의로 배선하고 challenger를
재학습했습니다. 승격은 하지 않았으며 운영 비교 결과는 7장에 기록합니다.

## 5. 운영 배선

| 지점 | 변경 |
| --- | --- |
| `src/ml/institution_history.py` | 반감기 20건 EWM 학습 특징과 스트리밍 집계 |
| `src/ml/features.py` | 평균·표본 수·EWM을 집계 표 한 번의 조회로 생성 |
| `src/ml/trainer.py` | 용역만 EWM 1개 추가, 점 추정 리프 255 적용 |
| `src/app/models/bids.py` | 파생 집계 테이블에 nullable `ewm_rate` 추가 |
| `migrations/versions/d4e5f6a7b8c9_add_institution_ewm_rate.py` | 단일 head 마이그레이션 |

물품은 기존 34개 특징과 리프 63을 유지합니다. 분위 모델도 검증된 리프 63을
유지해 점 추정 용량 변경과 예측 구간 변경을 분리했습니다.

## 7. 운영 경로 쌍대 비교

필터 없는 2025년 용역 4,000건을 뽑아 같은 공고 순서로 두 모델을 호출했습니다.
금액 미공개 1건을 제외한 3,999건을 채점했습니다.

| 모델 | MAE | RMSE | 0.5%p 적중 | 구간 폭 중앙값 | 피복률 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 현 champion | 1.4984 | 3.9942 | 62.54% | 1.6898 | 89.57% |
| challenger | **1.4471** | **3.9564** | **64.02%** | 1.7286 | 89.40% |

| 지표 | 평균 차이 | 표준오차 | t | 판정 |
| --- | ---: | ---: | ---: | --- |
| 절대오차 | -0.05135 | 0.00684 | -7.50 | challenger 우세 |
| 제곱오차 | -0.30083 | 0.12012 | -2.50 | challenger 우세 |
| 구간 폭 | -0.07705 | 0.00824 | -9.35 | challenger 우세 |

MAE는 3.42% 개선됐습니다. 이 표본의 최소 감지 차이는 0.01369이고 관측 차이는
0.05135이므로 방향을 판정할 수 있습니다. 구간 폭 중앙값은 늘었지만 공고별 폭의
쌍대 평균은 유의하게 줄었습니다. challenger가 더 정확한 공고 비율은 53.81%입니다.

## 8. 데이터 무손실과 집계

마이그레이션 전후 원본 행 수는 공고 5,461,079행, 결과 3,405,928행으로
같았습니다. 파생 기관 집계도 38,765행을 유지했고 EWM은 38,581행(99.53%)에
채워졌습니다. 나머지는 최소 표본 미달이며 장기 평균으로 폴백합니다.
