# 용역 모델 기각 후보 편향 제거 재검증

> **작성일**: 2026-08-05
> **버전**: v1.0.0
> **상태**: 후보 재검증 완료, 운영 배선·재학습·승격 미실시
> **측정 스크립트**: `scripts/eval_servc_candidates_unbiased.py`

---

## 1. 목적

전량 재적합 결함 수정 전에 기각했던 점 추정 `num_leaves` 127·255와 기관 이력
지수감쇠 반감기 20건을 다시 평가했습니다. 과거 판정은 홀드아웃 실험과 서빙
모델의 학습 범위가 달랐으므로 새 전제에서 그대로 유지할 수 없습니다.

## 2. 평가 계약

| 항목 | 값 |
| --- | --- |
| 데이터 | `data/feature_store/dataset_Servc.parquet` |
| 불변조건 | 917,629행 × 28컬럼 |
| 학습 | 2015~2024년 765,150행 |
| 검증 | 2025년 96,141행 |
| 특징 | `src/ml/features.py`와 `src/ml/trainer.py::TRAINING_FEATURES`의 운영 34개 |
| 모델 | LightGBM Huber, 기준 리프 63 |
| 재적합 | 내부 시간순 80/20에서 트리 수 선택 후 2024년까지 전량 재적합 |
| 판정 | 같은 공고의 후보-기준 오차 쌍대 비교, 절대 t값 2 이상 |

모든 후보는 검증 연도를 학습하지 않습니다. 지수감쇠는 기관별 과거 낙찰률을
0~1 비율로 계산하고, 같은 개찰시각의 결과를 서로 보지 않도록 시각 경계를
적용했습니다. 기존 실험 스크립트의 32개 평가 특징 대신 운영과 같은 34개를
사용하고, 결측 대체도 `build_feature_frame` 단일 경로를 통과시켰습니다.

## 4. 판정

과거의 세 기각 판정은 새 학습 구조에서는 유지되지 않습니다. 세 후보 모두
기준보다 유의하게 우세하며, 현재 최선은 `num_leaves=255`와 반감기 20건
지수감쇠의 결합입니다.

이번 측정만으로 운영 모델을 바꾸지는 않습니다. 다음 단계는 학습·서빙 양쪽에
지수감쇠를 단일 정의로 배선하고 challenger를 재학습한 뒤, 서비스 모집단 전체를
대상으로 현 champion과 쌍대 비교하는 것입니다. 승격은 그 운영 검증 이후 사람이
별도로 수행합니다.
