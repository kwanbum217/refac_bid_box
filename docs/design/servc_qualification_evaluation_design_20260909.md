## 3. 규칙 판별 순서

1. `category != 'Servc'` -> 계산 차단
2. `raw_data.prearngPrceDcsnMthdNm == '비예가'` -> 계산 차단
3. `raw_data.sucsfbidMthdNm` 이 `적격심사제-관리규정외 수기심사` -> 계산 차단, 공고문 확인 요구
4. `sucsfbidMthdNm` 을 2.1 표의 식별 문자열과 매칭 -> 별표 확정
5. 매칭 실패 -> 계산 차단, 수동 규칙 선택 요구
6. 하한율은 **공고의 `sucsfbidLwltRate` 가 최우선**. 결측이면 별표 기본값을 쓰되 `기본값 사용` 경고
7. 공고값과 별표 기본값이 다르면 **공고값을 쓰고** 불일치 경고

추정가격 구간으로 별표를 추론하지 않습니다. 문자열이 정본입니다.

## 4. 계산 규칙

### 4.1 가격점수

```text
x  = ROUND_HALF_UP(입찰금액 / 예정가격, 소수점 4자리)
P  = B - k × |(기준비율 - x) × 100|
```

- 소수점 다섯째 자리에서 반올림해 넷째 자리까지 확정한 뒤 후속 연산. 세 참고 자료가 모두 같습니다.
- `Decimal` 과 `ROUND_HALF_UP` 을 씁니다. 부동소수점 금지.
- 연산 순서는 괄호 안 나눗셈이 먼저입니다.

### 4.2 A값 반영 투찰금액

공고에 A값(국민연금·건강보험 등 합산액)이 있으면 하한 투찰금액은 다음과 같습니다.

```text
최저 투찰금액 = (예정가격 - A값) × 하한율 + A값
```

A값이 없으면 `예정가격 × 하한율` 입니다. **이 산식을 빠뜨리면 하한율 미달로 즉시 탈락**하며
인포21C 자료가 실무 최다 사고로 지목한 항목입니다.

### 4.3 최저 가능 투찰률 역산

사용자 정량점수 `Q` 로 통과점수 `T` 를 맞추는 최저 투찰률입니다.

```text
필요 가격점수 P_req = T - Q
최저 투찰률 = 기준비율 - (B - P_req) / (100 × k)
```

결과가 공고 하한율보다 낮으면 **하한율이 실질 하한**입니다. 둘 중 큰 값을 표시합니다.

### 4.4 복수예가 시나리오

기초금액과 `totPrdprcNum`(통상 15), `drwtPrdprcNum`(통상 4)으로 구성합니다.

| 시나리오 | 예정가격 |
| --- | --- |
| 하단 | 기초금액 × (1 - 범위) |
| 기준 | 기초금액 |
| 상단 | 기초금액 × (1 + 범위) |

범위는 국가계약 ±2%, 지방계약 ±3% 를 기본값으로 하되 공고에 명시가 있으면 그것이 우선합니다.
**예정가격을 예측했다고 표현하지 않습니다.**

### 4.5 종합점수

```text
Q = 수행능력(실적 + 경영상태) + 근로조건 이행계획 + 신인도 가감점
총점 = Q + P
적격 = 결격사유 없음 AND 입찰금액 <= 예정가격 AND 총점 >= T
```

근로조건 이행계획은 단순노무용역 필수 항목이며 **0점이면 사실상 통과 불가**입니다.
사용자 입력 항목으로 노출하고 미충족 시 그 사실을 경고합니다.
