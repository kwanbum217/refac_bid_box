> **대상**: Servc (용역) 낙찰률 예측 모델 `servc_institution_v1`
> **측정 스크립트**: [`scripts/eval_servc_huber_alpha.py`](../../scripts/eval_servc_huber_alpha.py),

## 1. 왜 이 축을 봤는가

[`servc_hyperparam_search_20260804.md`](servc_hyperparam_search_20260804.md) 의
좌표 하강 17회는 `num_leaves`, `min_child_samples`, `learning_rate`,
`n_estimators`, `colsample_bytree`, `subsample`, `reg_lambda` 를 다뤘습니다.
**손실함수는 탐색 축에 없었습니다.** `trainer._train_lightgbm` 은
`objective="huber", alpha=1.0` 으로 고정돼 있었고 한 번도 재본 적이 없습니다.

이 축이 중요한 이유가 있습니다. Huber 는 잔차가 `alpha` 보다 작으면 L2(평균
겨냥), 크면 L1(중앙값 겨냥)으로 동작합니다. 현행 `alpha` 는 1.0 인데 운영
실측에서 오차가 0.5%p 이내인 건이 64%, 1%p 이내가 75% 입니다. **핵심 지표가
걸린 구간 전체가 평균 겨냥으로 학습되고 있었습니다.**

2026-08-06~07 진단에서 세 번 만난 "모델이 조건부 중앙값을 겨냥해 평균 편향이
남는다" 는 현상도 이 손잡이가 정하는 동작입니다. 현상을 세 번 관찰하고도
손잡이 자체는 돌려보지 않았습니다.

## 2. 설계

| 항목 | 설정 |
| --- | --- |
| 학습 구간 | 2025년까지 861,291행 |
| 평가 구간 | 2026년 56,338행 out-of-sample |
| 기준선 | `huber alpha=1.0` (현행 서빙 설정) |
| Huber 후보 | alpha 0.2 / 0.5 / 2.0 / 5.0 |
| 대조 | `quantile alpha=0.5` (MAE 직접 최적화) |
| 고정 | 손실함수 외 하이퍼파라미터와 학습 상한 전부 동일 |
| 판정 | 같은 공고의 절대오차 쌍대 차이 + 최소 감지 차이 |

쌍대 비교는 7개 모집단에서 냅니다. `alpha` 를 낮추면 큰 오차에 관대해지므로
산포가 큰 셀에서 손해, 작은 셀에서 이득이 나는 **재분배**가 예상됐기 때문입니다.
전체만 보면 상쇄돼 판별 불가로 끝나고 이유를 모르게 됩니다.

| --- | --- |

| 악화 집단 | 없음 (6 우세 / 1 판별 불가 / 0 악화) |

**RMSE 가 나빠집니다** (2.7454 -> 2.7834, +1.4%). L1 최적화가 큰 오차를 덜

3%p 이내 적중도 86.12% 에서 86.06% 로 미세하게 낮아집니다.

## 5. Huber 와 quantile 은 이어지지 않습니다

`alpha` 를 0 으로 줄이면 Huber 가 L1(=quantile 0.5)에 수렴할 것처럼 보이지만
**실측은 반대입니다.**

| 후보 | MAE |
| --- | ---: |
| huber a=0.5 | 1.3477 |
| huber a=0.2 | **1.7971** |
| quantile a=0.5 | 1.3312 |

`alpha` 0.2 에서 MAE 가 급격히 나빠집니다(기준선 대비 32% 악화). LightGBM 의
Huber 구현에서 잔차가 `alpha` 를 넘으면 gradient 가 `±alpha` 로 고정되는데,
`alpha` 가 작으면 대부분의 표본에서 gradient 크기가 같아져 **학습 신호가
평평해집니다.** quantile 목적함수는 L1 을 직접 최적화하므로 이 문제가 없습니다.

**두 목적함수는 연속적으로 이어지지 않습니다.** L1 을 원하면 `alpha` 를 줄이지
말고 objective 를 바꾸십시오.

## 6. 승격 전 남은 절차

1. **운영 경로 쌍대 검정.** 후보 모델을 서빙 루트에 임시 ID 로 올리고
   `compare_servc_models_paired.py` 로 champion 과 겨룹니다. 홀드아웃 우세가
   운영에서 뒤집힌 전례가 네 번 있습니다.
2. **예측 구간 확인.** `_conformal_scale` 은 분위 모델의 자체 중심
   `(lo+hi)/2` 를 쓰므로 점 추정 목적함수 변경이 구간 보정에 **영향을 주지
   않습니다.** 코드로 확인했으나 승격 후 실측으로 재확인하십시오.
3. **모델 선택 경로 확인.** `train_and_register` 는 LightGBM/CatBoost/Ridge 중
   MAPE 가 가장 낮은 것을 고릅니다. 목적함수를 바꾸면 이 선택이 달라질 수
   있으므로 후보 선택 결과를 함께 봐야 합니다.
4. 승격은 예행 후 명시적 `--apply`, 사후 기본 서빙 경로 재측정.

구현 시 `trainer._train_lightgbm` 의 `params` 를 바꾸게 되는데, 이 함수는
**물품(Thng)도 함께 씁니다.** 용역에서만 검증된 변경이므로
`CATEGORY_HYPERPARAMS` 처럼 카테고리별로 분기해야 합니다. 물품에 그대로
적용하면 검증되지 않은 변경이 됩니다.

### 8.4 집단별 회귀 검정

전체 판정만으로는 특정 집단의 회귀를 놓칩니다. `huber alpha=0.5` 가 정확히

판정은 우세 집단의 **개수가 아니라 비중**으로 하고, 다중 검정이므로 t 임계값을
본페로니 보정으로 2.0 에서 2.64 로 올립니다.

### 8.5 하한율 결측 집단은 약하게 악화합니다

**이것을 숨기지 않고 기록합니다.** 두 해 모두 부호가 악화 방향이며 2025년에는
유의했습니다. 연도 특수 현상이 아니라 구조적 신호로 봅니다.

원인은 이 집단의 분포입니다.

| 집단 | 낙찰률 IQR | 표준편차 |
| --- | ---: | ---: |
| 하한율 보유 | 0.705 | 4.026 |
| 하한율 결측 | **9.682** | 6.879 |

사분위 범위가 **14배** 입니다. 하한율이 존재하지 않는 제도(수의시담·규격가격
동시입찰)라 낙찰률이 제도적으로 고정되지 않습니다. 이렇게 넓은 분포에서
중앙값만 겨냥하는 quantile 은 꼬리를 사실상 포기하는 반면, huber(alpha=1.0)는
잔차 1.0 이내를 L2 로 다뤄 더 안정적입니다.

악화는 소수 건에 몰려 있습니다. 2025년 결측 2,646건 중 **상위 50건(1.9%)을
빼면 평균 차이가 +0.0400 에서 +0.0083 으로 줄어듭니다.** 이 건들은 90분위
6.27%p, 99분위 18.5%p 로 예측이 이미 실용성을 잃은 구간입니다.
