### 3.2 그러나 평균에는 계단이 없습니다

적격심사 명시 건만 추린 결과입니다.

원인은 침투율입니다. 시행 후 적격심사 표본 1,908건 중 신 제도 값은 약 326건(17%)에 불과합니다. **시행일이 "최초 입찰공고분부터"이므로 기존 사업의 재공고·차수 변경 건은 구 기준을 유지**하며, 시행 후 10주차인 현재는 전환 중입니다.

### 3.3 설계서 수정

`g2b_procurement_institution_analysis.md` 6.2 절은 이 변경을 "결정론적 레짐 전환"으로 규정하고 6개 조치를 전부 **필수**로 지정했습니다. **과대평가였습니다.** 정정합니다.

| 조치 | 기존 | 수정 |
| --- | --- | --- |
| 레짐 플래그 특징 | 필수 | **유지 (필수).** 비용이 없고 신 제도 값이 실재함 |
| 하한율 정규화 (하한율 - 레짐 기준치) | 필수 | **철회.** 침투율 17% 에서 정규화는 오히려 왜곡. 하한율 원값 사용 |
| 절단 기준 갱신 (행별 실제 하한율) | 필수 | 유지 (필수). 원래 행별 값이므로 자동 충족 |
| 홀드아웃을 시행일 이후로 | 필수 | **하향.** 시행 후 낙찰률 보유 표본이 11,833건뿐. 별도 보고 축으로만 유지 |
| PSI 알람 억제 | 필수 | **하향.** 계단이 없으므로 급등하지 않음. 통상 임계 유지 |
| 표본 가중 | 조건부 | **보류.** 침투율이 50% 를 넘을 때 재검토 |

**제도 변경 감지 모니터링(6.3 절)은 유지합니다.** 신 제도 값 3종이 시행일에 정확히 출현한 것은 "최빈값 집합 변화" 신호가 실제로 작동함을 보여줍니다. 평균 이동보다 값 집합 변화가 훨씬 빠른 신호였습니다.

1% 미만이지만 **비율 특징(`base_ratio`, 낙찰률)의 평균을 완전히 망가뜨립니다.** V3-a 질의에서 `sucsf_bid_amt/presmpt_prce` 평균이 185만% 로 나온 원인입니다.

낙찰률 자체도 오염돼 있습니다. 최댓값 999.999, 최솟값 0 이 존재합니다.

**정제 규칙을 `src/ml/dataset.py` 에 넣습니다.**

| 필드 | 규칙 |
| --- | --- |
| `presmpt_prce` | 10만원 미만 또는 1조 초과 행 제외 |
| `sucsf_bid_rate` | 30~130 범위 밖 제외 |
| 결측 | `presmpt_prce` NULL/0 행 제외 |
