# 용역 낙찰하한율 가용성 재검증

> **작성일**: 2026-08-04
> **버전**: v1.0.0
> **상태**: 수집 누락 가설 기각
> **측정 스크립트**: [`scripts/audit_servc_lwlt_coverage.py`](../../scripts/audit_servc_lwlt_coverage.py)

---

## 1. 결론

미개찰 용역 공고의 `sucsfbidLwltRate` 결측은 수집 누락이 아니라 대부분
**낙찰하한율을 적용하지 않는 낙찰 방식**입니다. 2026년 7월 이후 미개찰 공고
10,434건을 낙찰 방식별로 분리한 결과, 하한율 명시 방식은 3,587건 모두 값을
보유했고 실제 누락은 0건이었습니다.

따라서 결측값을 역산하거나 다른 값으로 대치하면 존재하지 않는 제도 제약을
모델에 주입합니다. 하한율 결측 구간의 넓은 예측 구간은 데이터 수집 결함이 아니라
협상계약·규격가격동시입찰·수의시담의 결과 산포를 반영한 것입니다.

## 2. 데이터 검증

### 2.1 학습 데이터 무결성

| 항목 | 실측 |
| --- | ---: |
| `dataset_Servc.parquet` 행 | 917,629 |
| 컬럼 | 28 |
| 하한율 보유 | 712,391 |
| 하한율 결측 | 205,238 (22.37%) |

데이터셋은 인수인계 기준인 917,629행 x 28컬럼과 일치합니다.

### 2.2 미개찰 공고

측정 범위는 2026-07-01 이후이며, 이미 낙찰 결과가 연결된 공고는 제외했습니다.

| 구분 | 공고 수 | 하한율 보유 | 실제 누락 |
| --- | ---: | ---: | ---: |
| 전체 | 10,434 | 3,642 | 6,792 |
| 하한율 명시 방식 | 3,587 | 3,587 | **0** |
| 그 외 방식 | 6,847 | 55 | 6,792 |

하한율 명시 방식은 `적격심사`, `낙찰하한율`, `소액수의견적` 표식이 있는
낙찰방법으로 판정했습니다. 이 방식에서는 실제 누락이 없습니다. 그 외 방식에
하한율 55건이 존재하지만 같은 방법 안에서도 1 또는 89.745처럼 의미가 달라
방법명만으로 결측을 보간할 수 없습니다.

| 결측 상위 낙찰방법 | 건수 |
| --- | ---: |
| 협상에 의한 낙찰자 결정 | 4,326 |
| 협상에 의한 낙찰자 결정(SW사업) | 984 |
| 규격가격동시입찰 | 728 |
| 수의시담 | 290 |
| 최저가낙찰제 | 134 |

## 3. 대체 API 검증

공공데이터포털의 조달청 나라장터 입찰공고정보서비스가 제공하는 별도
오퍼레이션도 2026-08-01~2026-08-04 응답으로 확인했습니다.

| 오퍼레이션 | 표본 | `sucsfbidLwltRate` | 판정 |
| --- | ---: | ---: | --- |
| 용역 공고 목록 | 첫 100건 | 29건 | 현행 수집 원천 |
| 용역 기초금액 | 첫 100건 | 0건 | 응답 스키마에 필드 없음 |
| 용역 변경이력 | 전체 10건 | 0건 | 변경 항목만 제공 |

용역 기초금액 및 변경이력 오퍼레이션을 추가해도 하한율 가용성은 늘지 않습니다.

## 4. 판정

| 접근 | 판정 | 근거 |
| --- | --- | --- |
| 별도 기초금액 API 병합 | 기각 | 하한율 필드 자체가 없음 |
| 변경이력 API 병합 | 기각 | 변경 전후 값만 제공 |
| 배점표 역산 | 기각 유지 | 비적용 방식에 허위 하한율 생성 |
| 공고명 기반 추정 | 기각 유지 | 기존 중·소분류와 중복 |
| 결측을 비적용 상태로 해석 | 채택 | 하한율 명시 방식 실제 누락 0건 |

하한율 결측 축소는 더 이상 유효한 최적화 과제가 아닙니다. 예측 구간을 줄이려면
하한율 비적용 방식의 결과 산포를 설명하는 새로운 사전 가용 신호가 필요합니다.
기존에 기각한 세그먼트별 보정 배율, 참가자 수 이력, 공고명 텍스트는 재시도하지
않습니다.
