# 용역 낙찰하한율 가용성 재검증

> **작성일**: 2026-08-04
> **정정일**: 2026-08-05
> **버전**: v2.0.0
> **상태**: 미개찰 표본 한정으로는 비적용, 학습 모집단에서는 76.8% 설명 불가
> **측정 스크립트**: [`scripts/audit_servc_lwlt_coverage.py`](../../scripts/audit_servc_lwlt_coverage.py)

---

## 1. 결론

**초판(v1.0.0)의 기각 판정을 철회합니다.** 미개찰 공고 표본에서는 결측이 전부
하한율 비적용 방식으로 설명됐으나, 그 결론을 **학습 모집단으로 일반화한 것이
오류**였습니다. 두 모집단은 낙찰방법 표기 관행이 다릅니다.

학습 데이터 917,629행에 같은 판정을 적용하면 이렇습니다.

| 구분 | 결측 | 비중 |
| --- | ---: | ---: |
| 전체 결측 | 205,238 | 100% |
| 방법명으로 설명됨 (수의시담·협상계약 등 결측률 0% 또는 100%) | 47,591 | 23.2% |
| **방법명으로 설명되지 않음** | **157,647** | **76.8%** |

설명되지 않는 결측은 거의 전부 `공고서참조` 한 방법에 있습니다. 이 방법은
765,620건 중 20.6%만 결측이며, **같은 방법명 안에서 79.4%는 하한율을 보유합니다.**
제도상 비적용이라면 그럴 수 없습니다. 값을 공고 문서로 넘긴 표기 문제입니다.

결정적인 두 가지입니다.

| 근거 | 내용 |
| --- | --- |
| 산포 차이 | `공고서참조` 결측 건의 낙찰률은 평균 94.29% / 표준편차 6.35, 보유 건은 88.71% / 2.77 로 **산포가 2.3배**입니다. "결측 구간 폭이 보유 구간의 7배" 의 원인이 여기입니다 |
| 연도 변동 | 같은 방법의 결측률이 2021년 14.7% 에서 2024년 26.3% 까지 움직입니다. 제도 속성이라면 이렇게 출렁이지 않습니다 |

유지되는 판단은 하나입니다. **결측값을 역산하거나 대치하지는 않습니다.** 결측
안에 비적용(23.2%)과 미표기(76.8%)가 섞여 있어, 일괄 보간은 비적용 건에 존재하지
않는 제약을 주입합니다. 보강은 값을 만들어 내는 방식이 아니라 **원 공고에서 실제
값을 가져오는 방식**이어야 합니다.

## 2. 데이터 검증

### 2.1 학습 데이터 무결성

| 항목 | 실측 |
| --- | ---: |
| `dataset_Servc.parquet` 행 | 917,629 |
| 컬럼 | 28 |
| 하한율 보유 | 712,391 |
| 하한율 결측 | 205,238 (22.37%) |

데이터셋은 인수인계 기준인 917,629행 x 28컬럼과 일치합니다.

### 2.2 미개찰 공고

측정 범위는 2026-07-01 이후이며, 이미 낙찰 결과가 연결된 공고는 제외했습니다.

| 구분 | 공고 수 | 하한율 보유 | 실제 누락 |
| --- | ---: | ---: | ---: |
| 전체 | 10,434 | 3,642 | 6,792 |
| 하한율 명시 방식 | 3,587 | 3,587 | **0** |
| 그 외 방식 | 6,847 | 55 | 6,792 |

하한율 명시 방식은 `적격심사`, `낙찰하한율`, `소액수의견적` 표식이 있는
낙찰방법으로 판정했습니다. 이 방식에서는 실제 누락이 없습니다. 그 외 방식에
하한율 55건이 존재하지만 같은 방법 안에서도 1 또는 89.745처럼 의미가 달라
방법명만으로 결측을 보간할 수 없습니다.

| 결측 상위 낙찰방법 | 건수 |
| --- | ---: |
| 협상에 의한 낙찰자 결정 | 4,326 |
| 협상에 의한 낙찰자 결정(SW사업) | 984 |
| 규격가격동시입찰 | 728 |
| 수의시담 | 290 |
| 최저가낙찰제 | 134 |

**이 표본에는 `공고서참조` 가 등장하지 않습니다.** 최근 공고는 낙찰방법이 코드로
채워지는 반면, 학습 데이터의 상당수는 방법을 공고 문서로 넘겼습니다. 초판이
미개찰 표본만 보고 결론을 낸 것이 오류였던 지점이 바로 여기입니다.

### 2.3 학습 모집단 (정정의 근거)

`--skip-db --parquet` 로 재현합니다.

| 낙찰방법 | 공고 수 | 결측 | 결측률 |
| --- | ---: | ---: | ---: |
| `공고서참조` | 765,620 | 157,579 | **20.6%** |
| 수의시담·협상계약·규격가격동시 등 | 48,552 | 47,654 | 100% |
| 하한율 명시 방식 | 103,457 | 5 | 0.0% |

가운데 그룹과 아래 그룹은 방법명이 결측을 완전히 결정하므로 제도 속성입니다.
`공고서참조` 만 0% 와 100% 사이에 있고, 여기에 전체 결측의 **76.8%** 가 몰려
있습니다.

| `공고서참조` 내부 | 건수 | 낙찰률 평균 | 표준편차 |
| --- | ---: | ---: | ---: |
| 하한율 보유 | 608,041 | 88.71 | 2.77 |
| 하한율 결측 | 157,579 | 94.29 | **6.35** |

## 3. 대체 API 검증

공공데이터포털의 조달청 나라장터 입찰공고정보서비스가 제공하는 별도
오퍼레이션도 2026-08-01~2026-08-04 응답으로 확인했습니다.

| 오퍼레이션 | 표본 | `sucsfbidLwltRate` | 판정 |
| --- | ---: | ---: | --- |
| 용역 공고 목록 | 첫 100건 | 29건 | 현행 수집 원천 |
| 용역 기초금액 | 첫 100건 | 0건 | 응답 스키마에 필드 없음 |
| 용역 변경이력 | 전체 10건 | 0건 | 변경 항목만 제공 |

용역 기초금액 및 변경이력 오퍼레이션을 추가해도 하한율 가용성은 늘지 않습니다.

## 4. 판정

| 접근 | 판정 | 근거 |
| --- | --- | --- |
| 별도 기초금액 API 병합 | 기각 | 하한율 필드 자체가 없음 |
| 변경이력 API 병합 | 기각 | 변경 전후 값만 제공 |
| 배점표 역산 | 기각 유지 | 결측에 비적용이 23.2% 섞여 허위 하한율 생성 |
| 공고명 기반 추정 | 기각 유지 | 기존 중·소분류와 중복 |
| 결측 전체를 비적용으로 해석 | **기각** | 76.8% 가 방법명으로 설명되지 않음 (2.3 절) |
| 공고 원문에서 하한율 확보 | **미검토. 유효한 경로** | `공고서참조` 는 값이 없는 것이 아니라 문서에 있음 |

**하한율 결측 축소는 여전히 유효한 과제입니다.** 다만 대상이 바뀝니다. 협상계약과
수의시담은 실제로 하한율이 없으므로 건드리지 않고, `공고서참조` 157,579건이
표적입니다. 이 그룹은 같은 방법 안에서 79.4%가 값을 갖고 있으므로 결측분도 원
공고에는 값이 있을 가능성이 높습니다.

확보 경로는 공고 첨부·본문 조회 계열 오퍼레이션이며, 3장에서 확인한 기초금액·
변경이력과는 다른 원천입니다. **아직 조사하지 않았습니다.**

기존에 기각한 세그먼트별 보정 배율, 참가자 수 이력, 공고명 텍스트는 재시도하지
않습니다.
