# CatBoost 목적함수를 맞춰도 앙상블 여지는 없습니다

> **작성일**: 2026-08-09
> **버전**: v1.0.0
> **상태**: 기각. 앙상블 축 종결
> **대상**: Servc (용역) 낙찰률 예측 모델 `servc_institution_v1`
> **선행 문서**: [`2026-08-07_servc_next_axis_handoff.md`](../handoff/2026-08-07_servc_next_axis_handoff.md) 3장
> **측정 스크립트**: [`scripts/eval_servc_ensemble_headroom.py`](../../scripts/eval_servc_ensemble_headroom.py)

## 1. 물음

2026-08-07 에 LightGBM + CatBoost 반반 앙상블을 기각했습니다. 잔차 상관이
0.9389 로 한계(0.95) 아래인데도 반반 평균이 LightGBM 대비 MAE +0.0811 나빴고,
원인을 **목적함수 불일치**로 읽었습니다. LightGBM 은 `quantile(0.5)` 로 조건부
중앙값을, CatBoost 는 기본 RMSE 로 조건부 평균을 겨냥하므로 평균을 내면
중앙값 겨냥이 희석된다는 설명입니다.

그때 남긴 미측정 갈래가 이것입니다.

> CatBoost 에 L1 계열 목적함수를 주면 희석이 사라지는가.

**희석은 실제로 줄었습니다. 그런데 여지는 여전히 없습니다.** 이 축을 닫습니다.

## 2. 측정

`eval_servc_ensemble_headroom.py` 에 `--catboost-loss` 를 추가해 CatBoost
`loss_function` 만 `MAE` 로 바꿨습니다. 나머지는 2026-08-07 과 동일합니다.
2024년까지 학습(765,150행), 2025년 검증(96,141행), 특징 32개, 운영 카테고리
설정, 조기 종료는 학습 구간 내부 80/20.

## 3. 목적함수 정렬은 실제로 효과가 있었습니다

| 모델 | MAE | RMSE | R2 | 0.5%p 적중 |
| --- | ---: | ---: | ---: | ---: |
| LightGBM `quantile(0.5)` | **1.3593** | 2.7777 | 0.6656 | 59.93% |
| CatBoost RMSE (2026-08-07) | 1.5835 | 2.7825 | 0.6644 | 44.34% |
| CatBoost MAE | 1.4809 | 3.0137 | 0.6063 | **59.73%** |

**CatBoost 단독이 MAE 1.5835 -> 1.4809 로, 0.5%p 적중이 44.34% -> 59.73% 로
좋아졌습니다.** 적중률은 LightGBM 과 거의 같은 자리까지 왔습니다. 목적함수
불일치라는 진단 자체는 맞았습니다.

반반 평균의 손해도 절반으로 줄었습니다.

| CatBoost 목적함수 | 반반 평균 MAE | 단일 최고 대비 | 잔차 상관 |
| --- | ---: | ---: | ---: |
| RMSE | 1.4404 | -0.0811 | 0.9389 |
| MAE | 1.3990 | **-0.0397** | 0.9322 |

**상관은 오르지 않았습니다.** 목적함수를 맞추면 두 모델이 더 닮아 상관이
오를 것으로 봤는데 0.9389 -> 0.9322 로 오히려 미세하게 내렸습니다. 그
예상은 틀렸습니다. 다만 결론에는 영향이 없습니다.

## 4. 가중치를 어떻게 잡아도 손해입니다

"반반이 아니라 가중치를 최적화하면 다르지 않은가" 라는 반론을 닫기 위해
0.00 부터 1.00 까지 0.05 간격으로 훑었습니다. **가중치를 검증 연도에서 고르는
것은 오라클입니다.** 실제로는 미리 알 수 없으므로 이 값은 상한입니다.

| LightGBM 가중 | 0.00 | 0.25 | 0.50 | 0.75 | 0.90 | 0.95 | 1.00 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| MAE | 1.4809 | 1.4351 | 1.3990 | 1.3734 | 1.3633 | 1.3609 | **1.3593** |

**MAE 가 가중치에 대해 단조 감소하며 최적이 LightGBM 100% 입니다.** 오라클
상한조차 단일 최고 대비 **+0.0000** 입니다.

CatBoost 를 **어떤 비율로 섞어도 손해**라는 뜻입니다. 앙상블이 이득을 내려면
섞는 쪽이 독립적인 오차를 가져와야 하는데, 상관 0.9322 에서 독립 성분이 작고
그 모델이 MAE 에서 0.12 열등합니다. 열등한 모델을 거의 같은 방향으로 틀리는데
섞으면 열등함만 옮겨옵니다.

R2 와 RMSE 도 이번에는 반전이 없습니다. CatBoost MAE 는 RMSE 3.0137, R2
0.6063 으로 두 지표에서도 LightGBM 에 집니다. 목적함수를 L1 으로 바꾸면서
제곱오차 우위를 잃었기 때문입니다. **2026-08-07 에 반반 평균이 R2 에서
이겼던 것은 CatBoost 가 RMSE 를 겨냥했기 때문이지 앙상블 덕이 아니었습니다.**
