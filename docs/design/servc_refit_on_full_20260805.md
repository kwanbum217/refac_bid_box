# 서빙 모델이 최신 20%를 학습하지 않던 결함

> **작성일**: 2026-08-05
> **버전**: v1.0.0
> **상태**: 수정·승격 완료. 편향 없는 확인에서 MAE -7.12%
> **측정 스크립트**: [`scripts/diagnose_serving_vs_holdout_model.py`](../../scripts/diagnose_serving_vs_holdout_model.py)

---

## 1. 무엇을 쫓고 있었나

같은 조건(2025년, 하한율 보유)인데 두 측정이 30% 차이났습니다.

| 측정 | MAE |
| --- | ---: |
| 홀드아웃 실험 | 0.7616 |
| 운영 API 경로 | 0.9590 |

운영 쪽이 2025년을 학습에 **포함**하고도 나쁘다는 점이 이상했습니다. 후보는
둘이었습니다.

| 후보 | 내용 |
| --- | --- |
| 경로 | API 가 DB 에서 특징을 재구성하면서 학습 프레임과 달라진다 |
| 모델 | 서빙 아티팩트 자체가 이 구간에서 나쁘다 |

---

## 2. 가르는 실험

**서빙 모델을 parquet 프레임에 직접 적용**하면 갈립니다. 모델을 고정한 채
경로만 바꾸는 것이기 때문입니다.

| 조합 | MAE | 비고 |
| --- | ---: | --- |
| 홀드아웃 모델 + parquet | 0.7616 | 기측정 |
| **서빙 모델 + parquet** | **0.9500** | 이번 측정 |
| 서빙 모델 + API 경로 | 0.9590 | 기측정 |

**경로 차이는 0.009(1%)뿐이고 모델 차이가 0.19(25%)입니다.**

`weekday_sin` / `weekday_cos` 두 특징은 홀드아웃 실험 프레임(`build_frame`)이
만들지 않아 `features.py` 와 같은 정의로 채웠습니다. 그러지 않으면 34개 모델을
32개 프레임에 적용하게 되어 비교가 성립하지 않습니다.

---

## 3. 원인

`src/ml/trainer.py` 가 시간순 80/20 으로 나눈 뒤 **앞 80% 로 학습한 모델을
그대로 저장**하고 있었습니다.

```python
model = model_fn(X_train, y_train, X_valid, y_valid, params)
...
joblib.dump(best_model, model_file)   # 앞 80% 로만 배운 모델이 서빙됨
```

시계열 분할이라 버려지는 20% 는 **가장 최신 구간**입니다. 917,629행 기준으로
183,526행이며, 2024년 후반과 2025년 전체가 여기 들어갑니다.

즉 **서빙 모델은 최근 약 1.5년을 영영 배우지 못한 상태**였습니다. 홀드아웃
실험 모델은 2015~2024 전량(765,150행)을 학습해 2024년 후반을 포함하므로 2025년
예측이 낫습니다.

분위 모델(`_train_quantile_models`)도 같은 `X_train` 을 받고 있었습니다. 점
추정과 구간 양쪽이 최신 데이터를 버렸습니다.

## 4. 수정

선택이 끝난 뒤 전량으로 재적합합니다.

```python
best_model = _refit_on_full(model_fns[model_type], model_type, best_model, X, y, params)
```

### 4.1 트리 수를 고정하는 이유

그냥 재적합하면 안 됩니다. 검증 구간이 학습에 포함되므로 조기 종료
(`early_stopping(10)`)가 판단 근거를 잃고, 설정된 `n_estimators` 를 끝까지 써
과적합합니다.

그래서 **선택 단계에서 조기 종료가 고른 트리 수를 고정**해 다시 학습합니다.
LightGBM 은 `best_iteration_`, CatBoost 는 `get_best_iteration()` 입니다.
Ridge 처럼 반복 수 개념이 없는 모델은 그대로 재적합합니다.

### 4.2 지표와 가중치의 학습 범위가 다릅니다

`metrics` 는 재적합 **전** 홀드아웃 값을 유지합니다. 전량 학습본의 지표를
내려면 검증 구간이 학습에 포함돼 무의미해지기 때문입니다.

따라서 저장 모델과 지표의 학습 범위가 다릅니다. 이 사실을 `refit_on_full` 로
메타데이터에 남기고, 승격 판정은 계속 홀드아웃 지표로 합니다.

`build_serving_metadata` 도 이 키를 옮기도록 고쳤습니다. 서빙본에서만 보면
`source_metrics` 가 어느 모델의 것인지 알 수 없기 때문입니다.

**홀드아웃 지표는 이 수정으로 바뀌지 않습니다.** 지표를 내는 모델은 여전히 앞
80% 로 학습한 것이므로, 재학습 결과가 R2 0.6824 로 이전과 같습니다. 이 개선은
홀드아웃으로 볼 수 없고 운영 경로에서만 확인됩니다.

## 5. 실측

### 5.1 운영 경로 (낙관 편향 포함)

재학습·승격 후 서비스 모집단 3,999건 쌍대 비교입니다.

| 지표 | 구본(80%) | 신규(전량) | 변화 |
| --- | ---: | ---: | --- |
| MAE | 1.5989 | **1.4984** | **-6.3%** |
| RMSE | 4.0543 | **3.9942** | -1.5% |
| 0.5%p 적중 | 59.11% | **62.54%** | +3.43%p |
| **구간 폭** | 2.0737 | **1.6898** | **-18.5%** |
| 피복률 | 88.20% | 89.57% | 명목 90% 에 근접 |

| 지표 | 평균 차이 | t | 판정 |
| --- | ---: | ---: | --- |
| 절대오차 | -0.10043 | **-10.59** | challenger 우세 |
| 제곱오차 | -0.48412 | -3.36 | challenger 우세 |
| 구간 폭 | -0.12664 | -8.46 | challenger 우세 |

**다만 이 측정에는 낙관 편향이 있습니다.** 신규 모델은 2025년을 학습에
포함하는데 평가도 2025년으로 합니다.

### 5.2 편향 없는 확인

두 방식을 **같은 학습 상한**으로 맞춰 다시 잽니다. 2024년까지만 학습하고
2025년으로 평가하면 차이는 오직 "학습 구간을 다 쓰는가" 에서만 옵니다.

측정: [`scripts/eval_servc_refit_unbiased.py`](../../scripts/eval_servc_refit_unbiased.py)

| 방식 | 학습 행 | MAE | RMSE | R2 | 0.5%p 적중 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 구 (앞 80%) | 612,120 | 1.4003 | 2.7485 | 0.6726 | 58.51% |
| **신 (전량 재적합)** | 765,150 | **1.3006** | **2.6658** | **0.6920** | **60.34%** |

| 지표 | 평균 차이 | t | 판정 |
| --- | ---: | ---: | --- |
| 절대오차 | -0.0997 | **-52.27** | 전량 우세 |
| 제곱오차 | -0.4478 | -29.30 | 전량 우세 |

**MAE -7.12%.** 편향을 없앤 쪽이 오히려 이득이 큽니다. 앞 절의 개선이 낙관
편향에서 온 것이 아님을 확인합니다.

조기 종료가 고른 트리 수는 600, 즉 `n_estimators` 상한이었습니다. 이 데이터에서
조기 종료가 걸리지 않았다는 뜻이며, 두 방식의 차이는 순수하게 학습 행 수
(612,120 대 765,150)에서 옵니다.

## 6. 이 결함이 설명하는 것

2026-08-04~05 에 특징·파라미터 개선이 **홀드아웃에서 좋아지고 운영에서
재현되지 않는 일이 세 번** 있었습니다.

| 시도 | 홀드아웃 | 운영 |
| --- | --- | --- |
| 리프 255 | MAE -1.4% | 판별 불가 |
| 리프 127 | MAE -1.0% | 제곱오차 악화 |
| 지수감쇠 기관 이력 | MAE -1.79% | 악화 (t=5.39) |

홀드아웃 실험은 2024년까지 전량으로 학습하고, 운영은 2024년 중반까지만 학습한
모델을 씁니다. **두 모델의 학습 범위가 달랐으므로 한쪽의 개선이 다른 쪽에서
재현될 이유가 없었습니다.**

이 수정 이후에는 두 경로의 학습 범위가 맞으므로, 앞으로의 홀드아웃 개선은
운영에서 재현될 여지가 생깁니다.

**기각한 세 건은 다시 볼 값어치가 있습니다.** 다만 서둘러 되돌리지는 않습니다.
그 판정들은 각각 별도 근거도 함께 갖고 있고(리프 127 은 제곱오차 t=2.13,
지수감쇠는 t=5.39), 재확인은 편향 없는 방식으로 다시 재야 합니다. 다음 세션
과제로 남깁니다.
