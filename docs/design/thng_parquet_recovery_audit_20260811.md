## 1. 판정

S1 감사의 **`28,547건(3.64%)`은 실제 재생성 학습 행 수가 아닙니다.** 현재
`src/ml/dataset.py`의 조인과 정제를 그대로 적용하면 `lwlt_rate`가 유효하게
채워지는 행은 **14,766건 / 756,702건(1.951%)**입니다. 기존 parquet 784,266행을
분모로 유지해도 **1.883%**입니다.

반면 **그 행이 전부 시간순 홀드아웃에 들어간다는 방향은 맞습니다.** 회수 행은
전부 2026년이고, 재생성 프레임의 80:20 경계는 2024-03-26 11:00입니다. 학습
605,361행에는 회수 행이 0건이고 홀드아웃 151,341행에 14,766건이 모두 들어갑니다.

다만 이 판정은 `lwlt_rate`에 한정해야 합니다. 구형 12컬럼 parquet에 없던 정식
컬럼 `ntce_kind_nm`과 `bid_methd_nm`은 재생성 프레임 **756,702행 전부**에서
채워집니다. 따라서 물품 재생성의 하한율 기대는 낮춰야 하지만, 재생성 전체의
기대값을 “최신 3.64%뿐”으로 평가한 것도 정확하지 않습니다.

## 2. 측정 계약

### 2.1 기준선

| 항목 | 실측 |
| --- | ---: |
| 기존 parquet | 784,266행 x 12컬럼 |
| 기존 parquet 개찰일 | 2015-01-05 ~ 2026-07-31 |
| 기존 80:20 경계 | 2024-03-14 15:00 |
| 2026년 물품 공고 | 77,555건 |
| `sucsfbidLwltRate` 키 존재 | 54,738건(70.580%) |
| 공고 최신 일시 | 2026-08-08 23:03:06 |
| 재생성 프레임 최신 개찰일시 | 2026-07-31 17:00 |

parquet은 `pyarrow.parquet` 메타데이터와 필요한 컬럼만 읽었습니다. DB에는
`SET SESSION TRANSACTION READ ONLY`를 적용하고 `SELECT`만 실행했습니다. parquet,
DB, 모델 파일은 변경하지 않았습니다.

### 2.2 재생성 경로

`src/ml/dataset.py:151`의 공고-낙찰 조인과 다음 정제를 동일하게 적용했습니다.

1. 공고번호 + 정규화한 공고차수 + 업무구분으로 조인합니다.
2. 낙찰률 결측을 제외하고 70~110 구간만 남깁니다
   (`src/ml/dataset.py:193`, `src/ml/dataset.py:219`).
3. 낙찰금액 결측을 제외합니다 (`src/ml/dataset.py:221`).
4. 추정가격 10만원~1조원 구간만 남깁니다 (`src/ml/dataset.py:227`).
5. `sucsfbidLwltRate`는 빈 문자열과 숫자 변환 실패를 결측으로 처리하고, 0도
   결측으로 되돌립니다 (`src/ml/dataset.py:231`, `src/ml/dataset.py:238`).

따라서 JSON에 키가 있는 행, 값이 비어 있지 않은 행, 최종 학습 프레임에서
유효한 행은 서로 다른 집합입니다.

## 3. `70.6%`와 실제 회수 행의 차이

### 3.1 공고 원천

| 단계 | 2026년 공고 | 비율 |
| --- | ---: | ---: |
| 전체 | 77,555 | 100.000% |
| JSON 키 존재 | 54,738 | 70.580% |
| 값이 비어 있지 않음 | 29,508 | 38.048% |
| 숫자 변환 가능하고 0이 아님 | 29,507 | 38.047% |

확정 사실인 **54,738 / 77,555(70.6%)는 값 커버리지가 아니라 키 존재율**입니다.
키가 있어도 25,230건은 빈 값이며, 1건은 빌더가 결측으로 되돌리는 0입니다.

S1의 28,547건은 당시 스냅샷의 비어 있지 않은 공고 수와 가까우나, 낙찰 결과와
조인하고 학습 정제를 통과한 행 수가 아닙니다. 현재 공고 원천의 비어 있지 않은
값 29,508건에서도 실제 학습 행은 아래처럼 다시 줄어듭니다.

### 3.2 학습 빌더 단계별 축소

| 단계 | 전체 행 | 유효 `lwlt_rate` |
| --- | ---: | ---: |
| 공고-낙찰 조인 | 857,214 | 15,509 |
| 낙찰률 결측 제외 | 840,930 | 15,507 |
| 낙찰률 70~110 | 821,590 | 15,507 |
| 낙찰금액 결측 제외 | 784,268 | 14,863 |
| 추정가격 정제 후 최종 | **756,702** | **14,766** |

최종 비율은 **14,766 / 756,702 = 1.951%**입니다. S1 수치 28,547건보다
13,781건(48.27%) 적습니다.

기존 parquet 784,266행에는 현재 추정가격 기준을 벗어난 행이 27,566건 있습니다.
추정가격 정제는 기존 parquet 생성 뒤의 커밋 `646d460`에서 추가됐으므로, 지금
재생성하면 예상 행 수는 784,266행이 아니라 756,702행입니다. 정제 직전 현재
DB 행은 784,268건으로 기존 parquet과 2건만 차이 납니다.

## 4. 회수 행의 시간 분포와 홀드아웃

### 4.1 연도와 월

2015~2025년의 최종 학습 행에는 유효 `lwlt_rate`가 **0건**입니다. 14,766건은
전부 2026년입니다.

| 개찰월 | 재생성 최종 행 | 유효 `lwlt_rate` |
| --- | ---: | ---: |
| 2026-01 | 3,017 | 0 |
| 2026-02 | 4,453 | 0 |
| 2026-03 | 5,934 | 1,675 |
| 2026-04 | 6,760 | 4,249 |
| 2026-05 | 5,337 | 3,211 |
| 2026-06 | 6,250 | 3,674 |
| 2026-07 | 4,002 | 1,957 |
| **합계** | **35,753** | **14,766** |

최초 유효 행의 개찰일시는 2026-03-18 11:00이고 마지막은 2026-07-31
16:00입니다.

### 4.2 시간순 80:20 분할

`src/ml/trainer.py:294`의 위치 기반 시간순 분할을 적용했습니다.

| 구간 | 행 | 유효 `lwlt_rate` | 구간 내 비율 |
| --- | ---: | ---: | ---: |
| 학습 80% | 605,361 | **0** | 0.000% |
| 홀드아웃 20% | 151,341 | **14,766** | 9.757% |

경계 시각은 2024-03-26 11:00이며 같은 시각의 255행 중 168행이 학습, 87행이
홀드아웃에 걸립니다. 회수 행은 경계보다 2년 뒤이므로 동률 순서와 무관하게 전부
홀드아웃입니다. 기존 parquet의 경계 2024-03-14보다 늦어진 것은 재생성 시
추정가격 이상값을 제외하기 때문입니다.

여기에는 한 가지 중요한 제한이 있습니다. 후보 선택과 홀드아웃 지표를 만드는
앞 80% 모델은 `lwlt_rate` 실값을 한 건도 학습하지 못하므로, 이 홀드아웃은
`lwlt_rate`의 기여를 검증할 수 없습니다. 그러나 선택 후 저장 모델은
`src/ml/trainer.py:780`에 따라 전량 재적합하므로 최종 서빙 가중치는 14,766건을
학습합니다. 즉 **홀드아웃에서 기여는 측정 불가하지만 최종 모델에는 들어가는**
비대칭입니다.

## 5. 28컬럼 재생성의 실제 기대값

`lwlt_rate` 표의 14,767건 중 1건은 값 0이라 특징 생성 전 결측으로 바뀝니다.
따라서 최종 유효 수치는 14,766건입니다. `raw_data` 제도 필드 중 하나라도
비어 있지 않은 행은 24,867건(3.286%)이며 모두 최신 구간입니다.

### 5.2 정식 컬럼

| 재생성 컬럼 | 채움 행 | 비율 | 전체 수준 | 학습 80% 수준 |
| --- | ---: | ---: | ---: | ---: |
| `ntce_kind_nm` | 756,702 | 100.000% | 3 | 3 |
| `bid_methd_nm` | 756,702 | 100.000% | 7 | 7 |
| `cntrct_mthd_nm` | 24,867 | 3.286% | 4 | 0 |

`ntce_kind_nm`과 `bid_methd_nm`은 앞 80% 학습 구간에서도 전량 채워지고 수준도
전부 존재합니다. 기존 물품 모델에서는 두 컬럼이 parquet에 없어 모두 `미상`으로
학습됐습니다. 따라서 재생성은 하한율 외에도 **학습 가능한 역사 범주형 특징
2개를 즉시 회수**합니다.

### 5.3 재평가

| 주장 | 재평가 |
| --- | --- |
| 하한율 28,547건(3.64%) 회수 | **불일치.** 유효 학습 행은 14,766건(1.951%) |
| 회수 행 전부 홀드아웃 | **일치.** 학습 0건, 홀드아웃 14,766건 |
| 재생성으로 얻는 정보가 최신 3.64%뿐 | **불일치.** 정식 범주 2개는 전 기간 100% |
| 표준 홀드아웃으로 하한율 기여 검증 가능 | **불가능.** 학습 80%에 실값이 0건 |
| 최종 서빙 모델도 하한율을 못 배움 | **불일치.** 전량 재적합 단계에서는 학습함 |

물품 parquet 재생성의 기대값은 다음처럼 나눠야 합니다.

1. `lwlt_rate` 자체의 표본 기대는 **3.64%에서 1.95%로 하향**합니다.
2. `ntce_kind_nm`과 `bid_methd_nm`은 전 기간에 값이 있어 재생성만으로 실험할
   가치가 있습니다. 다만 실제 성능 이득은 아직 측정하지 않았습니다.
3. 현행 홀드아웃은 `lwlt_rate`를 학습하지 않은 모델을 평가하므로 기여 판정에
   쓰면 안 됩니다. 하한율 기여는 2026-03 이후 표본을 다시 시간순으로 나눈 전용
   실험이 필요합니다.
4. 재생성 결과는 756,702행 x 28컬럼으로 예상됩니다. 원본을 바로 덮어쓰지 말고
   별도 경로에 생성해 행 수, 스키마, 특징 수준, 모델 지표를 비교해야 합니다.
