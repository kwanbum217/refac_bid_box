# 사전규격 API 재수집은 기대 이득이 없습니다

> **작성일**: 2026-08-09
> **버전**: v1.0.0
> **상태**: 기각. 재수집 후보 중 유일하게 추론 시점 조건을 통과했으나 이득이 없음
> **대상**: Servc (용역) 낙찰률 예측 모델 `servc_institution_v1`
> **선행 문서**: [`servc_raw_data_candidate_screen_20260809.md`](servc_raw_data_candidate_screen_20260809.md)

---

## 1. 물음

`raw_data` 축이 닫히면서 G2B API 재수집이 남은 유일한 경로가 됐습니다. 후보
넷 중 **사전규격 API 만 추론 시점 조건을 통과**합니다. 나머지(참가업체 수,
낙찰자 이력, 계약 정보)는 개찰 후 확정값입니다.

재수집은 비용이 큰 설계 과업이므로 **착수 전에 이득의 상한을 재는 것이
순서입니다.** 호출을 한 건도 하지 않고 기존 데이터만으로 잽니다.

**이득이 없습니다.** 이 축을 닫습니다.

---

## 2. 연결률이 37.62% 입니다

`bfSpecRgstNo`(사전규격 등록번호)가 있는 공고만 사전규격 API 로 연결됩니다.
학습 대상 932,524행 기준입니다.

| 개찰 연도 | 행 수 | 연결률 |
| --- | ---: | ---: |
| 2015 | 60,657 | **0.00%** |
| 2016 | 69,940 | 31.11% |
| 2017~2022 | 각 7~8만 | 41.31%~43.98% |
| 2023~2026 | 각 5~10만 | 38.04%~40.24% |
| **합계** | **932,524** | **37.62%** |

**저희 3단계 판정 기준으로 이미 탈락입니다.** 결측 62.38% 는 임계값 40% 를
크게 넘고, 2015년 0% 때문에 연도 폭도 0.44 로 임계값 0.30 을 넘습니다.

**결측의 성격이 중요합니다.** 사전규격 공개는 일정 금액 이상에만 의무입니다.
없는 62% 는 수집 누락이 아니라 **제도적 부재**라, 재수집으로 채워지지 않습니다.
낙찰하한율 결측에서 이미 같은 구조를 겪었습니다.

## 3. 이득의 상한: 하한율 결측을 통제하면 사라집니다

사전규격 보유 건에서 현재 모델이 더 못합니다. 겉보기에는 개선 여지처럼
보입니다.

| 연도 | 구분 | 행 | MAE | 낙찰률 IQR | 편향 |
| --- | --- | ---: | ---: | ---: | ---: |
| 2025 | 사전규격 없음 | 57,665 | 1.1803 | 2.341 | -0.0239 |
| 2025 | 사전규격 있음 | 38,476 | **1.4536** | **8.644** | +0.1327 |
| 2026 | 사전규격 없음 | 34,272 | 1.1317 | 2.541 | -0.1527 |
| 2026 | 사전규격 있음 | 22,066 | **1.6411** | **9.099** | +0.1452 |

**IQR 이 4배 넓습니다.** 못해서가 아니라 어려운 집단이라는 신호이고, 이는
하한율 결측 집단(IQR 9.682 대 0.705)과 같은 모양입니다. 두 집단이 같은
것인지 확인했습니다.

2025년 교차표입니다.

| 하한율 | 사전규격 없음 | 사전규격 있음 |
| --- | ---: | ---: |
| 보유 | 42,558행 / MAE 0.6969 | 24,425행 / MAE 0.8239 |
| 결측 | 15,107행 / MAE 2.5422 | 14,051행 / MAE **2.5481** |

**하한율 결측 안에서는 사전규격 유무의 MAE 차이가 0.006 입니다.** 사실상
없습니다. 사전규격 보유 집단이 나빠 보였던 것은 **하한율 결측 집단과 겹쳤기
때문**이고, 그 집단은 이미 닫힌 갈래입니다(`servc_loss_function_20260807.md`
8.7).

남는 것은 하한율 보유 안의 0.127 뿐입니다. 그마저 사전규격이 원인이라는
근거가 없고, 해당 집단은 전체의 25.4% 입니다. **원인을 전부 사전규격으로
돌려도 전체 MAE 기여 상한은 0.032 이고, 실제로는 그보다 훨씬 작습니다.**

2026-08-03 조사도 같은 방향입니다. 사전규격 **존재 여부**의 eta 제곱은
0.000 이었습니다.

## 4. 결론

| 항목 | 판정 |
| --- | --- |
| 사전규격 API 재수집 | **기각**. 연결률 37.62%, 이득 상한 0.032 |
| 사전규격 보유 집단을 개선 축으로 | **기각**. 하한율 결측 집단과의 겹침이 설명하고, 통제하면 차이 0.006 |
| 나머지 재수집 후보 3종 | 추론 시점에 존재하지 않아 애초에 조건 미달 |

**G2B 재수집 축을 닫습니다.** API 호출을 한 건도 하지 않고 판정했습니다.

측정만 했고 재학습·승격은 하지 않았습니다. 서빙은 `v_20260807_043210_535`
그대로입니다.

## 5. 남은 것

Servc 모델에서 **사전에 순위를 매길 수 있는 개선 축이 모두 닫혔습니다.**
특징 집합, 셀 구조, 목적함수, 하이퍼파라미터, 앙상블, 저장된 `raw_data`,
재수집까지입니다.

다음에 이 모델을 건드릴 이유가 생긴다면 그것은 탐색이 아니라 **외부 사건**
이어야 합니다.

| 사건 | 대응 |
| --- | --- |
| 2026-05-26 레짐 전환 이후 데이터 축적 | 신 제도 기준 학습 데이터가 충분해지면 재학습 가치가 생깁니다 |
| 낙찰하한율 수집 경로 개선 | 결측 62.8% 가 제도적 부재가 아닌 부분이 있는지는 별도 과업 |
| 운영 지표 악화 감지 | PSI 모니터링에서 분포 이동이 잡히면 그때 대응 |

**탐색을 계속하는 것은 권하지 않습니다.** 열 축을 닫는 동안 승격은 하나
(`quantile(0.5)`)였고, 남은 후보의 기대 이득은 시드 산포 0.0016 수준에
가까워졌습니다.
