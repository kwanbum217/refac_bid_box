## 1. 목적함수: 제도 규칙이 모델을 이기고 있었습니다

하한율 보유 66,983건에서 모델과 두 줄짜리 제도 규칙을 비교했습니다.

| 방식 | RMSE | MAE | 1%p 이내 | 0.5%p 이내 |
| --- | ---: | ---: | ---: | ---: |
| L2 모델 | **1.9348** | 0.9676 | 77.68% | 57.43% |
| 규칙: 낙찰률 = 하한율 | 3.7555 | 0.9864 | 85.07% | 73.81% |
| 규칙: 하한율 + gap 중앙값(0.159) | 3.7160 | **0.9374** | **86.84%** | **78.81%** |

**적중률에서 규칙이 모델을 9.2%p 이겼습니다.** RMSE 만 모델이 앞섰습니다.

원인은 손실함수입니다. gap 분포가 0 에 몰린 비대칭이라, 제곱오차를 최소화하면
모델이 조건부 **평균**(0.944)을 향합니다. 그런데 실제 대다수는 조건부
**중앙값**(0.159) 근처에 있습니다. 결과적으로 긴 오른쪽 꼬리를 줄이려고 중심
예측을 위로 밀어 올려 대다수 건에서 조금씩 빗나갑니다.

### 1.1 목적함수 비교

| 목적함수 | R2 | RMSE | MAE | 0.5%p | 1%p | 3%p | 10%p 초과 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| L2 | **0.6910** | **2.6701** | 1.4959 | 45.69% | 63.46% | 84.87% | **1.11%** |
| L1 (= 분위수 0.5) | 0.6683 | 2.7663 | **1.3042** | **61.38%** | **72.17%** | 86.28% | 1.68% |
| **Huber (채택)** | 0.6764 | 2.7326 | 1.3402 | 59.91% | 71.90% | **86.32%** | 1.56% |

**Huber 를 채택했습니다.** L1 이득의 대부분을 가져오면서 꼬리 악화가 절반입니다.

구간별로도 전부 개선입니다.

| 구간 | L2 MAE | Huber MAE | L2 1%p | Huber 1%p |
| --- | ---: | ---: | ---: | ---: |
| 하한율 보유 | 0.9676 | **0.8010** | 77.68% | **86.90%** |
| 하한율 결측 | 2.7093 | **2.5789** | 30.80% | **37.43%** |
| 제한경쟁 | 1.8581 | **1.7432** | 60.57% | **68.26%** |

**하한율 보유 구간이 제도 규칙(86.84%)과 동등해졌습니다.**

### 1.2 편향이 사라졌습니다

L2 시절 예측 오차 중앙값이 +0.317%p 로 체계적 과대 예측이 있었습니다.
Huber + 반복 이력 적용 후 **평균 -0.002, 중앙값 +0.124** 입니다.

## 2. 공고명 텍스트: 분야 신호로는 기각

먼저 공고명을 **분야 분류**로 썼습니다. 제도 별표 기반 키워드 15군과
TF-IDF(어휘 4,000) + SVD 32차원을 각각 시험했습니다.

| 특징군 | 수 | R2 | RMSE | 1%p |
| --- | ---: | ---: | ---: | ---: |
| 현행 (Huber) | 26 | 0.6764 | 2.7326 | 71.90% |
| + 제도 키워드 15군 | 43 | 0.6774 | 2.7282 | 71.88% |
| + 텍스트 SVD32 | 58 | 0.6770 | 2.7299 | 71.84% |
| + 둘 다 | 75 | 0.6776 | 2.7274 | 71.91% |

**개선이 RMSE 0.19% 이고 적중률은 오히려 미세 하락입니다.**

### 2.1 중복성 확인

세부분류를 빼고 텍스트만 넣어 원인을 확인했습니다.

| 구성 | 수 | RMSE |
| --- | ---: | ---: |
| 분류 있음, 텍스트 없음 | 26 | **2.7326** |
| 분류 없음, 텍스트 없음 | 24 | 2.7793 |
| 분류 없음, 텍스트 있음 | 72 | 2.7615 |
| 분류 있음, 텍스트 있음 | 74 | 2.7271 |

분류를 빼면 RMSE 가 0.0467 나빠지는데 텍스트로는 0.0178 만 회복합니다.
**텍스트는 소분류 200종의 열등한 대체재입니다.** 특징 48개를 더해 얻는 것이
없으므로 기각합니다.

## 3. 반복 발주 이력: 같은 공고명을 개체 키로

용역은 청소·경비·통학버스·방과후프로그램처럼 **같은 기관이 주기적으로 같은
사업을 다시 발주**합니다. 공고명을 분야 신호가 아니라 **개체 식별 키**로 쓰면
재발주 이력이 붙습니다.

### 3.1 정규화

회차·연도·긴급 표기를 지워야 같은 사업의 서로 다른 해 공고가 한 키로 묶입니다.

```
2026학년도 창남초등학교 통학버스 임차 용역 입찰 공고
2025학년도 창남초등학교 통학버스 임차 용역 재공고
  -> 창남초등학교 통학버스 임차 용역   (같은 키)
```

키는 `기관명 + 정규화 공고명` 입니다. 정규화 후 4글자 미만이면 서로 다른
사업이 뭉치므로 이력을 붙이지 않습니다.

### 3.2 실측

| 항목 | 값 |
| --- | ---: |
| 재발주 보유 비율 (검증) | **26.05%** (25,048건) |
| 재발주 주기 중앙값 | **358일** |
| 직전 회차 낙찰률과의 절대차 중앙값 | **0.252%p** |

**1년 주기 반복이 데이터로 확인되고, 재발주 건의 낙찰률은 직전 회차가 사실상
그대로 재현됩니다.**

### 3.3 특징 6종과 성능

`is_repeat`, `repeat_cnt`, `repeat_hist_rate`, `repeat_prev_rate`,
`repeat_hist_std`, `repeat_days_since` 입니다.

| 특징군 | R2 | RMSE | MAE |
| --- | ---: | ---: | ---: |
| 현행 (Huber) | 0.6766 | 2.7316 | 1.3400 |
| **+ 반복 발주 이력** | **0.6961** | **2.6481** | **1.2929** |

| 구간 | 건수 | 현행 MAE | 반복이력 MAE | 개선 |
| --- | ---: | ---: | ---: | ---: |
| **재발주 건** | 25,048 | 1.3447 | **1.1454** | **-14.8%** |
| 신규 건 | 71,093 | 1.3384 | 1.3449 | +0.5% |
| 하한율 결측 | 29,158 | 2.5785 | **2.5056** | -2.8% |
| 제한경쟁 | 24,245 | 1.7430 | **1.6924** | -2.9% |

신규 건이 0.5% 나빠지지만 재발주 건 이득이 압도합니다.

### 3.4 누수 차단

`shift(1).expanding()` 으로 **자기 자신과 미래를 제외한** 같은 키의 과거 결과만
씁니다. `attach_institution_history` 와 같은 방식이며 회귀 테스트가 있습니다
([`tests/test_repeat_history.py`](../../tests/test_repeat_history.py)).
