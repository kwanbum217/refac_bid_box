## 1. 요약

물품 학습 특징 34개 중 **17개가 학습 프레임 전량에서 상수**입니다. 이름만
있고 값이 없습니다. 원인은 `data/feature_store/dataset_Thng.parquet` 이 제도
필드 16개가 빠진 12컬럼 구형 스키마로 만들어졌기 때문입니다.

용역에서 `inst_sample_cnt` 가 서빙에서 항상 0 이던 결함과 **같은 형태이되 방향이
반대**입니다. 그때는 학습에 값이 있고 서빙이 상수를 넘겼습니다. 지금은 학습이
상수를 보고 서빙이 실값을 넘깁니다.

다만 결과의 크기는 다릅니다. 모델이 이 17개에 배정한 분기 이득이 전체의
**0.0090%** 라 서빙 실값이 예측을 바꾸는 폭은 절대차 평균 **0.0378%p**
입니다. 승격본 MAE 2.8958 의 1.3% 수준이므로 **현재 성능을 갉아먹는 결함은
아닙니다.** 대신 용역 R2 를 0.5600 에서 0.6910 으로 올린 바로 그 정보가 물품
학습에서 통째로 빠져 있다는 **기회 손실**입니다.

## 5. 결함 후보 판정

### 5.1 결함 후보 A — 학습 상수 / 서빙 실값 (train/serve skew)

DB 최신 물품 공고 1,500건을 실제 서빙 경로(`announcement_feature_payload` ->
`build_feature_frame`)로 통과시켜 잰 값입니다.

| 특징 | 학습값(상수) | 서빙 고유값수 | 서빙 평균 | 학습값과 다른 비율 | 서빙 최대 |
| --- | ---: | ---: | ---: | ---: | ---: |
| lwlt_rate | 0.0 | 22 | 33.5431 | 0.3853 | 100.0 |
| lwlt_rate_missing | 1.0 | 2 | 0.6147 | 0.3853 | 1.0 |
| is_post_regime_shift | 0.0 | 1 | 1.0000 | **1.0000** | 1.0 |
| tech_ablt_evl_rt | 0.0 | 5 | 7.1767 | 0.0820 | 90.0 |
| bid_prce_evl_rt | 0.0 | 5 | 1.0233 | 0.0820 | 40.0 |
| tot_prdprc_num | 0.0 | 3 | 10.4567 | **0.9180** | 15.0 |
| drwt_prdprc_num | 0.0 | 3 | 2.7240 | 0.6813 | 4.0 |

**판정: 결함 성립. 용역 `inst_sample_cnt` 와 같은 형태이며 방향이 반대입니다.**

모델이 학습 중 한 번도 본 적 없는 값을 추론 시점에 받습니다. `tot_prdprc_num`
은 서빙 행의 91.8%가, `is_post_regime_shift` 는 100%가 학습 상수와 다릅니다.

범주형 11개는 skew 가 아닙니다. `apply_categorical_dtypes` 가 저장된 수준
`["미상"]` 밖의 값을 `MISSING_CATEGORY` 로 되접어 넣으므로 서빙에서도 `미상`
으로 붕괴합니다. 서빙 원본에는 실값이 있습니다(`cntrct_mthd_nm` 고유 4종,
`sucsfbid_mthd_nm` 고유 37종). **skew 는 없고 정보만 버려집니다.**

### 5.2 영향 크기 — 용역 결함과 다른 점

승격 모델을 직접 적재해 같은 2,000건에 두 번 예측했습니다. 한 번은 서빙 실값
그대로, 한 번은 위 7개를 학습 상수로 고정한 입력입니다.

| 항목 | 값 |
| --- | ---: |
| 서빙 실값 예측 평균 | 92.0566 (표준편차 4.3503) |
| 학습 상수 고정 예측 평균 | 92.0451 (표준편차 4.3388) |
| 차이 평균 | +0.0115%p |
| 절대차 평균 | 0.0378%p |
| 절대차 중앙값 | 0.0268%p |
| 절대차 최대 | 0.2943%p |
| 0.01%p 초과로 달라진 비율 | 63.65% |

이유는 모델이 이 특징들을 거의 쓰지 않기 때문입니다. LightGBM 분기 이득
비중입니다.

| 특징 | 이득 비중 |
| --- | ---: |
| inst_hist_rate | 33.85% |
| notice_duration | 28.02% |
| repeat_hist_rate | 15.42% |
| notice_amt_ratio | 7.12% |
| log_price | 6.67% |
| repeat_prev_rate | 4.33% |
| inst_sample_cnt | 1.77% |
| **상수 17개 합산** | **0.0090%** |

용역 `inst_sample_cnt` 결함은 평균 절대차 761 로 모델이 실제로 읽는 특징을
망가뜨렸습니다. 물품은 모델이 읽지 않는 특징이 흔들리는 것이라 **현 시점
성능 손실은 MAE 2.8958 대비 1.3% 수준으로 작습니다.**

### 5.3 결함 후보 B — 기회 손실 (본질적 문제)

용역에서 같은 특징군을 넣었을 때의 실측입니다
(`docs/design/servc_segment_experiment_20260803.md`,
`servc_restricted_competition_20260803.md`).

| 구성 | R2 | RMSE |
| --- | ---: | ---: |
| 기존 6종 | 0.5600 | 3.1780 |
| + 제도 수치 | 0.6433 | 2.8615 |
| + 제도 범주 5종 | 0.6767 | 2.7312 |
| + 세부분류·공고속성 범주 11종 | 0.6910 | 2.6701 |

R2 를 0.5600 에서 0.6910 으로 끌어올린 것이 바로 물품에서 죽어 있는 특징군
입니다. 물품 R2 0.4160 과 용역 0.6842 의 격차를 이것만으로 설명할 수는
없지만, **격차를 좁힐 후보 중 유일하게 실측 근거가 있는 축**입니다.

### 5.4 결함 후보 C — 측정 경로가 결함을 가림

`docs/design/thng_retraining_20260806.md` 5장은 "서빙 측정이 parquet 12개 중
3개만 전달" 하던 결함을 고쳤다고 적었습니다. 그 수정은 **12컬럼 전부를**
전달하도록 한 것이고, parquet 에 없는 16컬럼은 그대로 빠져 있습니다.

그래서 R2 0.4160 을 낸 측정은 학습과 같은 상수 입력을 썼습니다. 실제 API 는
DB 를 읽어 실값을 넘기므로 두 경로가 다릅니다. 5.2 기준 차이는 작지만,
**측정 경로가 skew 를 구조적으로 볼 수 없다**는 점 자체가 결함입니다.
