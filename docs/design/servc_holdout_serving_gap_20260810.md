## 1. 한 문장

**학습은 낙찰률을 `[70, 110]` 으로 자르는데 평가는 자르지 않습니다.** 운영 표본의
**0.667%(60건)** 가 그 밖에 있고 그 행들의 MAE 가 **35.08** 이라, 미설명으로
남아 있던 격차 0.17 이 전부 설명되고 부호까지 뒤집힙니다.

---

## 2. 무엇이 미설명이었는가

같은 해 같은 모델인데 경로별 절대 MAE 가 달랐습니다.

| 경로 | 2025년 MAE |
| --- | ---: |
| 홀드아웃 (parquet 96,141건) | 1.2407 |
| 운영 쌍대 (9,997건) | 1.4109 |

`servc_paired_asof_gap_20260810.md` 3.3 이 이력 시점으로 설명되지 않음을
확인했고, `servc_split_variance_20260810.md` 6장은 기준 MAE 자체의 분할 간
표준편차가 0.0205 로 0.17 을 설명하기엔 턱없이 작다고 적었습니다.

**두 문서 모두 원인을 열어 둔 채 끝났습니다.**

## 3. 후보를 하나씩 배제했습니다

DB 접속 없이 코드와 parquet 만으로 셋을 배제했습니다.

| 후보 | 확인 | 판정 |
| --- | --- | --- |
| 날짜 컬럼이 다르다 | 양쪽 모두 `BidResult.rl_openg_dt` | 배제 |
| 타깃 정의가 다르다 | `winning_rate` 는 `sucsf_bid_rate` 의 라벨 (`dataset.py:167`) | 배제 |
| 공고 조인 유무가 다르다 | parquet 의 `cntrct_mthd_nm` 결측률 0% 로 학습도 공고 조인 건 | 배제 |
| **낙찰률 범위 필터** | parquet 2025년 최솟값이 정확히 **70.0** | **유력** |

절단면이 정확히 상수 값에 걸리는 것은 필터의 흔적입니다.

## 4. 원인: 두 경로의 표본 정의가 다릅니다

```
학습   src/ml/dataset.py:220
       df = df[df["winning_rate"].between(MIN_WINNING_RATE, MAX_WINNING_RATE)]
       -> 70 <= winning_rate <= 110

평가   scripts/eval_servc_api_path.py:65
       BidResult.sucsf_bid_rate > 0
       -> 0 초과 전부
```

**모델이 배우지 않은 구간에서 채점하고 있습니다.**

저장된 쌍대 잔차로 기여를 쟀습니다(2025년 8,995건).

| 항목 | 값 |
| --- | ---: |
| 학습 범위 밖 | **60건 (0.667%)** |
| 그 60건의 MAE | **35.08** |
| 전체 MAE 기여 | **0.2340** |

| 조건 | MAE |
| --- | ---: |
| 운영 쌍대 전량 | 1.4159 |
| **운영 쌍대 범위 내 (8,935건)** | **1.1899** |
| 홀드아웃 (parquet) | 1.2407 |

**격차 0.17 이 전부 설명되고 부호가 뒤집힙니다.** 이상치를 빼면 운영이 홀드아웃
보다 0.05 좋습니다. 모델이 운영에서 나빴던 것이 아닙니다.

MAE 는 이상치에 선형으로 반응합니다. 0.667% 의 행이 오차 35 를 내면 그것만으로
0.23 이 더해집니다.

### 4.1 그 60건은 무엇인가

| 구분 | 값 |
| --- | --- |
| 방향 | **전부 70 미만.** 110 초과는 0건 |
| 실제값 중앙값 | 51.34 (최소 0.49, 최대 69.70) |
| 하한율 보유 | **38건 (63.3%)** |
| 용역구분 | 일반용역 55건 (91.7%). 범위 내 비중은 63.3% |

**하한율 보유 건이 63% 라는 것이 이상합니다.** 하한율이 있으면 낙찰률은 그
아래로 내려갈 수 없는데, 이 행들은 51% 수준입니다. 제도적으로 성립하지 않는
조합이므로 **데이터 품질 문제일 가능성이 높습니다.** 정체 규명은 이 문서의
범위 밖이며 후속 과제로 남깁니다(7장).

## 5. 판정에 미친 영향

같은 도구로 과거 판정을 다시 계산했습니다.

| 검정 | 전량 | 범위 내 | 변화 |
| --- | --- | --- | --- |
| **`quantile(0.5)` 승격** (2025) | -0.01099, **t=-2.89** | -0.00693, **t=-1.91** | **통과 -> 판별 불가** |
| `quantile(0.5)` 승격 (2026) | -0.01223, t=-2.92 | -0.00674, **t=-1.67** | **통과 -> 판별 불가** |
| 하이퍼파라미터 기각 (2025) | +0.01390, t=+5.14 | +0.01085, t=+4.16 | 기각 유지 |

**현재 서빙 중인 `quantile(0.5)` 의 승격 근거가 0.667% 의 행에 의존했습니다.**
쌍대 평균차의 **37%** 가 그 60건에서 나왔습니다(-0.01099 -> -0.00693).

### 5.1 그래도 롤백 사유는 아닙니다

| 근거 | 내용 |
| --- | --- |
| 방향 일관 | 2025년 -1.91, 2026년 -1.67 로 두 해 모두 challenger(quantile) 쪽 |
| 악화 아님 | 판별 불가일 뿐 base 우세로 뒤집히지 않았습니다 |
| 홀드아웃 근거 | quantile 채택은 홀드아웃 근거도 따로 있습니다 |

**유지합니다.** 다만 "운영에서 직접 통과했다" 는 서술은 과했으므로, 앞으로는
"두 해에서 방향이 일관하나 범위 내 표본에서는 판별 불가" 로 적어야 합니다.

### 5.2 기각 판정들은 영향받지 않습니다

하이퍼파라미터 축은 t=+5.14 에서 +4.16 으로 줄었을 뿐 방향과 유의성이
그대로입니다. **오늘 기각한 alpha 0.45 도 마찬가지입니다** — 분할 산포
0.0074 를 넘지 못한다는 것이 기각 근거였고, 그 판정은 홀드아웃 쪽이라 이
문제와 무관합니다.

## 6. 결정: 판정용과 보고용을 분리합니다

**판정용 표본은 학습 필터와 같은 정의를 씁니다.**

| 근거 | 내용 |
| --- | --- |
| 모델이 손댈 수 없는 구간 | `[70,110]` 밖은 어떤 후보든 같은 방식으로 틀립니다. 우열이 드러나지 않습니다 |
| 잡음이 신호를 덮음 | 0.667% 가 쌍대 평균차의 37% 를 만듭니다. 이건 신호가 아닙니다 |
| 검정력 | 범위 내 최소 감지 차이가 0.00761 에서 0.00725 로 줄어듭니다 |

**보고용 실측은 전량으로 유지합니다.** 사용자는 그 60건도 겪습니다. 서비스
성능을 말할 때 이상치를 빼고 말하면 실제보다 좋게 보고하는 것입니다.

| 용도 | 표본 | 2025년 MAE |
| --- | --- | ---: |
| 승격 판정 | 학습 범위 내 | 1.1899 |
| 성능 보고 | 전량 | 1.4159 |

**두 숫자를 섞어 쓰지 마십시오.** 지금까지 기록된 운영 기준선(1.4050 등)은
전량 기준이므로 보고용입니다.

## 7. 남은 과제

| # | 과제 | 성격 |
| --- | --- | --- |
| 1 | `compare_servc_models_paired.py` 에 범위 필터 반영 | 코드 변경. 미착수 |

판정을 얻습니다. 당장은 이 스크립트로 저장된 잔차를 사후 재계산하면 됩니다.

3번은 별개 위험입니다. `MIN_WINNING_RATE = 70.0` 의 근거가 코드에 없습니다.
이 값이 임의로 정해졌다면 학습 표본에서 정상 건을 버리고 있을 수 있습니다.

## 9. 교훈

**절대 수준이 다르면 표본 정의부터 맞춰 보십시오.** 이 격차는 두 번의 조사에서
미설명으로 남았습니다. 두 번 다 특징 값과 이력 시점을 봤고, 정작 **어떤 행이
표본에 들어오는가**는 보지 않았습니다. 특징을 아무리 대조해도 표본이 다르면
같은 값이 나오지 않습니다.

**필터는 한쪽에만 걸기 쉽습니다.** 학습 파이프라인의 정제 규칙은 데이터셋 빌더
안에 있고, 평가 스크립트는 DB 를 직접 조회합니다. 두 경로가 물리적으로 떨어져
있으면 규칙이 갈라져도 아무도 모릅니다. 이 저장소는 특징 생성을 `features.py`
로 단일화했는데(AGENTS.md 6항), **표본 선정 규칙에는 같은 원칙이 적용되지
않았습니다.**

**소수의 이상치가 판정을 만들 수 있습니다.** 0.667% 가 쌍대 평균차의 37% 를
만들었고, 그것이 승격 판정의 t 를 -2.89 로 밀어 올렸습니다. 표본의 절대 다수가
정상이라는 사실은 MAE 기반 판정을 보호해 주지 않습니다.
