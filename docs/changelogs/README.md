# Changelogs 안내

> **작성일**: 2026-07-31

---

## 기록 방식

- **이니셜별 단일 파일**에 작업 로그를 하단에 누적합니다.
- 파일명: `[이니셜].md` (예: `kb.md`)
- 작업 단위로 [`TEMPLATE.md`](TEMPLATE.md) 양식을 사용해 엔트리를 추가합니다.

## 엔트리 작성 규칙

1. 작업 완료 시 **반드시** 해당 이니셜 파일에 changelog 엔트리를 추가합니다.
2. 날짜는 `YYYY-MM-DD` 형식.
3. 구체적인 파일 경로, 함수명, 검증 결과를 명시합니다.
4. 한국어 존댓말로 작성합니다. 이모지는 금지합니다.

## 자동화 (선택)

작업 완료 후 자동 기록을 위한 스크립트를 제공할 수 있습니다:

- `scripts/postwork.sh` (macOS/Linux)
- `scripts/postwork.bat` (Windows)
