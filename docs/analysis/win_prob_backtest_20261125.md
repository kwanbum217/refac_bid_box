## 0. 결론 요약

1. **백테스트는 가능하다.** 최근 12개월 용역 예비가격 110,848건 중 56,515건(51.0%)에
   기초금액·예정가격·낙찰금액·낙찰하한율이 모두 있어 가상 낙찰 판정을 할 수 있었다.
2. **단일 투찰의 상한은 이 데이터에서 약 14%다.** S1 13.51%, S2 13.92%,
   S3 14.32%였고, S3와 S2의 차이는 통계적으로 유의하지 않다(McNemar p=0.386).
   단일 투찰가를 정교하게 고르는 것만으로는 큰 개선을 기대하기 어렵다.
3. **여러 법인 분산 배치의 효과는 크고 유의하다.** N=2 24.86%, N=3 32.07%로
   단일 S2(13.92%) 대비 각각 +10.9%p, +18.2%p다(McNemar p=8.55e-82, 4.46e-35).
   N=3은 단일 대비 약 2.3배다.
4. **낙찰률 분포는 반드시 같은 하한율로 조건화해야 한다.** 하한율을 섞은 무조건부
   모델은 12.98%로 S3 조건부(14.32%)보다 1.34%p 낮았고 유의했다(p=0.000849).
5. **설계 제안:** 단일 투찰은 현행 S2(보완 투찰률 x p50 사정률)를 유지하고,
   여러 법인은 하한율 조건부 승리 구간의 등확률 분위 `(j+0.5)/N`에 배치한다.
   N=2는 q25/q75, N=3은 q1/6·q1/2·q5/6이 측정상 가장 좋았다.

## 2. 방법

### 2.1 가상 낙찰 판정

- 기초금액 `B`, 실제 예정가격 `P`, 실제 낙찰금액 `W`, 낙찰하한율 `L`(퍼센트).
- 우리 투찰금액 `b`는 개찰 전 정보(`B`, `L`, 그 이전 기간 통계)로만 정한다.
- 가상 낙찰 조건: `b >= L*P/100` 이고 `b < W`.
  - 하한가 이상이면서 실제 낙찰자보다 낮으면, 경쟁자 투찰이 그대로일 때
    우리가 최저 통과 입찰자가 된다.
- 정량점수는 만점으로 가정했다. 따라서 보완 투찰률은 하한율 `L`과 같다.
- `x = b/B*100`(기초금액 대비 투찰률), `s = P/B*100`(사정률),
  `r = W/P*100`(낙찰률)로 두면 승리 구간은 `L*s/100 <= x < s*r/100`이다.

### 2.2 미래 정보 누설 차단

- 주 분할: 2025-11-25 ~ 2026-08-24 통계(49,958건) -> 2026-08-25 ~ 2026-11-25 평가(6,557건).
- 보조 분할: 2025-11-25 ~ 2026-05-24 통계(39,110건) -> 2026-05-25 ~ 2026-08-24 평가(10,848건).
- 워크포워드: 2026-09, 2026-10 각 월초까지의 통계로 해당 월 평가.
- 각 실행에서 `max(통계 개찰일) < 분할점 <= min(평가 개찰일)`을 코드로 단언한다.
- 사정률 p50, 낙찰률 분포, 분위 배치는 모두 분할점 이전 표본만 쓴다.

### 2.3 낙찰률 분포의 하한율 조건화

낙찰률 `r`의 수준은 그 공고의 하한율에 종속된다. 하한율 90% 공고의 낙찰률은
90% 근처, 80% 공고의 낙찰률은 80% 근처다. 따라서 낙찰률 표본을 하한율 구분 없이
섞으면 승리 구간의 상한이 왜곡된다. 이 백테스트는 다음 순서를 쓴다.

1. 같은 하한율(소수 3자리) 표본을 기관 -> 시·도 -> 업종 순으로 찾는다.
2. 기관은 전체 30건 이상일 때, 시·도는 전체 50건 이상일 때 후보가 된다.
   후보 범위 안에서 같은 하한율 표본이 30건 이상이면 그 분포를 쓴다.
3. 어느 범위도 같은 하한율 30건을 못 채우면, 가장 가까운 범위의
   마진 `m = r - L` 분포를 현재 하한율에 더해 `r = L + m`으로 근사한다.

주 분할에서 분포 출처는 기관 2,864건, 시·도 2,198건, 업종 1,444건,
마진 대체 51건이었다. 같은 하한율 표본 수는 중앙 140건(최소 30, 최대 27,801)이다.

### 2.4 비교 전략

| 전략 | 정의 |
| --- | --- |
| S1 | `x = L`. 하한율 x 기초금액, 사정률 100% 가정 |
| S2 | `x = L * p50(s) / 100`. 현행 추천의 정량점수 만점 버전 |
| S3 | 경험적 승리 구간 `[L*s/100, s*r/100)`을 가장 많이 덮는 `x` |
| S3_raw | S3의 반례. 낙찰률을 하한율로 조건화하지 않고 그대로 사용 |
| S4 N=k | 승리 구간 중앙값 분포의 `(j+0.5)/k` 분위에 k개 법인 배치 |
| S4 N=4,5 | 위 규칙의 확장(설계 참고, 요구 범위 밖) |

S3는 구간 끝점만 스윕해 정확한 최대를 찾는다. 동률 구간이 여럿이면 중앙값
분포의 중앙에 가장 가까운 구간의 중앙을 택했다. S4는 같은 승리 구간 분포의
중앙값을 분위로 나눠 배치하며, 이는 "S3 목표 분포의 서로 다른 분위"를
운영 가능한 형태로 구현한 것이다.

결과가 달라질 수 있으나, 발생 빈도가 낮아 결론을 바꾸지 않는다.

## 4. 해석

### 4.1 승리 창이 매우 좁다

주 통계 기간의 사정률은 평균 99.8373%, p10 98.932%, p90 100.718%다.
반면 낙찰률에서 하한율을 뺀 마진은 p50 0.148%p, p90 1.618%p다.
마진이 0.2%p 미만인 표본이 56.1%, 0.5%p 미만이 74.1%다.

즉 실제 낙찰자는 하한가 바로 위에서 결정되는데, 하한가 자체는 사정률 때문에
p10~p90이 약 1.8%p 폭으로 흔들린다. 고정된 투찰률 하나로는 이 좁은 창을
자주 맞출 수 없다. 이것이 단일 투찰 낙찰률이 14% 내외에 머무는 구조적 이유다.

### 4.2 단일 투찰 최적화의 한계

S1(하한율 그대로) 13.51%, S2(p50 사정률 반영) 13.92%, S3(경험적 최적)
14.32%다. S3가 가장 높지만 S2와의 차이는 유의하지 않다. S2는 S1보다
0.4%p 높은데 이 역시 유의하지 않다. 단일 투찰에서는
"하한율 x p50 사정률" 수준의 단순 규칙과 경험적 최적화의 실질 차이가 없다.

현행 추천은 정량점수로 필요한 가격점수를 만족하는 최저 투찰률(보완 투찰률)에
p50 사정률을 곱한다. 정량점수 만점 가정에서는 보완 투찰률이 하한율과 같으므로
S2가 현행 추천의 상한 성능이다. 정량점수가 만점이 아니면 실제 추천가는
더 높아지고, 승리 창에서 위쪽으로 벗어날 가능성이 커진다. 이 백테스트는
그 효과를 측정하지 않았다.

### 4.3 하한율 조건화가 중요하다

S3_raw는 낙찰률을 하한율 구분 없이 섞어 쓴 모델이다. 12.98%로 S1보다도 낮고,
S3 조건부보다 1.34%p 낮다. 하한율 90% 공고의 낙찰률(약 90%)을 하한율 80%
공고의 승리 구간 상한으로 쓰면 창이 실제보다 넓어져 과대 투찰하게 된다.
구현 단계에서 낙찰률 통계를 만들 때 하한율을 반드시 조건으로 넣어야 한다.

### 4.4 여러 법인 분산 배치가 핵심 레버다

N=2 24.86%, N=3 32.07%, N=4 37.55%, N=5 41.41%다. 단일 S2 13.92% 대비
N=2는 1.8배, N=3은 2.3배, N=5는 3.0배다. 한계 효익은 줄어든다.
N=2->3 +7.2%p, N=3->4 +5.5%p, N=4->5 +3.9%p다.

중요한 것은 "같은 가격을 여러 번 내는 것"이 아니라 "서로 다른 분위에
배치하는 것"이다. 같은 금액을 여러 법인에 중복 배치하면 판정이 동일해져
단일 전략과 같은 결과가 된다. q25/q75로 벌리면 24.86%가 된다.
분산 그 자체가 성과를 만든다.

### 4.5 분포 출처별 해석의 주의

기관 범위를 쓸 수 있는 공고의 S3 14.98%가 시·도 범위 12.92%보다 높다고
해서 "기관 통계가 더 좋다"고 단정할 수 없다. 두 집단의 공고 구성(하한율,
사정률 변동성, 참가 업체)이 다르다. 이 표는 어떤 분포가 실제로 쓰였는지를
보여주는 용도이며, 범위 선택의 인과 효과가 아니다.

## 5. 한계

1. **정량점수 만점 가정.** 모든 투찰가가 적격심사 정량점수를 통과한다고
   가정했다. 실제 회원의 비가격 점수가 낮으면 보완 투찰률이 하한율보다
   높아지고, 하한가 근처의 S1/S3/S4 투찰은 탈락한다. 따라서 단일·다법인
   낙찰률은 모두 상한 추정이다.
2. **실제 낙찰자 투찰 분포 미보유.** `bid_results`에는 낙찰금액만 있고
   전체 투찰자 분포가 없다. 가상 낙찰은 "경쟁자 투찰이 그대로일 때 우리가
   최저 통과자가 된다"는 반사실 가정이다. 우리 법인이 추가로 투입되어
   경쟁 구도가 바뀌는 효과는 반영하지 못했다. N이 클수록 이 상향 편향이
   커질 수 있다.
3. **동점 처리.** `b == W`는 패배로 계산했다. S1 24건, 나머지 0건이다.
4. **하한율 70~100% 필터.** 하한율 0% 이하 5,969건과 0% 초과 50% 미만
   526건을 제외했다. 이 필터는 "적격심사"를 식별하는 근사이며, 70%대 일부
   공고에는 다른 계약 유형이 섞여 있을 수 있다.
5. **데이터 신선도.** 11월 사용분이 3건뿐이고, 44,106건(39.8%)은
   예정가격/기초금액이 없어 제외됐다. 최근 구간의 수집 지연이 있어
   주 평가 기간은 2.5개월이다. 보조 분할과 워크포워드로 보완했지만,
   최신 유행이 바뀌면 결과가 달라질 수 있다.
6. **창 길이 미최적화.** 통계 창은 6~11개월 구간에서 안정적이었으나,
   최적 창 길이(9개월 vs 12개월 vs 36개월)를 탐색하지 않았다. 현행
   `institution_sajeong_rate_stats`는 1,095일 창을 쓴다. 이 백테스트는
   그 창을 재현하지 않았다.
7. **참가 업체 수·경쟁 강도 미반영.** `bid_results.raw_data.prtcptCnum`
   등 참가자 수를 모형에 넣지 않았다. 마진 분포가 참가자 수에 따라
   달라진다면 정밀도가 개선될 여지가 있다(미확인).
8. **다법인 제도 제약 미반영.** 동일 계열사·동일인 다수 투찰은 공고별
   입찰참가자격과 동일인 판정 기준에 따라 제한될 수 있다. 이 백테스트는
   제도적으로 허용된다고 가정했다. 구현 전에 공고 유형별 허용 여부를
   확인해야 한다.
9. **분위 배치의 최적성.** N=2/3에서 등확률 분위가 측정상 가장 좋았지만,
   더 정교한 최적화(예: 분포 추정 후 동적 계획)가 더 나을 가능성은
   배제하지 못했다. 다만 경험적 최대화(S3)는 표본이 작을수록 과적합되기
   쉬워, 등확률 분위가 운영에 더 안전하다.

## 6. 구현 Task 설계 제안

### 6.1 분포와 우선순위

다음 두 분포를 분리해 관리한다.

| 분포 | 정의 | 우선순위 |
| --- | --- | --- |
| 사정률 `s` | `plnprc / bssamt * 100` | 기관(30건 이상) -> 시·도(50건 이상) -> 업종 |
| 낙찰 마진 `m` | `sucsf_bid_rate - 하한율` | 같은 하한율 표본: 기관(30건) -> 시·도(50건) -> 업종(30건) -> 마진 대체 |

- 사정률은 하한율과 독립이므로 전체 표본을 써도 된다.
- 낙찰률은 반드시 하한율로 조건화한다. 같은 하한율 표본이 부족하면
  마진 `m` 분포를 현재 하한율에 더해 `r = L + m`으로 근사한다.
- 승리 구간은 `[L*s/100, s*(L+m)/100)`이다. 가능하면 `(s, m)`을 같은
  과거 공고에서 짝지어 뽑아 상관을 보존한다.
- 기존 `institution_sajeong_rate_stats`는 사정률 분위(p10/p50/p90 등)만 있고,
  기존 `institution_win_rate_stats`는 낙찰률 평균(과 지수감쇠 평균)만 있다.
  두 표로는 승리 구간 분포를 만들 수 없다. `(범위, 하한율, 창)`별 낙찰 마진
  분포 또는 분위(p10/p25/p50/p75/p90)를 새로 집계해야 한다.

### 6.2 단일 투찰 추천

- **현행 S2를 유지한다.** 보완 투찰률 x p50 사정률은 단일 전략 중
  S3와 유의한 차이가 없고, 표본이 작은 기관에서도 안정적이다.
- 단일 투찰의 추정 낙찰 확률을 표시하려면, 선택한 `x`가 승리 구간을
  덮는 비율을 같은 조건부 분포에서 계산해 보여준다. 이 값은 이 데이터에서
  약 14% 수준이며, 95% 구간은 13~15%다.
- **회원별 보완 투찰률 `M`을 하한율 `L`과 분리한다.** 정량점수가 만점이
  아니면 `M > L`이다. 이때 회원의 승리 조건은
  `M*s/100 <= x < s*(L+m)/100`이다. 하한은 회원의 `M`, 상한은 경쟁자의
  규칙 하한율 `L`로 계산해야 한다. `M`이 `L+m` 분포의 상당 부분보다 크면
  그 회원은 구조적으로 이길 수 없으므로 추천에서 제외하거나 경고를 표시한다.
- p50 하나만 보여주는 현재 UI는 "왜 이 가격인지"를 설명하지 못한다.
  최소한 p10/p50/p90 시나리오의 하한 미달·낙찰자 상회 확률을 함께
  보여주는 것이 좋다.

### 6.3 여러 법인 배치 규칙

1. 공고의 규칙 하한율 `L`과 범위(기관/시·도/업종)를 정한다.
2. 해당 범위의 과거 `(s, m)` 표본으로 승리 구간 `[L*s/100, s*(L+m)/100)`을
   만든다.
3. 구간 중앙값을 정렬해 `x_j = quantile(midpoints, (j+0.5)/N)`을 구한다.
   - N=2: q25, q75
   - N=3: q1/6, q1/2, q5/6
   - 일반식: `(j+0.5)/N`
4. `b_j = round(B * x_j / 100)` (1원 단위, ROUND_HALF_UP).
5. 각 법인 `i`의 최소 통과 투찰률 `M_i`를 반영해 `b_i`가
   `M_i * B * p50(s)/100` 이상이 되도록 클립한다. 이 클립은 p50 시나리오
   기준이며, 실제 사정률이 p50보다 높으면 하한 미달 위험이 남는다.
6. 클립 때문에 두 법인의 금액이 같아지면 한쪽을 1원 낮추거나 다음 분위로
   이동한다. 같은 금액을 여러 법인에 중복 배치하는 것은 승률을 높이지 않는다.
7. 낮은 분위(개별 승률이 높은 쪽)를 우선순위 법인에 배정한다. 어느 법인이
   이기든 그룹 목표가 같다면 배정 순서는 무관하다.
8. 동일 계열사 다수 투찰 허용 여부를 사전에 확인한다.

측정된 기대값은 N=2 24.86%, N=3 32.07%다. 이는 "공고 1건당 그룹이
하나라도 낙찰하는 비율"이며, 법인별 개별 승률의 합이 아니다.

### 6.4 집계·캐시·갱신

- 집계 키: `(scope, scope_name, category, lwlt, window_days)`.
- 저장 값: 표본 수, 마진 p10/p25/p50/p75/p90, 또는 원 표본 `(s, m)`.
- 갱신: 월 1회 야간 배치. 백테스트는 6~11개월 창에서 안정적이었으나
  최적 창은 미확인이므로, 우선 최근 12개월을 권장하고 창 길이는
  후속 실험으로 정한다.
- 요청 시점 계산: 같은 하한율 표본 중앙 140건, 최대 27,801건이다.
  기관/시·도 단위는 요청 시 계산해도 되지만, 업종 대표 하한율(예: 88%)은
  표본이 커서 야간 사전 계산과 캐시가 필요하다.
- 캐시 키에 `(scope, lwlt, N, window)`를 넣고, 통계 갱신 시 무효화한다.

### 6.5 검증·운영 계획

- **재현 검증:** 이 보고서의 표는
  `uv run python .orca/reports/win_prob_backtest_20261125.py` 출력과
  그대로 대조한다.
- **그림자 모드:** 추천을 실제 노출하지 않고 S3/S4 가상 결과를 로그로

  (정량점수 만점, 경쟁자 고정)이 운영에서 얼마나 어긋나는지 확인한다.
- **분포 드리프트:** 사정률 p50과 낙찰 마진 p50의 월별 이동을 모니터링한다.

- **제도 가드:** 다법인 배치 허용 여부, 동일인 판정, 법인별 입찰참가자격을
  사전에 검사한다. 이 백테스트의 N=2/3 수치는 제도적 허용을 가정한 값이다.
