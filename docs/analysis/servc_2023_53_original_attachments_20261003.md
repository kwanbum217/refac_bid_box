## 3. 판정

- 대비표 기반 복원에서 B 등급(동일 추정)이던 k 11개 별표 값이 원문과 전부 일치합니다. 기준값과 배점한도도 일치합니다. 따라서 B·k 를 A 등급(원문 직접 확인)으로 승격합니다.
- 규칙 단위 선언은 원문에서 단일값이 나오는 경우만 합니다. 5억원 축(B)이나 고시금액 축(k)으로 갈리는데 규칙이 두 구간을 함께 덮으면 None 으로 둡니다. 결과는 같은 구조의 2025-09-01 시행 판 선언과 같습니다.
