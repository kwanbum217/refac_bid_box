## 1. 요약

### 1.1 결론

1. 전라남도 예규 제1075호 별표 5는 낙찰하한율을 인쇄하지 않지만, 배점한도 B 80·60, 감점계수 k 2, 기준비율 88, 통과점수 95·90·85를 산식에 대입하면 85.495·82.995·80.495가 나옵니다. 규칙 등록값과 같습니다.
2. 광주광역시 예규 제377호 별표 6 육상운송 행은 낙찰하한율 85.495를 **원문에 인쇄**합니다. 전남광주통합특별시 예규 제3호 별표 5도 85.495·82.995·80.495를 **원문에 인쇄**합니다.
3. 87.995는 시·도 규칙값이 아닙니다. 공고값이 87.995인 156건 가운데 이번에 첨부를 확인한 4건의 공고문은 「조달청 일반용역 적격심사 세부기준」 별표 5(여객 육상운송, 추정가격 5억원 미만)를 명시 적용하고 그 값 87.995를 인쇄했습니다.
4. 같은 전남 권역에서 전남 예규 제1075호 별표 5를 적용한 공고 1건은 85.495를 인쇄했습니다. 이 대조가 규칙값 85.495가 원문과 맞는다는 직접 증거입니다.
5. 따라서 5.1절 권고 (C)의 결론은 **85.495 유지**입니다. 값 정정이 아니라, 공고가 인용한 기준과 코드가 고른 규칙 ID가 다른 문제입니다.

### 4.1 규칙값을 87.995로 정정할 경우

값을 87.995로 바꾸면 156건의 불일치는 사라지지만, 원문과 공고가 함께 지지하는 85.495를 버리게 됩니다. 전남 별표 5의 산식, 광주 별표 6의 인쇄값, 전남광주통합특별시 별표 5의 인쇄값, 화순군 공고문의 인쇄값이 모두 85.495입니다. 따라서 **값 정정은 근거가 없습니다.**

| 항목 | 현행 | 공고 인용 기준 우선 | 변화 |

### 4.3 전남광주통합특별시 대표값 84.245 관찰

`SERVC_LOCAL_JNGJ_20260716_ATTACH_05`의 대표값은 84.245입니다([`src/app/services/evaluation_rules_local.py:1578`](/src/app/services/evaluation_rules_local.py:1578)). 그러나 별표 5가 인쇄한 값은 85.495·85.495·85.495·82.995·80.495이고 84.245는 어느 구간에도 없습니다. 구간값이 모두 등록되어 있어 추정가격이 있으면 구간값이 쓰이므로 이번 157건에는 영향이 없습니다. 추정가격이 없어 구간을 고르지 못할 때만 84.245로 되돌아갈 수 있는 잠재 위험입니다. 이번 창의 전남·광주 육상운송 165건에서는 이 규칙이 적용된 건이 없어 실제 영향은 0건입니다.

```sh

uv run python scripts/db_readonly_query.py --limit 0 --format json --sql "
WITH rep AS (
  SELECT ba.bid_ntce_no, ba.bid_ntce_ord, ba.bid_ntce_dt, ba.dminstt_nm, ba.presmpt_prce,
         ba.raw_data,
         ROW_NUMBER() OVER (PARTITION BY ba.bid_ntce_no, ba.category
                            ORDER BY CAST(ba.bid_ntce_ord AS UNSIGNED) DESC) AS rn
  FROM bid_announcements ba
  WHERE ba.category = 'Servc'
    AND ba.bid_ntce_dt >= '2025-11-06' AND ba.bid_ntce_dt < '2026-11-07'
)
SELECT r.bid_ntce_no, r.bid_ntce_ord, r.bid_ntce_dt, r.dminstt_nm, r.presmpt_prce,
       JSON_UNQUOTE(JSON_EXTRACT(r.raw_data, '$.sucsfbidMthdNm')) AS mthd,
       JSON_UNQUOTE(JSON_EXTRACT(r.raw_data, '$.sucsfbidLwltRate')) AS lwlt,
       JSON_UNQUOTE(JSON_EXTRACT(r.raw_data, '$.dminsttCd')) AS inst_cd
FROM rep r
WHERE r.rn = 1
  AND JSON_UNQUOTE(JSON_EXTRACT(r.raw_data, '$.sucsfbidMthdNm')) LIKE '%육상운송%'
```
