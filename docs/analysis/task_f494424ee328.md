## 1. 목적

`docs/analysis/` 의 수치를 `data/benchmarks/*.json` 원시 측정에서 기계로 생성하고,
손으로 옮겨 적은 수치가 원본과 어긋나면 검사에서 잡는다.

---

## 2. 구현 요약

### 2.1 `scripts/render_analysis_metrics.py`

두 하위 명령을 제공한다.

| 하위 명령 | 설명 | 종료 코드 |
| --- | --- | --- |
| `generate` | JSON 경로와 키 선택자를 받아 마크다운 표 블록을 표준 출력으로 낸다 | 0 성공, 2 파일/키 없음 |
| `verify` | 마커가 있는 문서를 읽어 원시 JSON 과 대조한다 | 0 통과, 1 수치 불일치, 2 파일/키 없음 |

마커 형식:

```markdown
<!-- METRICS_BEGIN json=<json_path> hash=<sha256_hex> -->
| 지표 | 값 |
| --- | ---: |
| `key.path` | value |
<!-- METRICS_END -->
```

- JSON 경로와 SHA-256 해시가 마커에 기록된다.
- verify 는 해시 불일치와 수치 불일치를 각각 보고한다.
- 마커가 없는 문서는 검사 대상에서 제외된다 (통과 처리).
- JSON 부재 혹은 키 경로 없음은 종료 코드 2 로 fail-closed 처리한다.

### 2.2 `scripts/validate_agent_rules.py` 변경

`check_analysis_metrics_docs()` 를 추가하고 `get_all_checks()` 에 등록했다.
`docs/analysis/` 전체를 훑어 `METRICS_BEGIN` 마커가 있는 문서마다 `verify` 를 돈다.
