## 적용 내용

- `scripts/validate_agent_rules.py`가 `.pre-commit-config.yaml`의 `stages`를 동적으로 읽습니다.
- 각 stage에 대응하는 Git 훅 파일의 실존과 실행 권한을 검사하며, 실패 시 설치 명령을 출력합니다.
- CI 표준 환경변수 `CI=true`에서는 로컬 훅 설치 검사를 건너뜁니다.
- `scripts/orca_prepare_worktree.py`는 모든 stage 훅을 주 저장소 기준으로 확인·설치합니다.
