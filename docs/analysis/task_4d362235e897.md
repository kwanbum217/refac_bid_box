## 1. 개요 및 목적

코디네이터가 Orca 정본 스킬(`orca skills get orchestration`)을 확인하지 않고 워커를 띄우거나 낡은 지침을 기준으로 저수준 경로를 수동 조립하는 실패를 기계적으로 차단하기 위해 **2층 방어 체계(2-Layer Defense Gate)**를 구축했습니다.

- **1층 (자동 주입 및 발급)**: 코디네이터 세션 시작 시 `.claude/settings.json` 의 `SessionStart` 훅을 통해 `python3 scripts/orca_skill_receipt.py issue || true` 를 자동 실행합니다. 런타임 미가동 시에도 세션 진입을 방해하지 않는 fail-open 정책을 적용합니다.
- **2층 (엄격 검증 게이트)**: `scripts/orca_taskctl.py` 의 `create` 및 `dispatch` 서브커맨드 실행 시, 발급된 정본 영수증의 유효성(`sha256`, `appVersion`, 코디네이터 세션 핸들)을 실시간 런타임 상태와 대조하여 불일치 시 종료 코드 `4`로 즉시 거부하는 fail-closed 정책을 적용합니다.

## 2. 세부 구현 내역

### 2.1 1층: 세션 시작 훅 (`.claude/settings.json`)

기존 `enabledPlugins` 구성을 완전하게 보존하면서 `SessionStart` 훅을 추가했습니다.

- **설정 파일**: [`.claude/settings.json`](../../.claude/settings.json)
- **훅 명령**: `python3 scripts/orca_skill_receipt.py issue || true`
- **동작 특성**: Orca CLI 부재 또는 런타임 정체 시에도 세션 기동이 차단되지 않도록 `|| true` 로 처리했습니다.

### 2.2 2층: 정본 영수증 발급 및 검증기 (`scripts/orca_skill_receipt.py`)

- **스크립트 경로**: [`scripts/orca_skill_receipt.py`](../../scripts/orca_skill_receipt.py)
- **영수증 파일 위치**: `.orca/skill_receipt.json` (Git 미추적)
- **영수증 스키마 (`ORCA_SKILL_RECEIPT_V1`)**:
  - `canonical_command`: `orca skills get orchestration`
  - `sha256`: 발급 시점의 정본 스킬 본문 SHA-256 해시
  - `app_version`: 발급 시점의 Orca 런타임 버전 (`result.runtime.appVersion`)
  - `coordinator_handle`: 발급 코디네이터 터미널 핸들 (`ORCA_TERMINAL_HANDLE` 또는 `run-current`)
  - `issued_at`, `issued_at_iso`, `content_bytes`, `content_chars`
- **검증 규칙 (fail-closed)**:
  - 영수증 부재 또는 JSON 파싱 오류 시 거부.
  - 실시간 `orca status --json` 의 `appVersion` 과 영수증의 `app_version` 불일치 시 거부.
  - 실시간 `orca skills get orchestration` 의 SHA-256 해시와 영수증의 `sha256` 불일치 시 거부.
  - 영수증의 `coordinator_handle` 과 현재 세션 핸들 불일치 시 타 세션 영수증 재사용으로 간주하여 거부 (핸들 조회 불가 환경에서는 해당 검사만 건너뜀).
- **단일 해소 명령**: 모든 거부 상황에서 `python3 scripts/orca_skill_receipt.py issue` 를 출력.

### 2.3 제어 평면 게이트 통합 (`scripts/orca_taskctl.py`)

- **적용 서브커맨드**: `create`, `dispatch` (워커 기동과 관련된 두 명령에만 엄격 적용, `expand`, `finalize`, `status` 등은 제외).
- **종료 코드 규약**:
  - `0`: 성공
  - `1`: 워커 기동 실패, 동시 쓰기 상한 초과, 잔류 세션
  - `2`: 인자/계약 오류
  - `3`: 지시 도달 미확인
  - **`4`**: 정본 스킬 영수증 부재/불일치/만료로 거부
- **단일 우회 플래그**: `--skip-skill-receipt` (사용 시 stderr 경고 및 Dispatch 기록 보존, 환경변수 우회 없음).

### 2.4 규칙 검증기 포인터 정합성 검사 (`scripts/validate_agent_rules.py`)

- **추가 검사**: `check_canonical_skill_pointer`
- **검증 내용**: `.agents/skills/orca-section-coordination/SKILL.md` 0장에 정본 명령 `orca skills get orchestration` 이 정확히 명시되어 있는지 기계적으로 검증.
- **총 검사 수**: 17건에서 18건으로 확장 (`검증 통과: 18/18 건`).
