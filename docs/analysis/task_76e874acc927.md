## 1. 개요 및 배경

2026-09-07 세션에서 상시 감시기(`scripts/orca_worker_watch.py`)가 정상 작업 중인 워커를 "Antigravity 부팅이 인증 단계에서 정체"로 표시하는 오판이 발생했습니다. 코디네이터가 터미널을 직접 확인한 결과, 이는 워커 부팅 초기 출력에 남은 문자열이 스트림 버퍼에 유지되어 발생한 가탐(False Positive)이었습니다.

### 1.1 원인 분석
- `scripts/orca_worker_watch.py`의 `terminal_tail`이 `orca terminal read --terminal <handle>`을 `--screen` 플래그 없이 호출했습니다.
- `--screen`이 없는 호출은 렌더링된 화면이 아닌 누적 스트림(accumulated stream)을 반환하므로, 부팅 시점에 한 번 출력된 문자열이 워커가 작업 중이더라도 마지막 `TAIL_LINES` 버퍼에 남아 차단으로 오판되었습니다.

## 2. 해결 방안 및 설계 계약

| 구분 | 변경 전 | 변경 후 |
| --- | --- | --- |
| **기본 경로** | 누적 스트림 출력 (`orca terminal read`) | 렌더링된 화면 (`orca terminal read --screen --json`) |
| **판정 기준** | 최근 15줄 누적 텍스트 | 렌더링된 화면 버퍼 (지나간 스크롤백 검사 배제) |
| **Fallback 경로** | 없음 | `screen-unavailable`, source 부재, 호출 실패 시 누적 출력 fallback |
| **Fallback 조건** | 단일 관측 시 차단 판정 | 짧은 간격(기본 3초)을 두고 **2회 연속 동일 신호 관측** 시에만 차단 판정 |
| **신호 부재 시 처리** | 1회 조회 | 신호가 없으면 재확인 sleep 및 2회차 조회 즉시 생략 (루프 지연 방지) |
| **판정 근거 표시** | 표시 없음 | 사람 출력(`format_worker_state`) 및 JSON(`blocked_source`)에 화면 여부 명시 |
| **종료 코드 및 기타** | 정상 0 / 차단 1 | 규약 100% 보존, reclaim 및 answer_pending 판정 경로 변경 없음 |

## 3. 세부 구현 내역

### 3.1 `scripts/orca_worker_watch.py`
1. **설정 상수 추가**:
   - `DEFAULT_FALLBACK_RECHECK_DELAY_SECONDS: float = 3.0`
   - `FALLBACK_RECHECK_DELAY_SECONDS: float = 3.0` (주입 가능)
   - `FALLBACK_RECHECK_ENABLED: bool = True` (주입 가능)
2. **`read_terminal_screen(handle)` 함수 구현**:
   - `orca terminal read --terminal <handle> --screen --json` 실행
   - `result.terminal.source`와 `tail` 파싱 및 ANSI 이스케이프 제거
   - `(source, content)` 반환 (`source`: "screen", "screen-unavailable", "stream", "")
3. **`inspect_terminal_block(...)` 함수 구현**:
   - 1차: `read_terminal_screen` 호출. `source == "screen"`이면 렌더링된 화면만으로 `detect_block` 수행 후 `((reason, fix, kind), "screen")` 반환.
   - 2차(Fallback): 화면을 얻지 못하면 누적 출력 마지막 `TAIL_LINES` 줄에 대해 1회차 `detect_block` 수행.
   - 신호가 없으면 재확인 없이 즉시 `None` 반환.
   - 신호가 있으면 `FALLBACK_RECHECK_DELAY_SECONDS` 대기 후 `terminal_tail` 재조회 및 2회차 `detect_block` 수행.
   - 동일 신호가 2회 연속 지속될 때만 `((reason, fix, kind), "stream_fallback")` 반환.
4. **`WorkerState` 및 출력 서식 개선**:
   - `blocked_source: str | None` 필드 추가.
   - `as_dict()`에 `"blocked_source"` 직렬화 포함.
   - `format_worker_state`에 `근거: 화면` 및 `근거: 누적 출력 fallback (화면 아님, 2회 연속 관측)` 명시.
   - Fallback 차단 시 `notes`에 화면 미제공 및 2회 연속 관측 사실 기록.
   - `collect`에 `sleep_func` 인자 추가 및 `watch_loop` 연동.

### 3.2 `tests/test_orca_worker_watch.py`
1. 기존 테스트의 터미널 읽기 모킹을 `read_terminal_screen`으로 갱신하여 subprocess CLI 호출 방지 및 실행 속도 최적화 (6.58s -> 0.46s).
2. 필수 계약에 대한 5대 테스트 케이스 추가 (모두 mock 기반, 실제 orca CLI 미호출):
   - `test_screen_path_detects_block_signal`: 화면 경로 차단 신호 검출 및 `blocked_source="screen"` 검증.
   - `test_screen_path_ignores_boot_string_absent_from_screen`: 화면에 없고 누적 출력에만 남은 부팅 정체 문자열 오판 방지 검증.
   - `test_screen_unavailable_single_observation_is_not_blocked`: screen-unavailable 시 1회 관측 후 신호 해제 시 차단 미판정 검증.
   - `test_screen_unavailable_two_consecutive_observations_is_blocked`: screen-unavailable 시 2회 연속 관측 시 차단 판정 및 fallback 근거 검증.
   - `test_fallback_block_evidence_labeled_in_output_and_json`: fallback 차단 시 사람 출력 및 JSON 직렬화에 근거 레이블 표시 검증.
