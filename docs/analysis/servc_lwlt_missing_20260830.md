## 6. 추정 대체(Imputation)의 타당성 및 위험성 실측

### 6.1 보유 집단 하한율의 기관별 가변성

보유 집단(2,233건)의 낙찰하한율은 88.0%(61.6%), 90.0%(15.9%), 87.745%(8.4%), 86.745%(2.6%) 등 총 26개 고유값으로 분산되어 있습니다.
- 발주기관 843개 중 **23.8%(201개)**는 동일 기관 내에서도 공고마다 하한율이 변동(표준편차 최대 7.03%p)합니다. 발주기관만으로 하한율을 단일 상수로 매핑할 수 없습니다.

### 6.2 인위적 추정값 주입 시 발생하는 왜곡과 위험

결측 1,356건의 실제 낙찰률은 평균 **94.95%** (중앙값 96.37%, 95% 이상이 55.8%)에 형성되어 있습니다.
- 만약 이들 공고에 적격심사 기준인 `88.0%` 또는 평균 `88.666%`를 가상 하한율로 주입할 경우:
  - 모델은 `lwlt_rate = 88.0` 및 `lwlt_rate_missing = 0.0`을 입력받아 낙찰률을 88% 근처로 예측하게 됩니다.
  - 실제 낙찰률(95%~100%)과의 차이로 인해 **오차가 7%p~12%p로 폭증**하며 모델의 신뢰성을 완전히 파괴합니다.
- 결측 1,356건 중 실제 낙찰률이 88.0% 이하인 공고는 **7.67%(104건)**에 불과합니다.

**판정**: 존재하지 않는 낙찰하한율을 임의로 추정·대입하는 것은 데이터의 실제 물리적 생성 원리를 위반하는 심각한 왜곡이며, **추정 대체는 절대 불가(Prohibited)**합니다.

## 7. 최종 결론 및 권고 사항

1. **보전 경로 판정**: **"보전 경로 없음 (False Path)"**
   - 결측 1,356건은 수집 실패가 아니라 계약 제도의 본질적 차이(수의시담, 규격가격동시, 협상계약)에서 기인합니다.

### 8.1 OOS 표본 및 결측 특성 분석 재현
임시 스크립트(`/tmp/verify_servc_lwlt.py`)를 통해 아래 쿼리를 재현할 수 있습니다:
```python
import json
import pandas as pd
from sqlalchemy import text
from src.app.core.db import engine

sql = '''
SELECT
    a.id AS bid_id,
    a.bid_ntce_no,
    a.bid_ntce_ord,
    a.category,
    a.presmpt_prce,
    a.dminstt_nm,
    a.cntrct_mthd_nm,
    a.raw_data,
    r.rl_openg_dt AS openg_dt,
    r.sucsf_bid_rate AS actual_rate
FROM bid_announcements a
JOIN bid_results r
  ON a.bid_ntce_no = r.bid_ntce_no
 AND a.bid_ntce_ord = SUBSTR(CONCAT('000', r.bid_ntce_ord), -3, 3)
 AND a.category = r.category
WHERE a.category = 'Servc'
  AND r.rl_openg_dt > '2026-08-03 11:00:00'
  AND r.sucsf_bid_rate IS NOT NULL
  AND r.sucsf_bid_rate BETWEEN 70 AND 110
  AND r.sucsf_bid_amt IS NOT NULL
  AND a.presmpt_prce BETWEEN 100000 AND 1000000000000
ORDER BY r.rl_openg_dt ASC, a.bid_ntce_no ASC, a.bid_ntce_ord ASC
'''
df = pd.read_sql(text(sql), engine)
raws = [json.loads(r) if r else {} for r in df['raw_data']]
df['sucsfbidLwltRate'] = [r.get('sucsfbidLwltRate') for r in raws]
df['sucsfbid_mthd_nm'] = [r.get('sucsfbidMthdNm') or '(없음)' for r in raws]
df['prearng_mthd'] = [r.get('prearngPrceDcsnMthdNm') or '(없음)' for r in raws]

def is_missing(val):
    if val in (None, '', 0, '0'): return True
    try: return float(val) == 0.0
    except: return True

df['missing_lwlt'] = df['sucsfbidLwltRate'].apply(is_missing)
print('결측 1,356건 낙찰방법별 분포:')
print(df[df['missing_lwlt']]['sucsfbid_mthd_nm'].value_counts())
```
