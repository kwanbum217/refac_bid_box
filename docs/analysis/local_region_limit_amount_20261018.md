```sql
WHERE b.category = 'Servc'
  AND b.bid_ntce_dt >= '2022-11-15'  -- 기간 시작 (기간별로 조정)
  AND b.bid_ntce_dt < '2023-01-01'   -- 기간 끝 (기간별로 조정)
  AND g.rgn_cd LIKE '29%'
  AND b.raw_data LIKE '%ub099030001%'
  AND b.presmpt_prce IS NOT NULL
  AND b.presmpt_prce >= 330000000     -- 적용 경계 (기간별로 330000000 또는 350000000)
  AND b.presmpt_prce < 500000000;
```

- 2022-11-15 ~ 2022-12-31: `bid_ntce_dt >= '2022-11-15' AND bid_ntce_dt < '2023-01-01'`, 경계 `330000000` → 1건
- 2023-01-01 ~ 2024-12-31: `bid_ntce_dt >= '2023-01-01' AND bid_ntce_dt < '2025-01-01'`, 경계 `330000000` → 42건
- 2025-01-01 ~ 2026-07-16: `bid_ntce_dt >= '2025-01-01' AND bid_ntce_dt < '2026-07-17'`, 경계 `350000000` → 35건

- 집계 기준: `g2b_demand_institutions`의 `rgn_cd`가 `29`로 시작하는 수요기관(광주광역시)만 선택했습니다. `dminstt_nm LIKE '%광주%'`는 경기도 광주시를 섞으므로 사용하지 않았습니다.
- 적격심사 공고 판별은 `raw_data`의 `sucsfbidMthdCd`가 `낙030001`인 공고만 셌습니다. `bid_ntce_nm`에 "적격심사" 문자열이 들어 있는지로 판별하지 않았습니다.
- `presmpt_prce`가 없는 공고는 제외했습니다.

## 7. 판정

- verdict: `candidate`
- blocking_issues: `[]`
- 원문 미확보·접속 실패·근거 0건은 조사 결과이며 차단 사유가 아닙니다.
- 내려받은 원문은 `.cache/` 아래에 두었고 커밋하지 않았습니다.
- 코드는 고치지 않았습니다. `1억원` 경계(`100000000`)는 원문과 일치합니다.
- 금액은 고시 원문에서 옮겼습니다. 저장소 분석 문서나 상업 페이지를 금액 근거로 쓰지 않았습니다.
