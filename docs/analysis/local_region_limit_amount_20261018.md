| `SERVC_LOCAL_GWANGJU_20221115_ATTACH_1_5` 경계 (`upper_bound`) | 500,000,000원 (5억원) | 330,000,000원 (2022~2024) / 350,000,000원 (2025~) | 불일치 (코드는 고시 금액이 아닌 5억으로 고정) |

코드는 두 규칙 모두 500,000,000원으로 고정 등록했습니다. 고시 원문이 정한 `지역제한 금액`은 3.3억/3.5억이므로, 코드의 5억 고정값은 원문 대조만으로는 검증할 수 없는 해석적 변환입니다. `1억원` 경계(`100000000`)는 원문과 일치합니다.

코드는 고치지 않았습니다(범위 밖). 본 문서는 조사 결과만 기록합니다.

## 6. 영향 공고 건수

> 2026-10-18 코디네이터 재집계로 교체했습니다. 이전 판의 78건은 자치구 공고와 같은 공고의 여러 차수를 함께 셌고, 수요기관 이름으로 조인했습니다.

집계 방법: `scripts/report_rule_coverage.py` 의 `_load_institutions`·`_to_record`(원장과 같은 판정 경로)를 그대로 써서, 2022-11-15 이상 2026-07-16 미만 `Servc` 공고를 단일 스트림 질의로 읽었습니다. `raw_data` 의 `sucsfbidMthdCd` 가 `낙030001` 이고 `dminsttCd` 가 `g2b_demand_institutions.rgn_cd` 29 계열인 공고만 남기고, 같은 `bid_ntce_no` 는 최신 차수 하나만 셌습니다. 판정 결과 규칙이 광주 구판 두 규칙인 공고만 갈래로 나눴습니다. 갈래는 수요기관 소관구분과 공고 당시 수요기관명의 자치구명 접두로 정했습니다. 경계는 공고일 2025-01-01 전 330,000,000, 이후 350,000,000 입니다.

```sql
SELECT bid_ntce_no, bid_ntce_ord, bid_ntce_dt, category, dminstt_nm, cntrct_mthd_nm,
       presmpt_prce, raw_data
FROM bid_announcements
WHERE category = 'Servc'
  AND bid_ntce_dt >= '2022-11-15'
  AND bid_ntce_dt < '2026-07-16'
```

| 갈래 | 광주 구판 규칙 공고 | 추정가격이 [고시 금액, 5억) | 해당 수요기관 |
| --- | ---: | ---: | --- |
| 광역시 본청·소속기관 | 12 | 1 (2025-01-01 이후) | `6130670` 종합건설본부 1 |
| 자치구 | 0 | 0 | - |
| 교육청 소속 기관 | 12 | 8 (2025-01-01 이후) | `7140387`·`7140364`·`7140365`·`7140397` 특수학교 각 2 |
| 지방공기업 | 2 | 0 | - |

광주 지역 적격심사 용역 공고(최신 차수)는 876건이고, 그중 광주 구판 규칙(폐기물·육상운송)을 받는 공고는 26건입니다. 경계 차이로 배점 구간이 바뀌는 공고는 광역시 본청·소속기관 1건이 확정이고, 교육청 소속 8건은 3.4절 판단에 달려 있습니다. 수요기관명은 현재 원장 데이터에 `전남광주통합특별시` 명칭으로 남아 있습니다.

## 7. 판정

- verdict: `candidate`
- blocking_issues: `[]`
- 원문 미확보·접속 실패·근거 0건은 조사 결과이며 차단 사유가 아닙니다.
- 내려받은 원문은 `.cache/` 아래에 두었고 커밋하지 않았습니다.
- 코드는 고치지 않았습니다. `1억원` 경계(`100000000`)는 원문과 일치합니다.
- 금액은 고시 원문에서 옮겼습니다. 저장소 분석 문서나 상업 페이지를 금액 근거로 쓰지 않았습니다.
