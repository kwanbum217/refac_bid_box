## 1. 목적과 결론

- 목적: R1·R2 가 확정한 기관 규칙 67개는 입찰가격 축(B·k·기준비율·하한율)만 담고 있다. 평가 화면은 기관 정량배점표가 없어(`quant_basis=AGENCY_DOCUMENT_NOT_LOADED`) 정량점수 직접 입력을 요구한다. 이 문서는 10곳의 적격심사 세부기준 원문에서 **별표별 심사항목 배점한도표와 세부 평가기준(등급별 점수)** 을 기계 판독 명세로 확정한다.
- 결론: 기관 10곳, 규칙 67개, 구간(band) 136개, 별표 배점표 65개를 명세화했다. 67개 규칙 ID 는 코드 `INSTITUTION_RULES` 와 정확히 일치한다. 구간 배점 합계(신인도·결격사유 제외 + 입찰가격)는 전량 검산을 통과했다.
- 확보 등급: **완전 9곳**, **부분 1곳(한국가스공사)**. 한국가스공사는 별표 9 가 배점한도 숫자를 인쇄하지 않고 본문 제16조①에 숫자가 있으며, 입찰가격 배점한도 `B` 가 추정가격이 아니라 용역유형(계량화 정도) 축으로 갈려 단일 추정가격 축으로 확정할 수 없어 **부분**으로 둔다.
- 원문 근거가 없는 값은 넣지 않았다. 원문이 `-` 로 표기한 항목은 `limit_kind: absent`, 추측이 필요한 값은 항목 자체를 두지 않고 사유를 `note` 에 남겼다.

## 6. 코드 반영 계획 (후속 과업)

운영 코드는 바꾸지 않았다. 후속 과업이 아래 순서로 반영한다.

1. **규칙 → 별표 매핑**: `quant_score_table_for_rule`(`evaluation_rules.py:7388`)은 규칙 ID 접미사로 `QUANT_SCORE_TABLES` 를 찾는다. 기관 규칙은 접미사가 `MOLIT_20180104_GENERAL` 처럼 달라 그대로 안 맞는다. 기관 규칙 ID 로 별표를 찾는 별도 매핑(예: `rule_id → attachment`)을 명세에서 생성한다.
2. **항목 키 확장**: 조달청 항목 키(`performance`·`management`·`technical_capacity`·`labor_plan`·`reputation`·`price`·`disqualification`)에 기관 전용 키(예: `research_capacity`·`research_evaluation`·`research_base`·`staffing`·`region_hiring`·`insurance_payment_ability`)를 추가한다.
3. **B 축 처리**: 한국가스공사처럼 `B` 가 추정가격이 아니라 용역유형으로 갈리는 규칙은 `QuantScoreBand` 에 용역유형 축을 두거나, 규칙을 용역유형별로 나눈다.
4. **quant_basis 전환**: 명세를 옮긴 규칙의 `quant_basis` 를 `QUANT_BASIS_REGISTRY` 계열 기관 값으로 바꾸고, `quant_score_table_for_rule` 이 기관 표를 돌려주게 한다. 전환 전까지는 현재처럼 정량점수 직접 입력을 유지한다.
5. **검증 시험**: 명세 YAML 을 읽어 규칙·구간·항목·합계를 대조하는 단위시험(조달청 `servc_pre_rules` 를 검증하는 방식을 준용)을 추가한다. `tests/test_institution_rules.py` 가 이미 기관 규칙 YAML 을 읽으므로 그 옆에 정량표 시험을 둔다.

## 8. 남은 리스크와 후속

| 항목 | 내용 |
| --- | --- |
| 한국가스공사 B 축 | 용역유형 축 설계가 필요하다. 하한율은 R1·R2 에서 확정되어 있고 정량표의 B 만 미확정이다 |
| 입찰가격 평탄 점수 | 여러 기관이 평탄 비율만 인쇄하고 그 점수를 인쇄하지 않는다. 입찰가격 항목은 배점한도만 확정이며, 평탄 점수는 후속 코드가 산식으로 계산한다 |
| 국토교통부·환경부 부표 | 고시금액 미만 당해용역수행능력 세부항목(참여기술자 등)은 등급별 점수가 원문 부표에 있다. 항목 키 신설이 필요하다 |
| 인천국제공항공사 아웃소싱 | 별표 2·3 의 이행실적·매출액·사업관리능력 세부 기준은 별지 서식에 있으며 등급별 점수 일부만 명세에 담았다 |
| 신인도 세부표 | 대부분 기관이 별도 별표(별표 10·11·13 등)로 두어 이번 명세는 신인도 항목을 `reputation` 하나로만 표기했다. 신인도 항목별 점수표는 후속 과업 대상이다 |
