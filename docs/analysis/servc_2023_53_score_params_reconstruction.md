## 1. 판정 원칙과 직접 확인값

제2023-53호 통합본을 확보하지 못했습니다. 재구성 보고서는 제2025-257호 신구조문대비표의 '현행(제2023-53호)' 열을 직접 확인 근거로 사용하고, 대비표에 실리지 않은 항목은 개정 전문의 값을 두 판 공통으로 간주하는 전제로 채택했습니다. 그러므로 아래의 복원 채택값은 제2023-53호 공식 통합 원문을 직접 확인한 값과 구별합니다.

기존 미확정 조사에서는 공식 별표 원문을 확보하지 못해 14건 전체의 값을 확정하지 않았으며, 제2025-257호 값을 제2023-53호 확정값으로 소급 적용하지 말라고 했습니다(`docs/analysis/servc_qual_unconfirmed_params_investigation.md:144-150`). 이 표도 그 제한을 유지합니다. 여기의 B 등급은 확정값이 아니라, 지정된 재구성 보고서가 제시한 동일 추정입니다.

| --- | --- | --- |
| A | 대비표 직접 확인 | 신구조문대비표의 '현행(제2023-53호)' 열 또는 대비표가 인용한 제10조에 값이 직접 실려 있음 |

## 3. 코드 선언 가능성

- **A 등급 직접 확인 항목**: T는 14건 모두 A입니다. B는 별표 2(ATTACH_01)와 별표 1(ATTACH_06·07)의 5억원 구간값만 A입니다. ATTACH_06은 고시금액 미만 전용이므로 해당 조건 안에서 B=70입니다.
- **B 등급 동일 추정 항목**: k는 14건 모두 B입니다. 대비표가 계산식을 싣지 않아 개정 전문에서 가져온 수치입니다. 나머지 B 값도 직접 비교표에서 해당 별표 값이 확인되지 않는 행은 B입니다. B 등급 값을 제2023-53호 확정값처럼 코드에 선언하면 근거 수준을 과장합니다.
- **조건 보존**: B의 5억원 축과 k의 고시금액 축은 따로 유지합니다. 별표 8은 B=70 단일, 별표 9는 수요기관 설정값 60~70으로 적었습니다. 별표 9는 실제 수요기관 배점이 정해져야 개별 규칙값을 고를 수 있습니다.
- **C 등급**: 이 14건은 코드의 별표 귀속으로 별표별 재구성표에 연결되어 B·k·T 후보가 있으므로 C로 채운 행은 없습니다. 별표 귀속이 없는 일반 띠 ATTACH_12~14와 같은 확인불가 사례를 이 범위에 끌어오지 않았습니다.

따라서 이 표는 다음 구현 작업의 후보 매핑입니다. 공식 제2023-53호 원문 확인 전에는 B 등급 수치를 원문 확정값으로 승격하지 말고, A로 확인된 값과 동일 추정값을 선언·출처 문구에서 분리해야 합니다.
