## 3. 행 키 집합 SHA-256 결박

### 3.1 행 키 형식

```
{bid_ntce_no}:{bid_ntce_ord_3digits}:{category}
```

`bid_ntce_ord` 는 3자리 zero-padding 후 사용합니다 (`"1"` -> `"001"`).

### 3.2 해시 계산 방식

```python
sorted_keys = sorted(str(k).strip() for k in sample_keys if str(k).strip())
digest = hashlib.sha256()
for key in sorted_keys:
    digest.update(key.encode("utf-8"))
    digest.update(b"\n")
return digest.hexdigest()
```

- 키 목록을 사전순 정렬 후 `\n` 구분자로 연결하여 해시를 계산합니다.
- 입력 순서와 무관하게 동일한 행 집합이면 항상 동일한 해시가 생성됩니다.

## 4. 평가 지표 정의

### 4.1 기본 오차 지표

| 지표 | 정의 | 출처 |
| --- | --- | --- |
| MAE | `mean(|pred - actual|)` | `scripts/eval_servc_api_path.py:166` |
| RMSE | `sqrt(mean((pred - actual)^2))` | 같은 파일 |
| Bias | `mean(pred - actual)` | 같은 파일 |
| Median AE | `median(|pred - actual|)` | 같은 파일 |
| hit_rate_05 | `mean(|pred - actual| <= 0.5)` | 같은 파일 |

### 4.2 오차 밴드

`ERROR_BANDS = (0.5, 1.0, 2.0, 3.0, 5.0)`

각 밴드 b 에 대해 `count` (건수)와 `ratio` (비율)를 산출합니다.

### 4.3 예측구간 지표

| 지표 | 정의 | 명목 |
| --- | --- | --- |
| coverage | `mean(low <= actual <= high)` | 90% |
| coverage_gap | `coverage - 0.90` | - |
| median_interval_width | `median(high - low)` | - |

### 4.4 이전 측정과의 비교 기준

2025년 300건 평가 기준선 (`docs/analysis/servc_api_path_remeasurement_20260826.md`):

| 지표 | 2025년 300건 기준 |
| --- | ---: |
| MAE | 1.2686 |
| 0.5%p 적중률 | 63.33% |
| 피복률 | 89.67% |

OOS 3,589건 평가에서도 이 세 지표를 동일 계산식으로 산출해 비교합니다.

## 6. 단위 테스트 필수 항목

Capsule이 요구하는 5개 필수 테스트 (`tests/test_eval_servc_oos_champion.py`):
