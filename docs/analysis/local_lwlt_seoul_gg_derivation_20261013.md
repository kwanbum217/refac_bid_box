## 2. 역산 방법

낙찰하한율은 `가격점수 + 비가격 만점 = 통과점수` 가 되는 최저 투찰률입니다. 원문 평점산식은 기준비율 88 을 기준으로 `평점 = 배점한도 - k x |88 - 입찰가격/예정가격 x 100|` 이므로, 하한율 r 은 다음으로 닫힙니다.

```
k x (88 - r) = 100 - 통과점수
r = 88 - (100 - 통과점수) / k
```

- 배점한도 B 는 식에서 소거되므로 하한율은 B 가 아니라 평점계수 k 와 통과점수 T 로만 결정됩니다.
- 표기 관행: 소수 셋째 자리 `.995` 표기(예: 78.000 -> 77.995, 87.750 -> 87.745)를 따릅니다. 원문은 `입찰가격을 예정가격으로 나눈 결과 소수점 이하 숫자는 소수점 다섯째 자리에서 반올림`한다고 규정합니다.
- 각 별표·구간마다 원문에서 (1) 평점산식(행), (2) 비가격 만점(계 100 행 - 입찰가격 배점한도 행), (3) 통과점수(제7조·제8조 행)를 찾아 위 식에 대입합니다.

판정: 역산값과 코드 값이 같으면 `일치`, 다르면 코드를 정정하고 source 문자열을 `원문 산식 역산` 으로 바꿉니다. 원문에서 세 요소 중 하나라도 찾지 못하면 값을 바꾸지 않고 `근거 부족` 으로 적습니다. 이번 3개 규칙은 모두 세 요소를 확보해 전부 `일치` 입니다.
