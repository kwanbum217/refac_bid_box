| 판정 | 뜻 |
| --- | --- |
| 구판 있음(값 동일) | 시행일 이전 공고에 적용할 공식 구판 별표가 있고, 가격식 값이 현행과 같다 |

| 미확인 | 구판 문서 또는 별표 원문을 확보하지 못해 값 대조를 마치지 못했다 |
