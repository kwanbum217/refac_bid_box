### 2.3 2.4절 구간 레이턴시 정본 범위 한정

- **문제점**:
  - 2.4절이 sql P50 7.39ms(비중 0.19%)를 근거로 "지연의 98.8%가 vector와 llm에 몰려 있으며 최적화 대상은 이 둘뿐"이라고 기술했으나, 이는 직전 측정이 캐시를 데워놓은 warm 상태 기준임.

- **조치 사항**:
  - 2.4절 제목 및 본문에 `warm/steady-state 한정` 문구를 명시하고, 캐시 미스 시의 지연과 2.6절 링크를 상호 참조하도록 보강.
