## 2. Grok CLI 환경 및 실측 정본

- **실행 파일**: `/opt/homebrew/bin/grok` (grok 1.0.13 (5e9a58528b76) [stable], Homebrew 설치)
- **계정 상태**: SuperGrok 구독, grok.com 계정 로그인 완료
- **사용 가능 모델**: `grok-4.6` (기본값) 및 `grok-4.5` (2종만 유효)
- **단발 실행 형식**: `grok -p "<프롬프트>" --model grok-4.6 --output-format plain`
- **추론 수준**: `--effort` (별칭 `--reasoning-effort`, 값: `low`, `medium`, `high`)
- **등급 정책**:
  - `high`: 코디네이터 전용 등급 (워커 자동 배정 제외)
  - `medium`, `low`: 워커 및 리뷰어 허용 등급
  - Gemini `TIER_POLICY` 자동 배정은 불변 유지, Grok은 `WORKER_MODEL_NOTICE` 후 명시 배정으로만 운용
