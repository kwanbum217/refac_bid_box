## 2. 코드 경로

### 2.1 차단 코드가 만들어지는 지점

원장의 차단 분류는 판정 함수의 반환값을 그대로 씁니다. `scripts/report_rule_coverage.py:167-191` 의 `classify_result` 가 `is_blocked` 와 `block_reason_code` 를 `BLOCKED` 로 옮기고, `:194-198` 의 `blocked_category` 가 사용자 입력 필요(`manual_input`)와 자동 계산 불가(`not_computable`)로 나눕니다. `RULE_NOT_FOUND` 와 `RULE_REGIME_MISMATCH` 는 후자입니다.

두 코드의 생성 지점은 다음과 같습니다.

| 코드 | 생성 지점 | 의미 |
| --- | --- | --- |
| `RULE_NOT_FOUND` | `src/app/services/evaluation_rules.py:3934-3944` | 낙찰방법명이 어느 규칙 패턴과도 맞지 않음 |
| `RULE_NOT_FOUND` | `src/app/services/evaluation_rules.py:3327-3338` | 범위 축소(`_narrow_rule_scope`) 후보 없음 |
| `RULE_REGIME_MISMATCH` | `src/app/services/evaluation_rules.py:3754-3765` | 규칙은 확정됐지만 공고일이 규칙 시행일보다 앞섬 |

`evaluation_rules.py:3740-3741` 은 `is_blocked` 또는 `rule is None` 이면 그대로 반환하므로, 위 코드가 한 번 붙으면 뒤 단계에서 규칙을 확정하지 않는 한 해제되지 않습니다.

### 2.2 "2억미만 1억이상" 띠가 매칭되지 않는 이유

`RULE_NOT_FOUND` 6건 모두 낙찰방법명이 `적격심사제-추정가격 2억미만 1억이상` 입니다. 조달청 규칙 벌에는 이 문자열과 정확히 맞는 패턴이 없습니다.

- 조달청 일반용역 규칙의 띠 패턴은 `추정가격 2억원 미만인 용역`, `추정가격 5억원 미만 2억원 이상인 용역`, `추정가격 30억원 미만 15억원 이상인 용역` 입니다(`evaluation_rules.py:952-1002`, `POST_20260526_ATTACH_12~14`).
- `추정가격 2억미만 1억이상` 은 행안부 예규 제2장의2 [별표 4] 학술연구용역의 열 표기입니다. 코드는 이 띠를 `MOIS_ACADEMIC_BAND_ATTACHMENT_ONLY_RULES` 로만 두고(`evaluation_rules.py:1945-1975`), 낙찰방법명만으로는 기준 문서가 갈린다며 `select_mois_academic_band_rule` 에서 의도적으로 제외합니다(`evaluation_rules.py:2018-2029`, 특히 `:2024`).
- 이 띠를 풀 수 있는 구제 경로는 두 곳뿐인데, 둘 다 `attachment_regime` 을 요구합니다.
  - 조달청 첨부가 학술연구를 지목한 경우: `attachment_regime == "PPS"` 필요(`evaluation_rules.py:3461-3475`).
  - 행안부 첨부가 학술연구·기술용역을 지목한 경우: `attachment_regime in ("MOIS_ACADEMIC", "MOIS_TECH")` 필요(`evaluation_rules.py:3476-3497`).
- 마지막 행안부 띠 구제는 `select_mois_academic_band_rule` 을 다시 부르므로(`evaluation_rules.py:3675-3694`, 호출 `:3685`), 같은 이유로 `None` 을 받고 차단이 유지됩니다.

이 중 4건(강원·대구·강진·남원)은 학술연구 규칙이 이미 있으나 낙찰방법명 표기와 첨부 판별 갈래가 맞지 않아 선택되지 않습니다. 나머지 2건(순천)은 일반용역 2억미만 규칙 자체가 없습니다.

### 2.3 LOCAL 분기와 체제 판정

`contract_regime == "LOCAL"` 이면 조달청 매칭 결과보다 시·도 규칙을 먼저 봅니다(`evaluation_rules.py:3554-3661`). 시·도 규칙을 고르면 조달청 단계의 차단을 해제하고(`:3650-3661`), 고르지 못하면 시·도 차단 코드를 붙입니다(`:3639-3649`).

전남 분기에는 별도 예외가 있습니다. `_select_local_rule` 이 `LOCAL_RULE_NOT_FOUND` 를 돌려주고 `_is_jeonnam_local_announcement` 가 참이면 조달청 매칭 결과를 쓰도록 되어 있습니다(`evaluation_rules.py:3616-3638`). 그런데 이 분기는 `result.rule is not None` 일 때만 규칙을 좁히고, 조달청 매칭도 실패한 경우에는 **기존 `RULE_NOT_FOUND` 를 그대로 둡니다**(`:3624-3634`). 강진군 건이 이 경로입니다.

체제가 어긋나는 3건은 두 갈래입니다.

- 기관 규칙: `_select_institution_rule` 이 기관 규칙을 고르면(`evaluation_rules.py:3441-3460`) 조달청 결과를 덮어쓰고(`:3498-3507`), 마지막 시행일 대조에서 차단됩니다(`:3754-3765`).
- 시·도 규칙: `_narrow_to_current_regime` 은 같은 세부유형에 효력 구간에 드는 규칙이 없으면 시행일이 가장 늦은 현행 규칙을 남깁니다(`evaluation_rules.py:2162-2191`, 특히 `:2187-2188`). 그 규칙의 시행일이 공고일보다 뒤면 `RULE_REGIME_MISMATCH` 가 됩니다.

### 2.4 기관 체제·시·도 산출

`classify_contract_regime` 은 `jrsdctn_div_nm` 이 `기타기관` 이면 `None` 을 돌려줍니다(`src/app/services/demand_institutions.py:307-319`). 지방의료원 4곳(강원도원주·대구·남원·순천)이 이 경우입니다. `contract_regime` 이 `None` 이면 LOCAL 분기(`evaluation_rules.py:3554`)에 들어가지 않아 시·도 규칙을 아예 시도하지 않습니다.

`institution_sido` 는 `toplvl_instt_nm` 을 우선하고, 없으면 `rgn_nm` 첫 토큰을 씁니다(`demand_institutions.py:372-407`). 통합특별시 기관은 `toplvl_instt_nm` 이 통합 명칭뿐이면 `rgn_nm` 첫 토큰으로 옛 계열(46/29)을 보완합니다. 보완하지 못하면 통합 코드 12를 돌려줍니다.

통합 전 공고의 옛 계열 판별은 `_legacy_merged_institution_code` 가 맡습니다(`evaluation_rules.py:2221-2246`). 기관명에서 `전남광주통합특별시교육청` 접두를 걷어낸 뒤 남는 토큰이 광주·전남 시·군이어야 계열이 정해집니다. `AI교육원` 처럼 남는 토큰이 어느 쪽도 가리키지 않으면 `None` 이고, 통합 코드 12가 유지됩니다.
