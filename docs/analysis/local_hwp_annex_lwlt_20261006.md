## 2. 판독 방법

### 2.1 도구

| 항목 | 내용 |
| --- | --- |
| 포맷 | 5종 모두 HWP 5.x 바이너리(`file` 판정: Hangul (Korean) Word Processor File 5.x). HWPX 아님 → zipfile 경로 미사용 |
| 변환 도구 | `uvx --from pyhwp --with six hwp5html`(일시 실행). `pyproject.toml`·`uv.lock` 무변경 |
| 평문화 | `hwp5html` 산출 `index.xhtml` 에서 태그를 제거해 표 셀을 `@@ROW@@`·`|` 구분자로 평문화 |
| 구조 확인 | `olefile` 로 CFB 스트림 목록 확인(일시 실행, 의존성 미추가) |
| 대조 도구 | `uvx ... hwp5txt`(제목 식별), `grep`(문자열 전수 검색) |

`hwp5txt` 는 표 내용을 `<표>` 자리표시자로만 출력하므로, 표 칸을 직접 확인해야 하는 이 작업에는 부족합니다. 따라서 표를 실제 셀로 복원하는 `hwp5html` 산출물을 주 근거로 사용했습니다.

### 2.2 직접 판독 절차

1. 대상 HWP 를 `hwp5html` 로 변환해 표를 셀 단위로 복원합니다.
2. 복원 결과 전체에서 "하한"·"낙찰하한율"·후보 하한율 숫자를 전수 검색합니다.
3. 각 문서의 "추정가격 10억원 이상" 구간 표와 그 단서·각주·비고를 직접 인용해 확인합니다.
4. `olefile` 로 `BinData`(그림)·`BodyText`(본문 섹션) 스트림을 열거해 그림 속 표와 숨은 섹션을 확인합니다.
5. 내장 그림이 있으면 이미지로 열어 표 여부를 눈으로 확인합니다.

### 2.3 판정 등급

| 확인 | 원본 표 셀·행 또는 각주를 직접 인용해 10억원 이상 하한율이 존재함을 보임 |
| 부재 확인 | 원본 문서 전체(표 칸·각주·비고·그림)를 읽어 10억원 이상 하한율이 없음을 보임 |

## 5. 낮은 구간 하한율 대조표

원본 별표는 10억원 이상 구간뿐 아니라 **어느 구간에도 낙찰하한율을 인쇄하지 않습니다.** 원본에 인쇄된 것은 구간별 배점한도(B)·평점계수(k)·투찰률 단서입니다. 따라서 코드가 10억원 미만 구간에 넣은 값은 자치법규 원문이 아니라 공고 실측입니다.

| 지역 | 원본에 인쇄된 낮은 구간 하한율 | 원본 인쇄값(구간별 배점·단서) | 코드 10억원 미만 값(공고 실측) | 일치 여부 |
| --- | --- | --- | --- | --- |
| 인천 | 없음(미인쇄) | 5억~10억: B50·k2·90.5% 단서 / 2억~5억: B70·k4·89.25% / ~2억: B90·k20·88.25% | 85.495·86.745·87.745 | 원문 대조 불가(원문 미인쇄) |
| 제주 | 없음(미인쇄) | 5억~10억: B50·k2·90.5% 단서 / 2억~5억: B70·k4·89.25% / ~2억: B90·k20·88.25% | 85.495·86.745·87.745 | 원문 대조 불가(원문 미인쇄) |
| 강원 | 없음(미인쇄) | 5억~10억: B50·k2·90.5% 단서 / 2억~5억: B70·k4·89.25% / ~2억: B90·k20·88.25% | 85.495·86.745·87.745 | 원문 대조 불가(원문 미인쇄) |
| 경북 | 없음(미인쇄) | 5억원 이상: B50·k4·89.25% 단서 / 5억원 미만: B70·k20·88.25% 단서 | 85.495·86.745·87.745 | 원문 대조 불가(원문 미인쇄) |

원본에 인쇄된 투찰률 단서(98%·90.5%·89.25%·88.25%)는 평점 상한(만점 근처) 기준이며 낙찰하한율이 아닙니다. 추정·역산 금지 원칙에 따라 원문 미인쇄 값을 공고 실측으로 채우지 않았습니다.

## 9. 남은 리스크

| 항목 | 내용 |
| --- | --- |
| 판본 표기 | 제주·강원 HWP 별표에는 개정일이 인쇄되지 않아, 본문·부칙의 시행일(제주 `[시행 2024.01.01]`, 강원 "2023년 6월 11일부터 시행")로 코드 `effective_date` 와 대조했습니다. 별표 자체의 개정 판을 인쇄일로 직접 확정하지는 못했습니다. |
| 경남 공고번호 | `gn_general.hwp` 본문에 "경상남도 공고 제2023- 호" 로 공고번호가 공란입니다. 코드 `source` 의 "공고 제2023-23호" 와 문서 내 인쇄로는 대조하지 못했습니다. |
| 그림 속 표 | 5종 중 내장 그림은 경남 로고 1건뿐이었습니다. 원본 제작 과정에서 별표 표가 그림으로 삽입된 흔적은 없으나, 원본 자체가 표를 그림으로 대체했을 가능성은 이 판독으로는 배제하지 못합니다. |
| 공고 실측과 원문 불일치 | 원문이 하한율을 인쇄하지 않으므로 공고 실측 최빈값과 원문을 직접 대조할 수 없습니다. 실제 입찰에서는 공고 `sucsfbidLwltRate` 가 우선합니다. |

## 부록 A. 재현 명령

```
# 표를 포함한 HTML 로 복원(의존성 미추가, 일시 실행)
uvx --from pyhwp --with six hwp5html --output=<출력디렉터리> "<대상>.hwp"

# CFB 스트림(그림·본문 섹션) 확인
uv run --no-project --with olefile python3 streams.py "<대상>.hwp"

# 제목 식별
uvx --from pyhwp --with six hwp5txt "<대상>.hwp"
```

`hwp5txt` 는 표 내용을 `<표>` 자리표시자로만 출력합니다. 표 칸을 확인하려면 `hwp5html` 산출 `index.xhtml` 의 `<table>`·`<td>` 를 평문화해 검색해야 합니다.
