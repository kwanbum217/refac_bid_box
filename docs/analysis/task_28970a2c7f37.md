## 1. 개요 및 목적

### 1.1 배경
Section F3 실측(`task_f3_ngram_fulltext_probe.md`)에서 10개 대표 표본 키워드와 50개 케이스에 대해 MySQL 8 `ngram` FULLTEXT 인덱스와 기존 `LIKE` 결과가 100% 일치함을 확인하고, `dminstt_nm`(수요기관명) 및 `bidwinnr_nm`(낙찰업체명) 집계 쿼리에 대해 최대 18.99배의 성능 개선을 관측했습니다.

그러나 F3 검증에 사용된 10개 표본은 모두 **2글자 이상 순수 한글 토큰**이었습니다. 실제 공공조달 데이터에는 공백, 괄호, 하이픈, 슬래시, 영문/숫자 혼합, 유니코드 조합형(NFD), LIKE 와일드카드(%, _), FULLTEXT 불리언 모드 연산자(+, -, *, ") 등 다양한 경계값 문자열이 존재합니다.

`MATCH(...) AGAINST(...) AND col LIKE '%...%'` 형태의 선행필터 결합 방식은 `LIKE` 결과의 부분집합을 반환하므로, 토큰화 불일치나 연산자 오류 발생 시 예외(Exception)가 아닌 **조용한 누락(Silent Omission)**으로 이어져 일반적인 단위 테스트로는 검출하기 극히 어렵습니다. 또한 CI 환경(SQLite 인메모리)에서는 MySQL `ngram` 파서와 collation을 검증할 수 없습니다.

### 1.2 목적 및 범위
1. **경계값 및 기준선 키워드 픽스처 구축**: 14개 필수 경계값 클래스와 F3 기준선 10개 키워드를 포괄하는 표준 픽스처 정의.
2. **동등성 검증 회귀 하네스 구현**: 식별자 집합(Set of IDs) 기반 비교, 1글자 한글 토큰의 구조적 누락 관측 및 안전성 검증, CI 상시 실행 단위 테스트 및 MySQL 8 통합 테스트 구현.
3. **운영 스키마 안전 격리 보장**: 운영 스키마(`procurement`)에 대한 DDL 실행 0건 보장 및 애플리케이션 코드(`src/rag/structured_data.py`) 임의 변경 배제.

## 3. 동등성 검증 하네스 아키텍처

### 3.1 하네스 핵심 원칙
1. **식별자 집합(Set of IDs) 기반 엄격 비교**:
   단순 행 수(`COUNT`) 비교의 경우 서로 다른 행들이 동일한 개수로 반환될 때 결함을 감지하지 못합니다. 본 하네스는 `set(id)` 간의 차집합(`missing_in_ngram`, `extra_in_ngram`)을 연산하여 단 1건의 누락이나 위양성도 즉시 실패로 처리하고 표본 ID를 출력합니다.
2. **구조적 누락 클래스(`single_char_hangul`) 안전망 단정 고정**:
   1글자 한글 토큰은 `ngram_token_size=2` 환경에서 `MATCH AGAINST`가 0건을 반환합니다. 하네스는 이 누락을 실제 관측하고, 1글자 입력 시 `is_safe_for_ngram == False`임을 단정(Assert)하여 향후 구현체에서 반드시 `LIKE` 단독 경로로 폴백하도록 강제합니다.
3. **운영 스키마 보호 및 명시적 Skip**:
   운영 스키마(`procurement`)에 인덱스 추가/삭제 등 어떠한 DDL도 실행하지 않으며, MySQL 연결이 없거나 FULLTEXT 인덱스가 없는 환경에서는 조용한 통과가 아닌 명시적 skip 사유를 출력합니다.

### 3.2 쿼리 패턴 규격 (F3 표준)
- **Baseline LIKE**:
  ```sql
  SELECT id FROM {table} WHERE {column} LIKE :like_pattern [AND category = :cat]
  ```
- **NGRAM + LIKE (정밀 결합)**:
  ```sql
  SELECT id FROM {table} WHERE MATCH({column}) AGAINST(:ft_query IN BOOLEAN MODE) AND {column} LIKE :like_pattern [AND category = :cat]
  ```
- **Pure NGRAM**:
  ```sql
  SELECT id FROM {table} WHERE MATCH({column}) AGAINST(:ft_query IN BOOLEAN MODE) [AND category = :cat]
  ```
