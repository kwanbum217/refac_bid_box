# served-version 조회 경로

> 작업: `task_80f95ece9335`

`ModelRegistry`의 이미 로드된 wrapper 메타데이터와 서빙 디렉터리의 `metadata.json`을 읽기 전용으로 비교합니다. 조회 경로는 `/api/v1/health/served-version`이며, 모델별 인메모리 버전·디스크 버전·일치 여부를 반환합니다.

디스크를 읽지 못하면 해당 버전을 미상으로 표시하고, 모델이 로드되지 않은 환경에서도 빈 결과를 반환합니다. 자동 리로드와 readiness 결합은 구현하지 않았습니다.
