실측 필드에는 `dminsttCd`, 유효기간, 기관명, 사업자번호, `jrsdctnDivNm`, 기관유형 대·중·소분류, `rgnCd`, `rgnNm`, 상위기관, 주소·연락처, 등록·변경일이 포함됩니다. 등록일 기준 1950년부터 2026년까지 수집한 고유 기관 코드는 102,245개였습니다. 수집 키는 코드·로그·문서에 기록하지 않습니다.

## 법령 근거와 판별 규칙

지방계약법 제2조는 지방자치단체가 체결하는 계약에 적용합니다. 교육·과학·체육 사무에서는 지방자치단체의 장을 교육감으로 보며, 지방공사·지방공단에는 지방공기업법 제64조의2 및 시행령 제57조의8에 따라 지방계약법 시행령 제7조부터 제32조까지를 준용합니다. 국가기관·공기업·준정부기관은 국가계약법 계열로 판별합니다.

| 순서 | 기관정보 조건 | 결과 |
| ---: | --- | --- |
| 1 | 대분류 `교육행정조직`, 중분류(trim 후) `시, 도교육청`, `지역교육청`, `시, 도교육청 직속기관` | LOCAL |
| 2 | 소관구분 `지방자치단체` 또는 `지방공기업` | LOCAL |
| 3 | 대분류가 초등학교·중학교·고등학교·특수학교·유치원이고 소분류(trim 후) `공립` | LOCAL |
| 4 | 소관구분 `국가기관`, `공기업`, `준정부기관`, `정부투자기관` | NATIONAL |
| 5 | 그 밖의 값 | 미상 (`None`) |

2026-10-03 에 미상 범주를 재분해하고 법적 적용범위를 검토했습니다. 같은 수요기관 분류값에 서로 다른 설립근거·법률상 예외가 섞여 있어 추가로 안전하게 적용할 수 있는 규칙을 확정하지 못했습니다. 상세 분해표와 검토 근거는 [미상 범주 조사](demand_institution_regime_unknown_20261003.md)를 참조하십시오.

국립·사립 학교와 고등교육기관, 기타기관·기타공공기관, 지자체 출자출연기관, 미수집 기관은 `None`으로 유지합니다. 기관유형 소분류에는 값 오염이 확인됐습니다. 사립 가톨릭관동대학교가 `국립`, 공립 서울정목초등학교도 `국립`으로 적힌 사례가 있어 학교 소분류만으로 NATIONAL을 추정하지 않습니다.

### 실측 분포 및 코드 선택

2025-01-01 이후 용역 공고 372,766건에서 수요기관 코드(`raw_data.dminsttCd`) 고유값은 15,002개였습니다. 이 중 14,681개 기관이 매칭됐고, 공고 370,723건(99.45%)에 기관 정보가 있었습니다. 계약 주체에 해당하는 수요기관 코드를 사용하며 발주기관 코드 `ntceInsttCd`는 사용하지 않습니다.

| --- | ---: | ---: |
| LOCAL | 176,585 | 47.4% |
| NATIONAL | 84,968 | 22.8% |
| None | 111,213 | 29.8% |

## 적용 지점과 운영 적재

수요기관 테이블 `g2b_demand_institutions`에 기관코드별 정보를 멱등 upsert하고, 변경일 증분 수집은 `max(chg_dt)` 하루 전부터 다시 조회해 경계 시각의 누락을 줄입니다. 적격심사 API는 공고당 `dminsttCd`로 한 번 조회한 기관의 법령 판정과 `rgnCd`·`rgnNm`을 판정 문맥과 스냅샷에 전달합니다. 계약방법명에 `지방`이 포함되면 그 값이 우선이며, 그렇지 않으면 기관 판정을 사용합니다. 복수예가는 LOCAL이면 ±3%, 기관 미상이나 미수집이면 기존 동작대로 ±2%입니다.

수동 명령은 `uv run python scripts/collect_demand_institutions.py --mode full --dry-run`으로 API 파싱·집계를 확인하고, 실제 적재는 `--mode full`로 수행할 수 있습니다. 정기 증분은 매일 01:30 Arq 작업으로 등록돼 있으며 전용 인증키가 비어 있으면 건너뜁니다. 운영 DB 적용, 최초 전체 적재 및 G1 기준선 재생성은 리뷰 후 코디네이터가 수행합니다.
