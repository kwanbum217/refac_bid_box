## 1. 개요 및 배경

기존 `scripts/orca_auto_approve.py`는 `SAFE_PREFIXES` 튜플을 기반으로 명령 문자열 접두사를 단순 매칭하여 자동 승인을 수행했습니다.
이로 인해 `python3`, `git`, `find`, `npm`, `cp`, `mv`, `docker compose exec` 등이 접두사로 포함된 파괴적 명령(`git clean -fdx`, `git branch -D`, `find . -delete`, `python3 -c "..."`, `npm run build` 등)이 자동 승인될 위험이 존재했습니다.

본 작업에서는 접두사 매칭 방식을 완전히 제거하고, `shlex.split()` 기반의 인자(argv) 파싱과 명시적 정책 테이블 화이트리스트 및 Fail-Closed 원칙을 적용한 순수 함수 `classify_command`로 전면 개편했습니다.

3. **`shlex.split()` argv 파싱**: 파싱 실패(`ValueError` 등 따옴표 미완료) 시 즉시 `("hold", "명령 파싱 실패")` 반환.
