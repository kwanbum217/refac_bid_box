## 2. 변경 사항 상세

### 2.1 scripts/build_generalization_fixture.py
1. **전용 예외 클래스 정의**:
   - `ChromaLoadError(RuntimeError)` 추가.
2. **`load_chroma_embedding_ids` fail-closed 전환**:
   - `chroma_db_path: Path | str | None = None` 인자 추가.
   - DB 파일 부재 시 `ChromaLoadError("Chroma DB 파일이 존재하지 않습니다: ...")` 발생.
   - sqlite3 연결 실패 시 `ChromaLoadError("Chroma sqlite DB 연결 실패 (...): ...")` 발생.
   - 쿼리 실행 실패 시 `ChromaLoadError("Chroma DB 쿼리 실행 실패 (...): ...")` 발생.
   - 정상 조회 결과만 `set[int]`로 반환 (유효 근거가 0건이면 `set()`).
3. **`fetch_candidates_from_db` truthiness 판정 제거**:
   - `if chroma_ann_ids and ann_id not in chroma_ann_ids:` -> `if chroma_ann_ids is not None and ann_id not in chroma_ann_ids:` 로 수정.
   - Chroma 조회 결과가 유효 근거 0건(`set()`)인 경우 후보가 0건으로 엄격히 필터링됨.
4. **`build_fixture_v2` 명시적 제어 도입**:
   - `chroma_db_path`, `chroma_ann_ids`, `skip_chroma_filter: bool = False` 파라미터 추가.
   - 기본 호출 시 Chroma 검증을 반드시 거치며, 실패 시 `ChromaLoadError`로 fail-closed 중단.
   - Chroma 검증을 건너뛰는 경우는 명시적 플래그(`skip_chroma_filter=True`) 지정 시에만 허용.
