## 1. 조사 범위와 재현 질의

미상 모집단은 2025-01-01 이후 `category='Servc'` 공고를 `raw_data.dminsttCd`로 `g2b_demand_institutions`에 연결하고 기존 `classify_contract_regime` 조건을 SQL로 옮겨 None만 남긴 것입니다. 아래 두 질의는 모두 읽기 전용이며 `uv run python scripts/db_readonly_query.py --sql "<SQL>" --format json`으로 재실행합니다.

공통 CTE(이하 `Q0`):

```sql
WITH bids AS (
    SELECT JSON_UNQUOTE(JSON_EXTRACT(raw_data, '$.dminsttCd')) AS dminstt_cd,
           COUNT(*) AS n
    FROM bid_announcements
    WHERE bid_ntce_dt >= '2025-01-01' AND category = 'Servc'
    GROUP BY 1
)
```

`Q1`(모집단 규모, 아래 모든 기관 수·공고 수의 기준):

```sql
SELECT COUNT(*) AS institution_n, SUM(b.n) AS bid_n,
       SUM(b.dminstt_cd IS NULL OR b.dminstt_cd = '') AS null_cd_bid_n
FROM bids b
LEFT JOIN g2b_demand_institutions di ON di.dminstt_cd = b.dminstt_cd
WHERE CASE
    WHEN di.dminstt_cd IS NULL THEN 1
    WHEN TRIM(di.instt_ty_lrgclsfc_nm) = '교육행정조직'
     AND TRIM(di.instt_ty_midclsfc_nm) IN ('시, 도교육청','지역교육청','시, 도교육청 직속기관') THEN 0
    WHEN TRIM(di.jrsdctn_div_nm) IN ('지방자치단체','지방공기업') THEN 0
    WHEN TRIM(di.instt_ty_lrgclsfc_nm) IN ('초등학교','중학교','고등학교','특수학교','유치원')
     AND TRIM(di.instt_ty_smlclsfc_nm) = '공립' THEN 0
    WHEN TRIM(di.jrsdctn_div_nm) IN ('국가기관','공기업','준정부기관','정부투자기관') THEN 0
    ELSE 1 END = 1
```

실행 결과는 `institution_n=7425`, `bid_n=111565`, `null_cd_bid_n=0`입니다. 이 값은 대조 입력 파일 `.orca/capsules/task_b501ccbe7f74/external/unknowns.json`(기관 7,425행, 공고 합계 111,565건)과 정확히 일치합니다. 선행 문서가 쓴 미상 111,559건과는 6건 차이가 있습니다. 독립 리뷰에서 선행 질의를 다시 실행해도 미상이 111,565건으로 같아 두 질의는 논리상 동등했고, 같은 기간 전체 공고가 373,825건에서 373,833건으로 8건(LOCAL +2, 미상 +6) 늘어난 것이 차이의 원인입니다. 질의 조건 차이가 아니라 그 사이 수집분 증가입니다. 이 문서는 명시한 `Q1`의 111,565건을 기준값으로 씁니다.

`Q2`(대조 입력이 되는 기관 단위 덤프, 이 질의 출력이 `unknowns.json`):

```sql
SELECT b.dminstt_cd, di.dminstt_nm,
       COALESCE(NULLIF(TRIM(di.jrsdctn_div_nm), ''), '') AS juris,
       COALESCE(NULLIF(TRIM(di.instt_ty_lrgclsfc_nm), ''), '') AS large,
       COALESCE(NULLIF(TRIM(di.instt_ty_midclsfc_nm), ''), '') AS middle,
       COALESCE(NULLIF(TRIM(di.instt_ty_smlclsfc_nm), ''), '') AS small,
       JSON_UNQUOTE(JSON_EXTRACT(di.raw_json, '$.bizno')) AS bizno,
       di.toplvl_instt_nm AS parent_name,
       b.n AS bid_n
FROM bids b
LEFT JOIN g2b_demand_institutions di ON di.dminstt_cd = b.dminstt_cd
WHERE CASE
    WHEN di.dminstt_cd IS NULL THEN 1
    WHEN TRIM(di.instt_ty_lrgclsfc_nm) = '교육행정조직'
     AND TRIM(di.instt_ty_midclsfc_nm) IN ('시, 도교육청','지역교육청','시, 도교육청 직속기관') THEN 0
    WHEN TRIM(di.jrsdctn_div_nm) IN ('지방자치단체','지방공기업') THEN 0
    WHEN TRIM(di.instt_ty_lrgclsfc_nm) IN ('초등학교','중학교','고등학교','특수학교','유치원')
     AND TRIM(di.instt_ty_smlclsfc_nm) = '공립' THEN 0
    WHEN TRIM(di.jrsdctn_div_nm) IN ('국가기관','공기업','준정부기관','정부투자기관') THEN 0
    ELSE 1 END = 1
ORDER BY b.n DESC
```

`Q0`+`Q2`는 `Q0`+`Q1`과 동일한 CASE를 쓰므로 기관 수·공고 합계가 같습니다.

## 5. 법령 근거 확인

국가법령정보센터 원문(시행 2026.10.2, 법률 제21857호)을 2026-10-04에 확인했습니다.

- **지방자치단체 출자·출연 기관의 운영에 관한 법률(지방출자출연법) 제2조(적용 대상 등)**
  - 제1항: 지방자치단체가 설립하고 제5조에 따라 지정·고시된 출자기관 또는 출연기관(출자·출연 기관)에 적용. 출자기관은 지방자치단체 지분이 **100분의 10 이상**인 경우.
  - 제2항(적용 제외): 다음은 이 법을 적용하지 않음. 제1호 **지방공기업법 제2조, 같은 법 제3장·제4장에 따른 지방공기업(지방직영기업·지방공사·지방공단)**, 제2호 **공공기관의 운영에 관한 법률 제6조에 따라 재정경제부장관이 지정한 공공기관**, 제3호 지방자치단체 또는 그 공무원을 회원으로 하는 기관, 제4호 민법에 따른 사단법인.
  - 제3항: 지방자치단체 지분이 **100분의 50 미만**인 출자기관에는 제9조, 제10조의3, 제11조, 제12조, 제14조, 제15조, 제15조의2, 제15조의3, 제16조, **제17조**, 제17조의2, 제17조의3, 제18조제3항·제4항, 제19조, 제22조제1항을 적용하지 않음(단, 최대지분·지배 가능성, 기관장·이사 과반수 임명 관여, 예산·사업계획 승인 등 예외).
  - 제4항: 지분 100분의 25 이상인 출자기관에는 제9조, 제12조, 제15조의2, 제15조의3을 적용.
  - 제5항: 다른 법률에 특별한 규정이 있으면 제외.

- **지방공기업법 제2조(적용 범위)**: 수도, 공업용수도, 궤도(도시철도 포함), 자동차 운송, 지방도로(유료), 하수도, 주택, 토지개발, 주택·토지·공용건축물 관리 수탁, 공공재개발·공공재건축, 재생에너지·수소에너지, 내항 정기 여객운송 사업 중 지방자치단체가 직접 설치·경영하는 지방직영기업과 제3장·제4장에 따라 설립된 지방공사·지방공단에 각각 적용.

- **지방공기업법 제64조의2(회계처리의 원칙 등)**: 제3항은 공사가 계약을 체결할 때 일반경쟁 방식을 원칙으로 하고 예외를 두며, 제6항은 회계처리·계약 기준 및 절차·입찰참가자격 제한에 필요한 사항을 대통령령으로 정하도록 위임. 선행 문서가 든 지방공기업법 시행령 제57조의8이 이 위임을 받습니다.

이 조문들은 대조 결과의 분류 근거가 됩니다. **지방공기업 목록 일치 → 지방공기업법 적용(제2조), 알리오 지정 공공기관 일치 → 지방출자출연법 제2조제2항제2호로 지방출자출연법 적용 제외, 지방출자출연 목록 일치이면서 알리오 미지정 → 지방출자출연법 제2조제1항 적용 대상**으로 해석할 수 있습니다. 다만 지방출자출연법 제2조제3항은 지분 50% 미만 출자기관에 제17조 등을 적용하지 않으므로, 출자기관 16개 기관(458건)은 지분 관계 확인 전에는 같은 근거로 묶을 수 없습니다.

## 7. 결론과 권고

**근거 있게 줄일 수 있는 미상 공고 수의 상한.** 이름 정규화 일치를 그대로 인정한다는 가정에서 LOCAL 12,958건(512개 기관) + NATIONAL 143건(2개 기관) = **13,101건**, 미상 111,565건의 **11.7%** 입니다. 여기에 알리오 기타공공기관 23,765건(245개 기관)은 현행 판별 규칙에 대응 범주가 없어 포함하지 않았습니다. 실제 적용 가능한 값은 이름 오인(6절)과 지방출자출연법 제2조제3항 지분 요건 때문에 이 상한보다 낮습니다.

**구현에 필요한 것.**
1. 수집 경로: 알리오 일반현황 XLSX, 클린아이 지방공기업·출자출연 XLSX, 공공데이터포털 CSV. 모두 로그인 없이 파일로 받을 수 있습니다. 공공데이터포털 OpenAPI는 회원가입·활용신청이 필요하므로 쓰지 않습니다.
2. 갱신 주기: 알리오는 연간 공시, 클린아이는 기준일 표기(현재 2026.6.30), 공공데이터포털은 연간(차기 2027-10-16). 새 목록을 받아 정규화 인덱스를 다시 만드는 배치가 필요합니다.
3. 저장 범위: 미상 기관과의 일치 결과(기관 코드, 외부 목록명, 근거 유형, 확인 상태)만 저장하고, 외부 원본과 대조 스크립트는 저장소에 넣지 않습니다(이번 캡슐의 제약).
4. 기관별 확인 절차: 이름 일치 후보를 사업자번호·설립 지자체·지정 여부로 검증하고, 지방출자출연 출자기관은 지분 50% 요건을 별도 확인합니다.
5. 사용자 결정 사항: (a) 지방출자출연기관 계약을 현행 판별 함수의 LOCAL(복수예가 ±3%)로 볼지, 별도 범주로 둘지 (b) 알리오 기타공공기관을 국가계약으로 볼지 미상으로 둘지 (c) 이 조사 결과를 규칙에 반영할지 여부.

**권장 여부.** 외부 목록은 이름·설립 지자체·지정 여부를 주는 유용한 후보 정렬 도구이지만, 이름 완전 일치만으로 자동 판정 규칙을 만드는 것은 권장하지 않습니다. 동명·지부 오인이 확인됐고 클린아이 목록에는 사업자번호가 없습니다. 권장 순서는 (1) 알리오 사업자번호로 검증되는 기타공공기관·공기업·준정부기관 일치를 먼저 사람이 확인해 NATIONAL 후보로 정리, (2) 지방출자출연·지방공기업 일치는 지자체·기관 상세로 재검증한 뒤 LOCAL 후보로 정리, (3) 각 후보는 별도 규칙·데이터로 반영하는 것입니다. 판별 코드 변경은 이 문서의 범위 밖입니다.
