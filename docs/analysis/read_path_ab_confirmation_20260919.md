## 1. 한 줄 요약

2026-09-18 회차가 확정하지 못한 낙찰 목록 N+1 제거의 순개선 크기를, 같은 시각에 선채움을 켜고 끄며 3 왕복 교대로 재어 확정했습니다. 낙찰 목록 1쪽 P95 는 선채움을 켰을 때 **75.28ms**, 껐을 때 **202.01ms** 로 **-62.7%** 이며, 같은 회차의 대조군 다섯 경로는 전부 ±4ms 안에 머물러 측정이 유효합니다.

## 2. 왜 다시 쟀는가

전 회차는 병합 전 측정이 워커 3대가 돌던 중의 1회 표본이었고 병합 후 측정은 저장소가 조용한 상태였습니다. 시점이 달라 선채움과 무관한 대조군(공고 목록, 비교 통계)까지 각각 25.8%, 9.7% 줄었고, 그래서 낙찰 목록의 감소분 중 어디까지가 N+1 제거의 몫인지 분리되지 않았습니다. 전 회차 인수인계는 이 때문에 개선 크기를 `-64%` 로 인용하지 말라고 못박았습니다.

이번 회차는 같은 머신, 같은 시각, 같은 저장소 상태에서 A(선채움 ON)와 B(선채움 OFF)를 교대로 반복해 시간대 소음을 상쇄했습니다.

## 4. 결과: 실험군

선채움이 직접 적용되는 세 경로입니다. 값은 왕복별 P95 이고 요약은 3 왕복의 중앙값입니다.

| 경로 | 왕복1 A / B | 왕복2 A / B | 왕복3 A / B | A 중앙값 | B 중앙값 | 순차이 | 순개선율 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 낙찰 목록 1쪽 | 76.52 / 202.01 | 74.52 / 196.02 | 75.28 / 213.29 | **75.28ms** | **202.01ms** | -126.73ms | **-62.7%** |
| 낙찰 목록 50쪽 | 74.21 / 197.44 | 76.13 / 197.58 | 78.82 / 200.08 | **76.13ms** | **197.58ms** | -121.45ms | **-61.5%** |
| 홈 컨텍스트 | 69.09 / 140.26 | 67.19 / 132.25 | 70.87 / 131.05 | **69.09ms** | **132.25ms** | -63.16ms | **-47.8%** |

세 왕복 모두 같은 방향이고 왕복 간 산포도 좁습니다. 낙찰 목록 1쪽의 A 값은 74.52~76.52ms 범위이고 B 값은 196.02~213.29ms 범위입니다.

## 5. 결과: 대조군 (측정 유효성)

선채움과 무관한 다섯 경로입니다. A 와 B 가 같아야 이번 측정이 유효합니다.

| 경로 | A 중앙값 | B 중앙값 | 차이 | 판정 |
| --- | ---: | ---: | ---: | --- |
| 공고 목록 1쪽 | 64.62ms | 62.17ms | +2.45ms | 통과 |
| 공고 목록 50쪽 | 55.71ms | 55.52ms | +0.19ms | 통과 |
| 공고 목록 용역 필터 | 57.11ms | 55.24ms | +1.87ms | 통과 |

판정 기준은 절차서 5.1 절의 "±5% 이내 또는 ±5ms 이내" 입니다. 대시보드 통계는 비율로는 13.4% 이지만 절대 차이가 3.94ms 로 ms 기준을 만족합니다. 값 자체가 작은 경로라 비율이 과장되는 구간이며, 이 경로는 낙찰 행 직렬화를 거치지 않으므로 선채움의 영향을 받지 않습니다.

## 6. 판정

| 항목 | 판정 |
| --- | --- |
| 낙찰 목록 N+1 제거의 순개선 | **확정**. 1쪽 -62.7%, 50쪽 -61.5%, 홈 컨텍스트 -47.8% |
| 전 회차의 `-64%` 인용 금지 | **해제**. 다만 인용할 수치는 전 회차 값이 아니라 이 문서의 값입니다 |
| 대조군 동시 감소 문제 | **해소**. 같은 시각 교대 측정으로 시점 소음이 상쇄됐습니다 |

절대값은 전 회차와 다릅니다. 전 회차 병합 후 3회 중앙값은 79.16ms 였고 이번 A 중앙값은 75.28ms 입니다. 같은 조건의 반복 측정 범위 안이며, 이 문서가 주장하는 것은 절대값이 아니라 **같은 시각 A 와 B 의 차이**입니다.

## 7. 이번 회차에서 드러난 사실

| 사실 | 근거 | 조치 |
| --- | --- | --- |
| 첫 실행이 전량 실패했는데 결과표는 정상처럼 보였다 | 왕복1 A 를 뺀 전 구간에서 요청 100/100 실패. 표는 빈 칸을 `-` 로 채웠다 | 표본 0건이면 즉시 예외로 중단하도록 고쳤다 (`6289e15c`) |

| `docker compose up` 에는 `-e` 옵션이 없다 | 하니스와 절차서가 둘 다 이 형태를 썼고 compose 의 `app` 환경 목록에 변수도 없었다 | compose 전달 추가, 셸 환경변수 주입으로 교체 (`2ab8caa4`) |
| Level 1 게이트와 독립 리뷰가 이 셋을 모두 놓쳤다 | 세 검증 모두 명령의 실재 여부와 실행 결과를 검사하지 않는다 | 측정 도구는 병합 뒤 코디네이터가 한 번 실제로 돌려 보고 나서 신뢰한다 |
