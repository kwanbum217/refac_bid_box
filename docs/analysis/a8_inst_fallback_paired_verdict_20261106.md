# A8 기관 이력 폴백 정의 쌍대 실측 판정

> **작성일**: 2026-11-06
> **작성**: 코디네이터(Claude Opus 5.5)
> **대상**: `src/ml/institution_history.py` 의 `fallback_definition='training'` 변형, `scripts/compare_servc_inst_fallback_paired.py`
> **판정**: **기각.** 서빙 기본값 `current` 를 유지합니다. 변형과 측정 스크립트는 재측정용으로 남깁니다.

---

## 1. 측정 조건

| 항목 | 값 |
| --- | --- |
| 모델 | 서빙 `servc_institution_v1` 고정. 두 정의는 폴백 특징만 다릅니다 |
| 대상 | 기관이 집계 표에 없어 폴백을 타는 용역 공고 전량 |
| 2025년 | 폴백 대상 3,250건, 평가 쌍 3,244건, 판정 표본(낙찰률 70~110) 3,204건 |
| 2026년 | 폴백 대상 2,991건, 평가 쌍 2,988건, 판정 표본 2,955건 |
| 명령 | `uv run python scripts/compare_servc_inst_fallback_paired.py --year <연도> --samples 5000 --output <경로>` (주 저장소 모델 파일 필요) |

## 2. 결과 (판정 표본, training - current)

| 지표 | 2025 | 2026 | 해석 |
| --- | --- | --- | --- |
| MAE | 2.2624 -> 2.2628, t +0.37 | 2.5414 -> 2.5413, t -0.10 | 판별 불가. 최소 감지 차이 0.0024/0.0031 보다 작음 |
| 제곱오차 | t +4.90 | t +4.09 | **current 우세** |
| 구간 폭 | -0.0343, t -10.89 | -0.0496, t -10.85 | training 이 좁음 |
| 피복률 | 91.26% -> 91.26% | 91.51% -> 91.30%, t -2.45 | 2026년 **current 우세** |
| 0.5%p 적중 | 48.63% -> 48.69% | 42.64% -> 43.08% | 차이 작음 |

`inst_hist_rate` 평균은 두 정의에서 같았습니다(0.9011). 폴백 대상 기관은 전 이력으로 넓혀도 이상치 범위를 통과하는 표본이 거의 없어 기본값으로 떨어집니다. 실제로 달라진 것은 `inst_sample_cnt` 하나입니다(2026년 평균 0.0 -> 1.05).

---

## 3. 판정 근거

- 승격 기준인 MAE 가 두 해 모두 판별 불가입니다.
- 제곱오차가 두 해 모두 유의하게 나빠졌습니다. 꼬리 공고의 오차가 커진다는 뜻입니다.
- 구간이 좁아진 대가로 2026년 피복률이 0.21%p 내려갔습니다. 좁아진 구간은 개선이 아니라 과신입니다.
- 정의 일원화(AGENTS.md 6항)의 취지는 지켜야 하지만, 이 차이는 학습 경로가 아니라 **학습 표본이 없는 기관의 서빙 폴백**에서만 생깁니다. 학습에는 이런 행이 대부분 표본 미달 기본값으로 들어가므로 skew 를 메워도 예측이 좋아지지 않았습니다.
