10. 시·도는 그 시의 가격 별표를 읽기 전에는 행정안전부 예규 제373호(규모 구간, 기준비율 88%)에 둔다. 예규는 시·도별로 식을 나누지 않는다.

## 6. 확인 불가·유의 사항

- **한국수자원공사 기준율 표기 누락**: 2.3절대로, 추출물이 산식의 안쪽 분수를 빈 괄호 `()` 로 남겨 기준율을 본문에서 읽을 수 없습니다. 기준율 88%(별표 6은 91%)는 Capsule 확인 사실과 산식 예(`kw15571_tbl.txt:26`)에서 온 값입니다. 추출물 본문만으로는 미확인입니다.
- **한국수자원공사 별표 1의 `<삭 제>` 표시**: `kw15571_tbl.txt:253` 의 `<삭 제>` 가 어느 칸을 가리키는지 추출물로는 확인할 수 없습니다. 다만 심사방법·배점한도 칸은 남아 있고 대입값이 인쇄 22 와 정확히 일치합니다.
- **한국도로공사 별표 2 점수 미인쇄**: 원문이 88.25% 비율만 적고 평점 숫자를 인쇄하지 않아 대입값과 비교할 대상이 없습니다. 이 두 행을 일치로 처리하지 않았습니다.
- **원문 소재**: 두 기관 원문 추출물은 저장소 밖 `/tmp/qual-formulas/hermes-servc/` 아래에 있고 읽기 전용입니다. 재부팅 시 사라질 수 있으므로 위 인용문을 이 문서에 그대로 옮겨 근거로 남겼습니다.
- **변경하지 않은 것**: 이 작업은 `evaluation_rules.py`, 테스트, DB 스키마, Meilisearch 색인, Docker 관련 파일을 수정하지 않았습니다. 계수·기준율을 코드에 입력하는 일은 하지 않았습니다.
