### 2.2 원인 A: `GENERAL`·`SIMPLE_LABOR` 병존으로 세부유형 미판정 (5건)

**재현 경로**

2. `_select_local_rule`(`:2361-2372`)이 `LOCAL_RULES` 에서 지역 축이 맞는 후보를 고릅니다(`:2413-2424`).
3. `_narrow_to_current_regime`(`:2468`)이 공고일 효력 구간으로 판본을 하나만 남깁니다.

### 3.1 R1 적용 시 동작

- #1·#5: 조달분류 `학술연구서비스` → `ACADEMIC`. 전북·대전에 `ACADEMIC` 별표가 없으므로 `별표 유형 ACADEMIC 이(가) 없어 일반 별표를 적용했습니다.` 경고와 함께 `GENERAL` 로 계산됩니다(`evaluation_rules.py:2555-2559`).
- #2: 조달분류 중분류 `임대` → `LEASE`. 울산에 `LEASE` 별표가 없으므로 같은 폴백으로 `GENERAL` 계산입니다.
- 새 규칙 값을 만들지 않고 기존 `GENERAL` 규칙을 쓰므로 원문 미확보 항목이 없습니다.

### 3.2 R1 로 해소되지 않는 이유

- #3: `인력공급서비스` 를 `SIMPLE_LABOR` 로 매핑하면 단순노무 여부를 조달분류만으로 확정하게 되어 D5와 충돌합니다. 매핑하지 않으면 A 분기가 유지됩니다.
- #7: `폐기물` 은 `_PROCUREMENT_SERVICE_MARKERS` 에 이미 있으나 공고명은 판정 입력이 아닙니다(`evaluation_rules.py:2185-2189`). 공고명을 입력에 넣더라도 서울에 `WASTE` 별표가 없어 `GENERAL` 폴백이 되는데, 폐기물처리용역에 `GENERAL` 을 적용하는 것이 맞는지는 서울 예규 원문이 필요합니다.
- #4·#6: `학술연구`→`ACADEMIC` 을 적용해도 대구에는 `GENERAL` 이 없어 `LOCAL_RULE_NOT_FOUND` 로 바뀔 뿐 계산되지 않습니다(`evaluation_rules.py:2560-2561`).
- #8~#12: 여객 고시금액미만 규칙이 없으므로 매핑으로 풀 수 없습니다. D17(다른 구간 근사 금지) 때문에 5억원 미만 규칙으로 대체하지 않습니다(`:4002-4013`).

### 3.3 대안으로 검토했으나 채택하지 않은 안

- **LOCAL_SERVICE_TYPE_UNRESOLVED 를 행안부 학술연구 띠 구제 대상에 포함**: `_MOIS_ACADEMIC_BAND_FALLBACK_BLOCK_CODES` 에 코드가 이미 들어 있으나(`evaluation_rules.py:2867-2873`), 호출부가 `_is_band_only_method` 이고 차단 코드가 `RULE_NOT_FOUND` 가 아니면 구제하지 않습니다(`:3911-3916`). 이 예외를 풀면 #1·#5 가 행안부 [별표 4] 로 계산될 수 있으나, 시·도 자체 예규가 있는 지자체에 행안부 예규를 먼저 적용하는 결과가 되어 시·도 우선 원칙(`:3588-3590`)과 충돌합니다. 그래서 R1(지역 `GENERAL` 폴백)을 우선안으로 두었습니다.
- **화물→여객 교정을 띠가 없는 경우 생략**: #9~#11은 실제 서비스가 셔틀버스·통학버스라 여객 교정이 사실에 맞습니다. 교정을 생략하면 화물 고시금액미만 값이 적용되어 실제 기준과 어긋납니다.
- **여객 5억원 미만 규칙으로 근사**: D17 이 금지합니다(`evaluation_rules.py:4002-4013`).

## 4. 확인하지 못한 것

1. **대구 예규의 일반용역 적용 조항**: 예규 제238호가 일반 별표를 삭제한 뒤 일반용역을 무엇으로 심사하는지 저장소 원문에서 확인하지 못했습니다. 조달청 준용 조항이 있는지 확인 전에는 #4·#6 의 해소 방향을 확정할 수 없습니다.
2. **서울특별시 예규의 폐기물처리용역 별표**: 서울 규칙 레지스트리에 `WASTE` 가 없습니다(`evaluation_rules_local.py:1872-1903`). 폐기물처리용역이 `GENERAL` 별표 대상인지, 별도 별표가 있는데 미수집인지 확인하지 못했습니다.
3. **사하구 #3 의 실제 세부유형**: `안전요원 인력 파견` 이 단순노무(경비·시설관리)인지 일반용역인지 공고문 원문 없이 확정하지 못했습니다.
4. **조달청 여객 육상운송 고시금액미만 별표의 존재 여부**: 현재 코드 레지스트리에는 없습니다. 조달청 고시 원문에 해당 띠가 실제로 없는 것인지, 있는데 미등록인 것인지 확인하지 못했습니다. 미등록이라면 B·k·기준비율·통과점수는 원문에서 확인해야 합니다.
5. **에스알 #8·#12 의 서비스 실체**: 공고명은 `현금수입금 수납 및 지폐·주화교환 위탁용역` 인데 낙찰방법명은 `화물 육상운송`, 조달분류는 `도로여객운송` 입니다. 세 표기가 서로 달라 어느 별표가 실체에 맞는지 공고문 없이 판정하지 못했습니다.
6. **전남광주 AI교육원 #13 의 옛 계열**: `AI교육원` 만으로는 전라남도(46)와 광주광역시(29) 중 어디 계열인지 판별하지 못했습니다. 이 과업 지시에 따라 차단 유지 대상으로 두었고 보완안에 넣지 않았습니다.
7. **판정 함수 직접 재현**: 캡슐 금지에 따라 `resolve_evaluation_rule_from_raw_data` 를 호출하지 않았습니다. 분기 판정은 코드 경로와 DB 입력 필드 대조로 했으며, 원장의 차단 집계(7·5·1)와 대상 13건이 일치함을 교차 확인했습니다(`data/reference/rule_coverage_ledger.yaml:31-43`).
