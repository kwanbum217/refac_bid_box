### 3.3 입찰가격 배점·계산식·통과점수 (두 판 동일)

원문의 입찰가격 계산식은 `hp:equation` 수식 스크립트이며 두 판이 같습니다. 텍스트는 아래와 같습니다.

```text
평점(점) = 배점한도 - k × |( 기준비율/100 - 입찰가격/예정가격 ) × 100|
```

## 10. 재현 질의

모든 DB 조회는 `uv run python scripts/db_readonly_query.py --format json --sql "<질의>"` 로 실행했습니다. 조회일 2026-09-29. 낙찰방법명 필드는 `JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidMthdNm'))`, 하한율 필드는 `...'$.sucsfbidLwltRate'` 입니다.

- **Q1.** 개정 전 구간 낙찰방법명 분포(7장·8장 표본):
  `SELECT JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidMthdNm')) AS m, COUNT(*) AS rows_cnt, COUNT(DISTINCT bid_ntce_no) AS ntce_cnt FROM bid_announcements WHERE category='Servc' AND bid_ntce_dt >= '2025-09-01' AND bid_ntce_dt < '2026-05-26' AND JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidMthdNm')) LIKE '적격심사제%' GROUP BY m ORDER BY rows_cnt DESC`
- **Q2.** 낙찰방법명별 실측 최빈 하한율(7장·8장 lwlt):
  `WITH q AS (SELECT JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidMthdNm')) AS nm, CAST(JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidLwltRate')) AS DECIMAL(8,4)) AS lw FROM bid_announcements WHERE category='Servc' AND bid_ntce_dt >= '2025-09-01' AND bid_ntce_dt < '2026-05-26' AND JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidMthdNm')) LIKE '적격심사제%'), r AS (SELECT nm, lw, COUNT(*) c, ROW_NUMBER() OVER (PARTITION BY nm ORDER BY COUNT(*) DESC, lw) rn FROM q GROUP BY nm, lw) SELECT nm, lw, c FROM r WHERE rn=1 ORDER BY c DESC`
- **Q3(원문 추출).** 표: HWPX 의 `Contents/section0.xml` 에서 `hp:tbl`/`hp:tr`/`hp:tc` 를 문서 순서로 읽어 별표 헤더와 대조. 수식: `hp:equation` 의 `hp:script` 텍스트를 읽어 기준비율·계수 확인.
