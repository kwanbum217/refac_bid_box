## 계약 이행

- 매니페스트 없는 스냅샷은 목록에서 감추지 않고 valid False 로 드러낸다. 무효를 유효로 바꾸지 않는다.
- 매니페스트 없는 보존 대상이 있으면 errors 에 사유를 남기고 fail-closed 로 아무것도 삭제하지 않는다.
- 심볼릭 링크 분기는 문구와 동작을 중단으로 일치시켰다. 판단 근거는 아래 별도 절에 있다.

- 파일 분리 리팩터링을 하지 않았다.

## 심볼릭 링크 판단 근거

안전 쪽 기본값인 중단을 정본으로 삼고 문구를 동작에 맞췄다. 제외(건너뛰고 계속 삭제)로 바꾸려면 삭제 대상 열거와 보존 개수 계산이 링크를 제외한 뒤에도 정합함을 입증해야 하는데, 그 증명 없이 제외하면 검증되지 않은 상태에서 삭제가 진행되어 데이터 무손실(G1)에 반한다. 따라서 문구를 중단으로 고쳐 실제 fail-closed 동작과 일치시켰다.
