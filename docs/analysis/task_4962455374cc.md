# Arq 워커 관측 기록 구현 보고서

> 작업일: 2026-09-02

## 구현 내용

- Redis `CacheLayer`를 통해 워커 식별자와 마지막 heartbeat 시각을 기록합니다.
- heartbeat 시점의 `arq:queue` 대기 건수를 함께 기록합니다.
- 다섯 개 정기 작업의 마지막 실행 시각과 성공 여부를 래퍼에서 기록합니다.
- `/api/v1/health/worker` 읽기 전용 조회를 추가했으며 readiness 판정과 분리했습니다.
- Redis 기록·조회 실패는 예외를 전파하지 않고 미상(`null`)으로 처리합니다.
