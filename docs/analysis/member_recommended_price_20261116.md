# 내 조건 추천가: AI 예측가와 정량점수 통과 구간의 연결 (2026-11-16)

> **작성일**: 2026-11-16
> **범위**: 공고 상세 투찰가 추천(`POST /api/v1/evaluations/recommend`)과 화면 표시
> **판정**: 구현. 응답에 `member_recommended_price`·`member_recommendation_basis` 추가

---

## 1. 문제

사용자가 정량평가 배점을 바꿔도 AI 예측가가 같은 금액으로 나온다는 지적이 있었다.

| 항목 | 사실 | 근거 |
| --- | --- | --- |
| AI 예측가 입력 | 공고 ID 와 모델 선택만 받는다. 회원 정량점수는 넘기지 않는다 | `src/app/api/v1/evaluations.py` `_recommend_prediction` |
| 학습 특징 | 정량점수 특징이 없다. 나라장터 낙찰 결과에 참가업체별 정량점수가 없어 넣을 수 없다 | `src/ml/features.py` |
| 정량점수의 쓰임 | 최저가·최상가(통과 구간)에만 쓰인다 | `_recommend_price_bounds` |
| 결함 | 예측가와 통과 구간을 비교하는 곳이 없어, 통과할 수 없는 예측가를 그대로 보여 줄 수 있었다 | 서버·템플릿 모두 비교 없음 |

예측가가 점수와 무관한 것은 의도한 동작이다. 예측가는 공고의 시장 낙찰가 예측이고, 한 업체의 정량점수가 다른 업체의 투찰을 바꾸지 않는다. 결함은 두 숫자가 연결되지 않은 것이다.

## 2. 빈도 측정

2026-06-01 이후 용역 적격심사 공고 600건을 무작위(시드 42)로 뽑았다. 예측은 운영과 같은 `predict_price_api` 로, 통과 구간은 `compute_price_bounds` 로 계산했다. 정량점수는 `100 - B` 를 만점으로 보고 만점에서 0·1·2·3·5점을 뺀 다섯 경우를 넣었다. 읽기 전용이다.

| 구분 | 건수 |
| --- | --- |
| 계산 가능 | 170 |
| 배점표 입력 필요(`MISSING_SCORE_TABLE`) | 282 |
| 수기심사(`MANUAL_EVALUATION`) | 134 |
| 비예가(`NON_PRED_PRICE`) | 7 |
| 배점표 미확정 | 7 |

계산 가능 170건에서 AI 예측가가 최저가보다 낮은 비율이다. 최상가를 넘는 경우는 모든 경우에서 0건이었다.

| 정량점수 | 최저가 미달 | 미달 폭 중앙값 | 미달 폭 최대 |
| --- | --- | --- | --- |
| 만점 | 3건 (1.8%) | 0.48% | 1.80% |
| 만점 -1점 | 3건 (1.8%) | 0.70% | 2.09% |
| 만점 -2점 | 3건 (1.8%) | 0.92% | 2.38% |
| 만점 -3점 | 3건 (1.8%) | 1.15% | 2.67% |
| 만점 -5점 | 13건 (7.6%) | 0.81% | 3.24% |

AI 예측 낙찰률은 낙찰하한율보다 중앙값 0.07%p 높아 하한 근처에 몰려 있다. 그래서 대부분의 공고에서는 예측가가 이미 통과 구간 안에 있고, 정량점수를 바꿔도 추천가가 그대로인 것이 맞다. 점수가 5점가량 모자라면 약 13건 중 1건꼴로 추천가를 올려야 한다.

## 3. 설계

| 항목 | 결정 |
| --- | --- |
| 계산 위치 | 서버 순수 함수 `member_recommended_price` (`src/app/services/evaluation_recommendation.py`) 하나 |
| 규칙 | 예측가 < 최저가면 최저가(`raised_to_min`), 예측가 > 최상가면 최상가(`lowered_to_max`), 그 밖에는 예측가(`ai`) |
| 계산 조건 | 통과 구간이 확정(`price_bounds.status == "ok"`)되고 예측가가 있을 때만. 차단 응답은 두 필드가 모두 `null` |
| 화면 | AI 예측가·최저가·최상가 세 칸은 그대로 두고 그 아래 "내 조건 추천가" 블록을 둔다. 조정된 경우 주황 배경과 사유 문장 |
| AI 예측가 | 바꾸지 않는다. 시장 예측으로 계속 보여 준다 |

최저가는 사정률 하한 시나리오(가장 낮은 예정가격)에서도 통과점수를 넘기는 가장 낮은 금액이다. 그보다 낮게 투찰하면 어떤 예정가격에서도 적격심사를 통과하지 못하므로 최저가로 올리는 것이 안전한 최소 조정이다. 구간 안의 예측가가 실제 예정가격에서 통과하는지는 여전히 예정가격에 달려 있으며, 이 조정은 그 불확실성을 없애지 않는다.
