### 3.3 낙찰하한율 역산

원문이 하한율을 인쇄하지 않아 `하한율 = 88 − (100 − T) / k` 로 역산하고 표기 관행대로 소수 셋째 자리에서 0.005 를 뺐습니다(`.995` 표기). 이 식은 비가격 배점 최대치를 `100 − B` 로 두고 `T = (100 − B) + B − k×(88 − 하한율)` 을 하한율에 대해 푼 것입니다.

- 검산 근거: 2015년 판 별첨 1 은 같은 구조의 값을 직접 인쇄합니다. 예를 들어 폐기물 `지역제한 금액미만 1억원 이상` 행은 `비가격 20·입찰가격 80·필요 75·87.745·통과 95` 로, `80 − 20×|88−87.75| = 75` 와 일치합니다. 2023년 판에서 같은 (B·k·T) 조합인 구간은 같은 값이 되고, 실제로 폐기물 5구간·육상운송 4구간 값이 현행 통합 지침 별표 3·5 가 인쇄한 값과 모두 일치합니다.
- 공고에 낙찰하한율(`sucsfbidLwltRate`)이 있으면 종전과 같이 공고값이 우선합니다.

### 4.2 현재 코드의 날짜 선택 구조 확인 (변경 전)

`_select_local_rule` 은 공고일을 받지 않고 `LOCAL_RULES` 를 **지역 축으로만** 걸러 세부유형을 고릅니다. 같은 시·도·세부유형 규칙이 둘이면 `LOCAL_SERVICE_TYPE_UNRESOLVED` 로 차단하고, 시행일 대조는 `resolve_evaluation_rule` 마지막의 `announced < effective_date` 한 곳에서만 했습니다. 즉 구판과 현행을 같은 지역·세부유형으로 함께 두면 둘 다 후보가 되어 막히는 구조였습니다.

### 4.3 구현한 방식

| 요소 | 내용 |
| --- | --- |
| 규칙 필드 | `EvaluationRule.superseded_date`(폐지된 구판만 값 보유, 현행은 None) |
| 가르기 | `_narrow_to_current_regime`: 같은 세부유형 후보가 둘 이상이면 공고일이 효력 구간(`effective_date ≤ 공고일 < superseded_date`)에 드는 하나만 남김 |
| 구간에 드는 규칙이 없을 때 | 시행일이 가장 늦은 현행 규칙을 남겨 종전처럼 `RULE_REGIME_MISMATCH` 로 차단(2023-03-02 이전 전남 공고 회귀 방지) |
| 공고일이 없을 때 | 폐지되지 않은 현행 규칙을 남겨 종전 판정 유지 |
| 광주 계열 | 구판 규칙을 만들지 않아 현행 규칙만 후보가 되고, 시행일 대조에서 `RULE_REGIME_MISMATCH` 유지 |
