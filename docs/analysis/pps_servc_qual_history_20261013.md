## 1. 요약

2015~2022년에 시행된 조달청 일반용역 적격심사 세부기준 **12개 판(版)** 의 입찰가격 평점 별표를 원문에서 읽어, 별표별 배점한도 B·평점계수 k·기준비율·통과점수·낙찰하한율을 기계 판독 명세로 만들었습니다.

- **수집한 판**: 제2015-41호(시행 2015-05-01)부터 제2022-42호(시행 2022-02-11)까지 12개 판. 국가법령정보센터 행정규칙 연혁(`admRulId=33121`)에서 상세 페이지와 [별표] 첨부(HWP 5.x)를 내려받아 판독했습니다.
- **가격 별표 83개**: 판마다 별표 5~8개가 입찰가격 평점산식을 담습니다. 별표 1~6(학술연구·시설분야·정보통신/소프트웨어·폐기물·육상운송·보험)이 대상이고, 별표 7~8(신용평가등급·신인도)은 가격과 무관해 제외했습니다.
- **핵심 구조**: 모든 판에서 계산식은 `평점 = 배점한도 - k × |기준비율/100 - 입찰가격/예정가격| × 100` 이고, 하한율은 `기준비율 - (100 - 통과점수) / k` 로 역산합니다. 원문 표기 관행대로 소수 둘째 자리까지 버리고 0.005 를 빼 `.995` 로 적습니다.
- **검증**: 역산 하한율이 저장소가 기록한 개정 전 실측 최빈값(시설분야 87.995, 보험 47.995, 학술연구·폐기물 고시금액 미만 84.245, 이상 80.495, 소프트웨어 대상 87.995)과 정확히 일치합니다. 이는 명세 값이 원문과 어긋나지 않는다는 교차 증거입니다.

핵심 판정 6건입니다.

- **개정 시점별로 k 가 세 번 바뀝니다.** 2015-41~2017-82 는 모든 비대상 별표가 k=2 단일 계산식이고, **2017-95(시행 2017-12-01)부터** 고시금액 미만 구간이 k=4 로 분리되며, 2019-31(시행 2019-04-01)부터 구간 경계 표기가 금액에서 `고시금액` 으로 바뀝니다.
- **시설분야 별표는 12개 판 전부 동일합니다.** k=5·기준비율 91·평탄 94%·하한율 87.995 로 개정이 없습니다.
- **B 와 계산식의 구간 경계가 다릅니다.** 학술연구는 B 와 계산식이 같은 경계를 쓰지만, 정보통신·소프트웨어·폐기물·육상운송 별표는 **B 는 5억원 경계, 계산식은 고시금액(2017-95·2018-36 은 2.1억원) 경계** 로 갈립니다. 명세는 이 두 축을 `price_lower/price_upper` 와 `formula_lower/formula_upper` 로 나눠 적었습니다.
- **하한율이 2017-95 에서 실제로 바뀝니다.** 비대상 별표의 고시금액 미만 구간 하한율이 80.495(2015~2017-82) 에서 84.245(2017-95~2022-42) 로 오릅니다. k 가 2 에서 4 로 커진 결과입니다.
- **통과점수는 본문 제10조에만 있습니다.** 별표는 통과점수를 인쇄하지 않습니다. 12개 판 모두 85점이고, 중소기업자간 경쟁제품 대상(정보통신/소프트웨어/육상운송)과 2022-42 의 여객 육상운송용역만 88점입니다.
- **제2016-48호와 제2016-51호는 시행일이 같습니다.** 발령 2016-04-08 과 2016-04-26 이고 시행일이 둘 다 2016-05-01 입니다. 별표 9개 중 5개는 텍스트가 완전히 같고 4개는 결격사유·신인도 문구만 다르며 가격 파라미터는 같습니다. 시행일 전 제2016-51호로 대체된 것으로 봅니다.

평탄 비율은 별표 예외사항이 `입찰가격이 예정가격 이하로서 예정가격의 N% 이상인 경우` 로 인쇄한 값입니다. 보험 별표는 평탄 문장이 없습니다(명세에서 `flat_ratio: null`).

### 4.3 하한율 역산 검산

`하한율 = 기준비율 - (100 - 통과점수) / k` 를 소수 둘째 자리까지 버리고 0.005 를 뺀 값입니다.

| 별표(구간) | 계산 | 하한율 |
| --- | --- | ---: |
| 시설분야 | 91 - (100-85)/5 = 88.000 | 87.995 |
| 학술연구 등 (k=2) | 88 - (100-85)/2 = 80.500 | 80.495 |
| 학술연구 등 (k=4) | 88 - (100-85)/4 = 84.250 | 84.245 |
| 대상 (k=4, 통과 88) | 91 - (100-88)/4 = 88.000 | 87.995 |
| 보험 | 88 - (100-85)/0.375 = 48.000 | 47.995 |

이 값들은 저장소가 기록한 개정 전 실측 최빈 하한율과 일치합니다([`servc_pre20260526_rules_sourcing_20260929.md`](servc_pre20260526_rules_sourcing_20260929.md) 4.5 절).

| 2022-42 보험(별표 6) | `배점한도-0.375 TIMES ( {88} over {100}`, 예외 문장 없음 | 일치 |

| 2016-48 vs 2016-51 | 별표 9개 중 5개 레코드 텍스트 동일, 4개는 결격사유·신인도 문구만 상이 | 일치 |

`하한율` 은 원문에 인쇄되지 않아 위 4.3 의 식으로 역산한 파생값입니다. 명세는 `lwlt_basis: derived` 를 `conventions` 에 적었습니다.

## 7. 레지스트리 반영 계획

운영 코드(`src/app/services/evaluation_rules.py`)는 이번 과업에서 바꾸지 않았습니다. 후속 과업의 반영 계획입니다.

| 단계 | 작업 | 근거 |
| --- | --- | --- |
| R1 | 명세 YAML 을 규칙 레지스트리로 옮길 때 `SERVC_QUAL_HIST_<판>_<별표>` 네임스페이스를 새로 둡니다. 기존 `SERVC_QUAL_PRE_20230501_*`·`POST_*` 와 판이 겹치지 않게 합니다. | 3장 연혁 |
| R2 | 규칙 스키마에 B 축(`price_lower`/`price_upper`)과 계산식 축(`formula_lower`/`formula_upper`)을 별도 필드로 담습니다. 현재 스키마는 단일 `price_bands` 만 있어 4.1·4.2 의 이원 경계를 담지 못합니다. | 4.1, 4.2 |
| R3 | `effective_date` 구간 라우팅을 공고일 기준으로 넣습니다. 경계는 3장 시행일·종료일입니다. 제2016-48호는 제2016-51호와 시행일이 같으므로 라우팅에서 제외하고 2016-51 만 등록합니다. | 3장, 6장 |
| R4 | 원문 인쇄값(`B`, `k`, `base_ratio`, `flat_ratio`, `pass_score`)을 규칙 필드로 넣고, `lwlt_rate` 는 4.3 식으로 계산해 파생 필드로 둡니다. | 4.3 |
| R5 | 2015-41 대상 별표와 2020-10·2020-30 보험 별표는 원문 보완 전까지 등록하지 않거나 `null` 로 두고 차단합니다. 추정값을 넣지 않습니다. | 6장 |
| R6 | 반영 뒤 2015~2022 공고를 `resolve_evaluation_rule` 에 통과시켜 `RULE_NOT_FOUND`·`RULE_REGIME_MISMATCH` 비율과 하한율 일치율로 백테스트합니다. | [`past_criteria_rule_map_20261013.md`](past_criteria_rule_map_20261013.md) 6.4 |

선행 실측 [`past_criteria_rule_map_20261013.md`](past_criteria_rule_map_20261013.md) 는 2015~2022 공고 대응이 0~1건에 그친 이유를 "규칙 레지스트리가 2023-05-01 이후만 담는다"로 특정했습니다. 이 명세가 그 시간 범위를 채우는 입력입니다.

## 9. 한계와 검증

### 9.1 한계

- 하한율은 원문 미인쇄값이며 4.3 식으로 역산한 파생값입니다.
- 통과점수는 본문 제10조에만 있고 별표에는 없습니다. 별표별 통과점수 차등(대상 88)은 본문 문구로 판정했습니다.
- B 축과 계산식 축이 다른 별표는 두 축을 명세에 나눠 적었으나, 두 축의 교차 조합을 코드가 어떻게 라우팅할지는 후속 과업의 설계 대상입니다.
- 2015-41 의 대상 별표와 2020-10·2020-30 의 보험 별표는 원문 미확보입니다.

### 9.3 재현

원문 재판독은 `.cache/pps_history/` 안에서 가능합니다. 판독기는 저장소 스크립트를 그대로 씁니다.

```sh
# 별표 HWP 에서 입찰가격 파라미터 추출 (요약 출력)
uv run python .cache/pps_history/_extract2.py

uv run python .cache/pps_history/_build.py
```

`.cache/pps_history/` 는 커밋 대상이 아니며, 원문 HWP 는 저장소에 넣지 않았습니다.
