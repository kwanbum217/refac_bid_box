## 2. 항목별 원문 근거와 판정

### 2.1 한국수력원자력 수요기관명 별칭 (확정)

- 원문: 한국수력원자력 「일반용역적격심사세부기준」(일부개정 2026-06-19) 적용 주체는 `한국수력원자력주식회사(한수원)` 입니다(선행 문서 [servc_formula_userfiles_agency_20261004.md](servc_formula_userfiles_agency_20261004.md) 6.1절).
- 기관표(`procurement.g2b_demand_institutions`)에 본청 코드가 없어 수요기관 코드로는 판정할 수 없고, 이름 정확 일치로만 판정합니다.
- DB 실측(`uv run python scripts/db_readonly_query.py --sql "SELECT dminstt_nm, COUNT(*) c FROM procurement.bid_announcements WHERE dminstt_nm LIKE '한국수력원자력%' GROUP BY dminstt_nm ORDER BY c DESC"`):
  - 본사 표기: `한국수력원자력주식회사`(93건), `한국수력원자력(주)`(1건).
  - 하위 조직 표기: `한국수력원자력(주)한울원자력본부`(103건), `한국수력원자력(주)양양양수발전소`(70건), `한국수력원자력(주)한빛원자력본부`(58건) 등 12종.
- 판정: 본사 표기 두 개만 별칭으로 넣습니다. 접두 일치를 쓰지 않으므로 `한국수력원자력(주) 한울원자력본부` 같은 하위 조직 표기는 별칭과 정확히 같지 않아 매칭되지 않습니다(하위 조직은 별도 Task S1 조사 대상).

### 2.2 한국가스공사 B 30/50/70 (유지)

- 원문: 한국가스공사 「공사·용역 적격심사 세부기준」(개정 2026-07-08, 시행 2026-07-09). 현행판 본문 추출본 인용입니다.
  - 제16조①(심사분야별 배점한도): B(입찰가격 배점한도)는 해당 용역수행능력을 **100% 계량화하여 절대평가**하면 30, **70% 이상 계량화**하면 50, **70% 미만 계량화**하면 70 입니다. 시설분야용역은 50, 별표10 준용(실적·경영상태만)은 70, 사전평가 기술용역은 30 입니다. 근거 `.orca/capsules/task_a61c0e310be3/external/kogas/cur2026/kogas_cur2026_main.txt:201-217` (제16조① 1~5호, 제16조②).
  - 제17조①(입찰가격 평점산정): k(평점계수)는 추정가격 구간으로 정해집니다. 30억원 이상 1.5, 30억원 미만 10억원 이상 2, 10억원 미만 고시금액 이상 3, 고시금액 미만 5 이고 기준비율은 90 입니다. 근거 같은 파일 `:218,220-224`.
- 판정: B 는 추정가격이 아니라 **용역수행능력의 계량화 정도**로 정해지고, 그 정도는 제15조·제16조에 따라 용역별로 입찰공고에 명시하는 값입니다. 공고 메타데이터(분류·낙찰방법명·추정가격)에는 계량화 정도가 없어 자동 판정할 수 없습니다. 따라서 B 는 추측하지 않고 `max_price_score=None` 과 구간별 사유를 그대로 유지합니다(k·기준비율·통과점수·하한율은 확정). 근거 문서: [servc_formula_kogas_qualification_20261004.md](servc_formula_kogas_qualification_20261004.md) 5.2·5.3절.

### 2.3 별표 8 임대차 k=2·k=4 (확정)

두 기관 모두 별표 8 `①입찰가격 계산식` 표의 사업예산규모를 **추정가격 고시금액 이상/미만** 두 행으로 인쇄하고, 각 행의 계수를 k=2/k=4 로 달리 둡니다. B(입찰가격 배점한도)는 두 행 모두 70(별표의 `Ⅱ.입찰가격` 배점한도)이라 고시금액 경계로 두 구간을 나눕니다.

| 기관 | B | 고시금액 이상 | 고시금액 미만 | 근거 |
| --- | ---: | --- | --- | --- |
| 인천국제공항공사 | 70 | k=2, 기준 88, T 85, 하한율 80.495% | k=4, 기준 88, T 85, 하한율 84.245% | `.orca/capsules/task_afb66751579d/external/extracted/iia_17529_full.txt:1566-1568`(B), `:1589-1598`(k) |
| 인천공항시설관리 | 70 | k=2, 기준 88, T 85, 하한율 80.495% | k=4, 기준 88, T 85, 하한율 84.245% | `.orca/capsules/task_4103791c2123/external/extracted/iia_full.txt:1565-1567`(B), `:1589-1597`(k) |

- 인천국제공항공사 원문 행: `추정가격 고시금액 이상` → `평점(점)=배점한도-2 x |( 88/100 - 입찰가격/예정가격 ) x 100|`(평탄 95.5%), `추정가격 고시금액 미만` → `평점(점)=배점한도-4 x |( 88/100 - 입찰가격/예정가격 ) x 100|`(평탄 91.75%).
- 인천공항시설관리 원문 행: 위와 같음(두 문서가 같은 별표 8 체계).
- 판정: 원문이 `고시금액 이상/미만` 두 행으로 구분 근거를 인쇄하므로, 종전에 "구분 근거 없음"으로 두었던 것은 별표 8 표를 두 행으로 읽지 않은 데서 온 것입니다. 두 규칙을 하나로 합치고 고시금액 경계로 나눠 `RULE_SCOPE_AMBIGUOUS` 차단을 없앱니다. 원문이 인쇄한 값만 썼고 새로 추정하지 않았습니다.
- 선행 문서의 표(`servc_formula_recover_a_20261005.md` 4.2절, `servc_formula_userfiles_agency_20261004.md` 9.2절)는 별표 8 의 k 를 `2 / 4` 로만 적고 적용 구간을 "단일"로 적었는데, 원문 두 행을 반영해 이번에 고시금액 경계로 확정합니다.

## 4. 한국수력원자력 별칭 추가 전후 매칭 공고 수

| 구분 | 별칭 | 매칭 공고 수 |
| --- | --- | ---: |
| 추가 전 | `한국수력원자력`, `한수원`, `KHNP` | 0 |
| 추가 후 | 위 + `한국수력원자력(주)`(1), `한국수력원자력주식회사`(93) | 94 |
