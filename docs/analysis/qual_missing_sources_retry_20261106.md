### 6.2 사용자 결정 항목

1. **LH 지정 확인의 규칙 반영 여부.** 기존 YAML note는 이미 "나라장터 LH 일반용역 공고는 조달청 기준을 적용한다"고 적고 있다. 이번 조사로 근거 공고가 13건으로 늘었으므로, note의 출처에 본 문서를 추가할지만 결정하면 된다. 조달청 별표 계수는 LH 계수로 옮기지 않는다.
2. **한전KPS 지정 확인의 규칙 등록 여부.** 근거가 개별 공고 1건뿐이다. 전사 규칙(`status`)을 `confirmed`로 올리는 것은 권고하지 않는다. 공고 단위 사실로만 남기는 편이 안전하다.
3. **한국도로공사 2022-10-01판 확보 경로.** 나라장터 공고 첨부 경로에서는 확인되지 않았다. 기관 전자조달 자료실, 사용자 제공 원문, 또는 공식 문서 공개 요청 중 어느 경로를 쓸지 결정이 필요하다.
4. **한전 전력연구원 조사 종료 여부.** 나라장터 용역 발주가 협상계약 1건뿐이라 공고 첨부 경로의 추가 조사 여지는 사실상 없다. 자체 전자조달·사규 공개 경로를 계속 볼지 결정이 필요하다.
5. **규칙 값 이관 금지.** 이번 문서에는 배점표 숫자·계수를 옮기지 않았다. 원문이 확보되기 전까지 `evaluation_rules.py`와 YAML bands는 현행 `unresolved`/`partial` 상태를 유지하는 것이 맞다.

### 6.3 방법과 한계

- 나라장터 공고 검색 화면은 `시스템 접근 안내`를 반환해 직접 검색이 막힌다. 첨부 내려받기(`UntyAtchFile/downloadFile.do`)는 정상 동작하므로, 공고번호를 아는 건은 첨부 원문을 직접 받아 확인했다.
- 공고번호를 모르는 건은 공개 공고 목록 색인으로 번호만 확인하고, 원문 판정은 나라장터 첨부로만 했다.
- 요청 사이 간격은 1.1초 이상 두었다. 새 라이브러리는 설치하지 않았다. 텍스트 추출은 `scripts/extract_score_params.extract_document_text`만 사용했다.
- 내려받은 원본과 추출 결과는 `.cache/inst4/raw/`에 있고 Git 추적 대상이 아니다. 문서에는 경로와 sha256만 남긴다.
