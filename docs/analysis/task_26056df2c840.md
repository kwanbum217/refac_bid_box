## 1. 개요 및 변경 내역 요약

실시간 집계 경로에서 손상값 제외 사실이 사용자 안내(`insufficiency_hints`)로 전달되지 않던 회귀를 시정했습니다.
Wave E1이 제거한 전체 테이블 스캔(`LIKE '%\ufffd%'` probe)을 다시 들이지 않으면서, 스냅샷이 없는 경로에서도 제외 사실이 안내에 정확히 실리도록 조치했습니다.

### 주요 변경 사항
1. **`src/rag/structured_data.py`**:
   - `retrieve_structured_data` 내 `winner_rows`, `institution_rows`, `announcement_rows`의 `live_stmt`에서 `exclude_corrupted()`를 제거하고 `column.is_not(None)`으로 변경.
   - `_top_rows`에서 `LIVE_OVERFETCH_FACTOR`(3배수)로 가져온 행을 `_drop_corrupted()`가 직접 판독하여 제외 건수를 반환하도록 정비.
2. **`tests/test_ranking_snapshots.py`**:
   - `test_live_path_no_hint_when_clean_data`: 정상 데이터 시 안내 문구 미부착 회귀 방지.
   - `test_live_path_announcement_excludes_corrupted`: 실시간 경로 공고 테이블(수요기관, 공고명) 손상값 제외 및 안내 문구 부착 검증.
   - 테스트 간 캐시 격리를 위한 `isolated_cache` fixture 추가.
