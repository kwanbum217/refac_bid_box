## 1. 결론

**`GET /api/v1/bids/compare-stats` 의 캐시 미적중 종단 시간은 두 쿼리가 87% 를 차지합니다.**

| 구간 | P50 | 범위 | 비중 |
| --- | ---: | --- | ---: |
| `agency_announce_top10` | 2,097.1ms | 2,048.0~2,477.3 | **56.3%** |
| `matched_count` | 1,135.5ms | 1,108.0~1,200.1 | **30.5%** |
| `announce_by_month` | 338.9ms | 330.1~348.4 | 9.1% |
| `result_by_month` | 157.9ms | 153.1~161.6 | 4.2% |
| `announcement_summary` | 1.2ms | 1.1~4.3 | 0.0% |
| `result_summary` | 0.5ms | 0.5~0.9 | 0.0% |
| `cache_lookup` | 0.1ms | 0.1~0.1 | 0.0% |
| `cache_store` | 0.2ms | 0.2~0.3 | 0.0% |
| `result_assembly` | 0.0ms | 0.0~0.0 | 0.0% |

최적화 대상의 순위가 확정됐습니다. **기관별 상위 10 집계가 1순위이고 매칭 건수
쿼리가 2순위입니다.** 월별 두 건을 합쳐도 13.3% 이므로 그쪽을 먼저 손대면 종단은
거의 움직이지 않습니다.

## 3. AY1 의 잔여 1.4초 추정은 성립하지 않습니다

**AY1 은 종단에서 SQL 합계를 빼는 방식으로 잔여를 약 1.4초로 추정하고, 그것을
HTTP·FastAPI·SQLAlchemy·조립·Redis 쓰기 구간이라고 기술했습니다.** 이번에는 같은
요청 안에서 두 값을 동시에 재어 직접 비교했습니다.

| 항목 | AY1 추정 | AZ3 실측 |
| --- | --- | --- |
| 비 SQL 구간 | 약 1,400ms | **3.7ms** (`residual_ms`) |
| 클라이언트 왕복과 서버 계측의 차 | 미측정 | **2.3ms** |

`residual_ms` 는 `total_ms - cursor_ms` 이며 파이썬 조립, 캐시 직렬화, 세션
처리를 포함합니다. 종단 wall 과 서버 `total_ms` 의 차 2.3ms 가 HTTP 와 FastAPI
계층입니다. **두 값을 더해도 6ms 대입니다.**

AY1 의 1.4초는 뺄셈의 두 항이 서로 다른 실행에서 온 값이라 생긴 차이로 보이며,
**비 SQL 구간의 비용이라는 해석은 이번 실측으로 뒤집혔습니다.** 이 경로에서
SQL 밖을 최적화해도 얻을 것이 없습니다.

## 4. 측정 전에 계측이 통째로 유실되고 있었습니다

AZ1 의 계측을 켜고 첫 측정을 돌렸을 때 **12회차 전부 `no_candidate` 로 무효**가
났습니다. 하네스가 조용히 채우지 않고 무효로 기록한 것은 설계대로 동작한 것입니다.

원인은 `src/app/main.py` 의 `_enable_latency_segment_logging` 이 **`src.rag.engine`
하나만 보강**한 것입니다. 컨테이너 런타임의 루트 로거는 WARNING 이고 핸들러가
없을 수 있어, 새 계측이 쓰는 `src.app.services.dashboard` 로거의 `logger.info` 가
전부 버려졌습니다. 단위 테스트는 pytest 의 로그 캡처를 쓰므로 이 유실을 드러내지
못했고, 독립 리뷰도 잡지 못했습니다.

보강 대상을 `SEGMENT_LOGGER_NAMES` 상수로 묶어 두 로거를 함께 처리하도록 고쳤고,
회귀 테스트를 추가했습니다.

**부수적으로 확인한 함정이 하나 더 있습니다.** `docker compose up -d app` 은
설정이 바뀌지 않으면 컨테이너를 재생성하지 않습니다. 소스가 바인드 마운트라
파일은 최신인데 **실행 중인 프로세스의 lifespan 은 옛 코드로 이미 끝나 있습니다.**
기동 시 1회 실행되는 코드를 고쳤으면 `docker compose restart app` 을 쓰십시오.

   섞지 마십시오. 잡음 바닥은 회차간 범위이며 그보다 작은 차이는 구별 불가입니다.
