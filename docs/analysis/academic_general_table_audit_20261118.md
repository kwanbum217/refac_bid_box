`resolve_local_service_type` 이 조달분류에서 `ACADEMIC` 을 확정하면 다음 분기를 지납니다.

1. D25 되돌림(`evaluation_rules.py:2906-2911`): `service_type == "ACADEMIC"` 이고 `basis == "PROCUREMENT_CLASS"` 이면서 `not _is_band_only_method(method_name)` 일 때만 `GENERAL`/`UNRESOLVED` 로 되돌립니다. 띠 표기 5건은 `_is_band_only_method` 가 참(`:3650-3653`)이라 **이 되돌림을 타지 않고 `ACADEMIC` 이 유지됩니다.**

```sql
SELECT LEFT(g.rgn_cd, 2) AS sido, COUNT(*) AS rows_all,
       COUNT(DISTINCT a.bid_ntce_no) AS notices
FROM bid_announcements a
JOIN g2b_demand_institutions g
  ON g.dminstt_cd = JSON_UNQUOTE(JSON_EXTRACT(a.raw_data, '$.dminsttCd'))
WHERE a.category = 'Servc'
  AND a.bid_ntce_dt >= '2024-11-18 00:00:00'
  AND JSON_UNQUOTE(JSON_EXTRACT(a.raw_data, '$.pubPrcrmntMidClsfcNm')) LIKE '%학술연구%'
  AND JSON_UNQUOTE(JSON_EXTRACT(a.raw_data, '$.sucsfbidMthdCd')) = '낙030001'
  AND g.rgn_cd IS NOT NULL
  AND LEFT(g.rgn_cd, 2) IN ('11','26','28','30','31')
GROUP BY LEFT(g.rgn_cd, 2)
ORDER BY sido;
```
