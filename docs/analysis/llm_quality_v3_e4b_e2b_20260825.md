## 3. 판정

**현 근거로 e2b 를 승격하지 않습니다.**

- e2b 는 numeric(67.6% vs 61.8%)·문항 단위 통과(18/48 vs 12/48)·지연(P50
  -588ms)·인용(48/48)에서 e4b 를 앞섰고, 근거 검색은 동일(51/51)합니다.
- 그러나 거절해야 하는 미개찰 공고 q18 에서 e2b 는 3회 중 2회 과잉응답했고 e4b 는
  1회입니다. q18 은 근거 없는 정보를 사실처럼 제시하는 안전성 결함이므로, 이
  하나가 numeric 우위보다 무겁습니다.
- v2 대비 두 모델 모두 근거 적중이 올라 numeric·evidence 가 함께 개선됐으나, e2b
  의 q18 과잉응답은 v2(2/3)와 동일하게 재현되어 검색 개선이 이 문제를 해소하지
  못했습니다.
