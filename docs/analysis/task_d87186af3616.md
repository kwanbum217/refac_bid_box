## 1. 개요 및 배경

외부 재감사에서 벤치마크 호스트 부하 지표 산식인 `(os.getloadavg()[0] / cpu_count) * 100`을 코드와 문서에서 "코어당 사용률", "CPU 사용률"로 표기하여 지표의 실제 물리적 의미(1분 정규화 load average)와 혼동을 유발한다는 지적이 있었습니다.

게이트 판정 근거의 기술적 정합성을 확보하기 위해, 본 작업에서는 다음을 수행했습니다:
1. 지표 명칭을 `normalized_load_1m_percent`로 명시화하고 주석·docstring·문서의 "CPU 사용률" 표현을 정규화 1분 load average(%)로 바로잡았습니다.
2. 기존 커밋된 벤치마크 산출물 및 파서와의 하위 호환성을 위해 `per_core_percent` 키를 동일 값의 별칭으로 유지했습니다.
3. 실제 CPU utilization(사용률) 계측은 신규 외부 라이브러리 추가 금지 원칙에 따라 현재 미도입 상태이며, 향후 정밀 프로파일링을 위한 후속 과제임을 문서에 명시했습니다.

## 2. 세부 변경 사항

### 2.1 `scripts/benchmark_provenance.py`
- `single_host_load_sample()`:
  - 산출물 딕셔너리에 `normalized_load_1m_percent` 키를 추가했습니다.
  - `per_core_percent` 키는 하위 호환을 위해 동일 값으로 보존하며 docstring 및 주석에 "normalized_load_1m_percent의 하위 호환 별칭이며 CPU 사용률이 아님"을 명시했습니다.
- `compute_host_load_stats()`:
  - 표본 통계 산출 시 `normalized_load_1m_percent`를 우선 읽고, 없으면 `per_core_percent`로 폴백하도록 구현했습니다.
  - 통계 결과 딕셔너리에 `normalized_load_1m_percent`와 `per_core_percent`를 모두 제공합니다.
- `check_ambient_load_protocol()`:
  - `normalized_load_1m_percent`를 우선 검사하고 `per_core_percent`로 폴백합니다.
  - 반환 detail 딕셔너리에 `normalized_load_median_percent`, `normalized_load_max_percent`를 추가하고 기존 `median_percent`, `max_percent`도 동일 값으로 유지합니다.

### 2.2 `scripts/run_p9_sse_rebaseline.py`
- `AmbientLoadLogger`:
  - 내부 변수명을 `normalized_load_1m_pct`로 수정하고 docstring에 정규화 load average 지표임을 명시했습니다.
  - 콘솔 출력 메시지를 `주변 부하 (정규화 1분 load average)`로 정정했습니다.
  - 기존 CSV 헤더 필드(`load_per_core_pct`)는 호환성을 위해 유지했습니다.

### 2.3 문서 정정 (`docs/ops/latency_gate_protocol.md`, `docs/analysis/arq_harness_blocker_remediation_20260824.md`)
- `docs/ops/latency_gate_protocol.md` 5.3 절:
  - 지표 정의를 "정규화 1분 load average(%)"로 정정했습니다.
  - 실제 CPU utilization(사용률) 계측은 미도입 후속 과제임을 명시하는 안내 블록을 추가했습니다.
- `docs/analysis/arq_harness_blocker_remediation_20260824.md` 2.1 절:
  - `normalized_load_1m_percent` 도입 및 실제 CPU utilization 계측 분리 후속 과제 문단을 추가했습니다.

### 2.4 테스트 보강 (`tests/test_benchmark_provenance.py`)
- `TestCrossPlatformHostLoad`:
  - `single_host_load_sample`의 `normalized_load_1m_percent`와 `per_core_percent` 일치성 검증.
  - `compute_host_load_stats`의 신규 키 산출 및 레거시 표본 폴백 검증.
- `TestAmbientLoadProtocol`:
  - 신규 키(`normalized_load_1m_percent`) 및 구형 키(`per_core_percent`) 각각의 입력에서 임계값(30%/50%) 판정이 동일하게 동작함을 검증.
  - 반환 `detail`에 신규/기존 키가 모두 포함됨을 검증.
