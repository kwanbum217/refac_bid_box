> **상태**: 완료
> **범위**: `scripts/arq_gate.py`, `tests/test_arq_gate.py`, `docs/context/CURRENT_STATE.md`

## 1. 배경

2026-08-24 정식 캘리브레이션으로 경로별 기준선이 확정됐으나, 세 가지 잔여 결함이 있었다.

1. `RepetitionThresholds` 의 `min_throughput_tasks_per_sec`(900.0)와
   `max_p95_latency_ms`(600.0) 기본값이 폐기된 잠정값 그대로여서, thresholds 를
   생략한 호출이 옛 기준으로 판정될 수 있었다.
2. 기준선은 특정 Mac 호스트 실측인데, 코드는 worker_mode 만 보고 기준선을 골라
   다른 호스트의 측정에도 조용히 적용됐다.
3. SSOT 인 `CURRENT_STATE.md` 가 4장(70행)과 6.1장(103행)에서 캘리브레이션
   완료와 미실행을 동시에 서술하는 자기모순을 가졌다.

---

## 2. 변경 내용

### 2.1 폐기된 잠정 임계값 제거

- `RepetitionThresholds` 에서 `min_throughput_tasks_per_sec` 와
  `max_p95_latency_ms` 의 기본값을 제거해 생성 시 반드시 명시하도록 했다.
  (필수 필드는 기본값 필드보다 앞에 배치했다.) `min_runs`(3)와
  `max_failure_rate`(0.0) 기본값은 유지했다.
- `evaluate_repetition_gate` 의 `thresholds` 인자를 필수로 바꾸고
  `thresholds or RepetitionThresholds()` 폴백을 제거했다.
- CLI(`main`)의 반복 판정 경로는 `WORKER_MODE_THRESHOLDS` 프리셋을 명시적으로
  넘기도록 이미 되어 있어 그대로 사용했다.

### 2.2 호스트 결박 (fail-closed)

- 캘리브레이션 호스트 지문 상수를 추가했다.
  `CALIBRATION_HOST_PLATFORM_OS="macos"`, `CALIBRATION_HOST_PLATFORM_ARCH="arm64"`,
  `CALIBRATION_HOST_CPU_COUNT=14`, `CALIBRATION_HOST_PYTHON="3.12.14"`.
  출처는 `data/benchmarks/frozen/arq/<mode>/0ab8c3e/` 의 각 JSON `environment`
  블록이며 주석으로 남겼다.
- `verify_calibration_host(environment, *, allow_mismatch=...)` 를 추가해,
  evidence 의 `environment.platform` 과 `environment.host_cpu_count` 를 지문과
  대조한다. 불일치하면 "재캘리브레이션이 필요하다"는 사유와 함께 `ValueError` 로
  실패 처리한다.
- platform 비교는 OS 계열과 아키텍처 수준으로 정규화해 마이너 버전 차이로
  오탐이 나지 않게 했다(예: `macOS-26.7.1-arm64-arm-64bit` 는 통과).
  host_cpu_count 는 완전 일치를 요구한다.
- 명시적 옵트인 플래그 `ALLOW_CALIBRATION_HOST_MISMATCH`(기본 `False`, fail-closed)를
  두고, `verify_calibration_host` 의 `allow_mismatch` 기본값으로 사용한다.
- 호스트 결박은 파일 로딩 계층(`resolve_repetition_thresholds`, `main` 의
  `--repetition` 경로)에서 evidence 파일의 `environment` 블록을 읽어 적용한다.

### 2.3 테스트

- thresholds 없이 호출하던 테스트 3건을 `IN_PROCESS_THRESHOLDS` 를 명시적으로
  넘기도록 바꿨다(원래 검사하던 임계 미달/통과/실패율 판정 의도 유지).
- 사용자 지정 임계값 테스트는 필수 필드(`max_p95_latency_ms`)를 명시하도록 고쳤다.
- 다음 테스트를 추가했다.
  - `RepetitionThresholds` 를 임계값 없이 생성 불가.
  - `evaluate_repetition_gate` 를 thresholds 없이 호출 불가.
  - 같은 호스트 지문의 증거는 통과.
  - 다른 platform 의 증거는 실패.
  - 다른 host_cpu_count 의 증거는 실패.
  - environment 블록 누락 시 fail-closed.
  - 옵트인 플래그를 주면 통과.
  - 같은 Mac 계열의 마이너 버전 차이는 통과(오탐 방지).
  - 옵트인 기본값이 fail-closed 인지 고정.

### 2.4 SSOT 정합

- `CURRENT_STATE.md` 103행의 낡은 서술("잠정 봉투는 캘리브레이션 미실행으로
  유지")을 현재 사실로 고쳤다: 2026-08-24 정식 경로별 10회 캘리브레이션으로
  잠정 봉투가 폐기됐고 게이트는 경로별 정식 임계값을 사용하며, production
  business-task E2E 는 여전히 미측정이다.
- 문서 전체에서 캘리브레이션 상태를 말하는 다른 낡은 서술이 없는지 훑었고
  70행(완료)과 103행(완료·E2E 미측정)이 모순되지 않음을 확인했다.
