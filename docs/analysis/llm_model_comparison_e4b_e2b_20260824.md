## 3. 답변 품질 비교 (5문항)

하네스 정본 질의 5종에 대해 두 모델의 답변을 같은 조건에서 받아 대조했습니다.
각 모델 워밍 1회 후 측정했습니다.

| # | 질의 | 정확도 | 충실도 우세 |
| ---: | --- | :---: | :---: |
| 1 | 적격심사 기준이 어떻게 되나요 | 양쪽 정상 | 대등 |
| 2 | 2025년 물품 낙찰 평균 낙찰률 | 양쪽 91.1075% 동일 | 대등 |
| 3 | 공사 부문 최근 낙찰 동향 | 양쪽 정상 거절 | **e4b** |
| 4 | 수요기관별 낙찰 금액 상위 | 양쪽 정상 | **e2b** |
| 5 | 용역 계약 방법 | 양쪽 정상 거절 | **e4b** |

### 3.1 관찰

- **"사실 오류 0건"은 지면 대조 한정 판정입니다.** 5문항 모두 답변이 그럴듯해
  눈으로 확인한 범위에서 명백한 오류를 찾지 못했습니다. 다만 **ground truth(정답
  참조) 대조는 수행하지 않았으므로** 수치·사실의 정확성은 이 비교의 판정 범위가
  아닙니다. 컨텍스트가 부족한 문항은 4문항 (1·3·4·5)입니다. 이 중 3·5는 두 모델
  다 근거 없음을 명시하고 답변을 거절했고, 1·4는 답변은 했으나 충분한 컨텍스트가
  없었습니다. 근거 표기 (`근거: DB 집계 기반` / `Chroma 문맥 기반`)도 양쪽 다
  정상입니다
- **DB 집계 경로(2번)는 결과가 완전히 같습니다.** 이 경로는 LLM 이 수치를
  만들지 않고 집계 결과를 서술만 하므로 모델 교체 영향이 작습니다
- **3·5번은 e4b 가 낫습니다.** e4b 는 거절하면서 검색된 컨텍스트 항목을
  분류와 함께 열거해 왜 답할 수 없는지를 검증 가능하게 보여줍니다. e2b 는
  같은 결론을 요약만 합니다
- **4번은 e2b 가 낫습니다.** 세 기관을 모두 순위화하고 차트 캔버스
  (`<canvas class='chat-chart' ...>`)까지 생성했습니다. e4b 는 "통계 데이터가
  없어 비교 분석이 불가능" 이라 해 놓고 곧바로 비교를 수행하는 **자기모순**이
  있습니다. 이는 위 "사실 오류 0건" 판정(지면 대조 한정, ground truth 부재)이
  포착하지 못한 논리 결함입니다

### 3.2 판정 불가

**5문항은 품질을 판정할 표본이 아닙니다.** 우세가 2 대 1로 갈렸고 그 차이도
정확도가 아니라 서술 충실도입니다. 이 표본으로는 다음을 구분할 수 없습니다.

- 모델 간 실제 품질 차이인지, 생성 온도에 따른 회차 변동인지
- 4번의 차트 생성이 e2b 의 능력인지 우연인지
- 컨텍스트가 충분한 질의에서 어느 쪽이 더 정확한지 (이번 5문항 중 컨텍스트가
  충분했던 것은 2번 하나뿐입니다)

## 4. 판정과 권고

**승격하지 않습니다.** 속도만 보고 승격하지 않는 것이 잔여 과업 명세의 완료
기준입니다.

| 축 | 상태 |
| --- | --- |
| 속도 | **e2b 우세 확정.** `llm_ms` P50 -54.1%, P95 -26.2% |
| 정확도 | **회귀 없음 관측.** 단 5문항이라 확정 불가 |
| 충실도 | **판정 불가.** 2 대 1로 갈림 |

### 4.1 승격하려면 필요한 것

1. **컨텍스트가 충분한 질의를 늘린 품질 세트.** 이번 5문항 중 4문항이 컨텍스트
   부족(1·3·4·5)이어서, 정작 생성 품질이 갈리는 구간을 재지 못했습니다
2. **같은 질의 반복 측정.** 1회 답변으로 모델 차이와 생성 변동을 구분할 수
   없습니다
3. **SSE 경로 품질.** 이번 비교는 단발 질의만 봤습니다

### 4.2 승격하지 않아도 얻은 것

현행 e4b 의 `llm_ms` P50 2,839.93ms 는 **부하 규약을 지킨 조건에서 처음 잰
값**입니다. 이전 3,681.90ms 는 오염된 값이었습니다. LLM 최적화의 출발점을
이 값으로 잡으십시오.
