## 3. 기관별 산식 값과 원문 인용

### 3.1 추출 방법과 재현

PDF 는 `pdfplumber`, HWPX 는 `zipfile`, HWP 는 저장소의 기존 추출기를 썼다. 새 라이브러리를 설치하지 않았다(설치된 `pdfplumber` 0.11.10 확인, 이번 원문 3건은 모두 HWP 라 PDF 경로는 쓰지 않았다).

HWP 본문은 `scripts/extract_score_params.py` 의 `_ole_streams`, `_hwp_records`, `_hwp_para_text` 를 그대로 import 해 `Section0`~`SectionN` 레코드를 문단 단위로 풀었다. 이 세 함수는 저장소가 이미 쓰는 코드이고 고치지 않았다.

```python
import sys
sys.path.insert(0, "scripts")
import extract_score_params as esp
from pathlib import Path
import re

def dump(src: Path) -> list[str]:
    streams = esp._ole_streams(src.read_bytes())
    out: list[str] = []
    for name in sorted(streams):
        if not re.fullmatch(r"(BodyText/)?Section\d+", name):
            continue
        out.append(f"##### {name}")
        for tag, level, payload in esp._hwp_records(streams[name]):
            if tag == esp._HWP_TAG_PARA_TEXT:
                t = esp._hwp_para_text(payload)
            elif tag == esp._HWP_TAG_EQEDIT:
                t = "[EQ]" + esp._hwp_para_text(payload)
            else:
                continue
            if t:
                out.append(t)
    return out
```

받은 파일의 `sha256`, 출처 URL, 받은 날짜, 판본은 2.1·2.3절 표에 적었다.

### 4.2 비교에서 읽는 것

1. **구간 축은 세 문서가 모두 같다.** B·k·T·구간 경계(10억원, 5억원, 고시금액)가 조달청 기술용역 별표 1 과 일치한다. 두 기관은 조달청 별표를 자기 문서에 옮겨 적은 것으로 읽힌다.
2. **다른 것은 기준비율 하나다.** 그리고 기준비율이 바뀌면 평탄 비율 네 개와 하한율 네 개가 함께 따라 바뀐다. 이는 평탄 비율이 `기준비율 + (100-T)/k` 라는 관계에서 나오기 때문이다.
3. **한국지역난방공사 2026-08-18 판본은 조달청 현행 90판과 값이 전부 같다.** 기준비율·평탄 비율·하한율이 4구간 모두 일치한다. 조달청이 2026-05-26 에 90 으로 올린 것을 이 기관이 2026-08-18 에 따라잡은 형태다.
4. **인천국제공항공사는 조달청 88판과 값이 전부 같다.** 2023-07-24 시행판이 조달청 2022-11-01 판(기준비율 88)을 그대로 옮긴 것이고, 그 뒤 조달청이 두 차례(2025-09-01, 2026-05-26) 개정한 것을 반영하지 않았다. 2026-10-27 공고까지 88 계열인 관측과 맞는다.

### 4.3 선행 보고서의 2.0%p 차이와의 정합

선행 보고서 3.5절은 `2026-05-26` 이후 60건 중 55건이 2.0%p 벌어진다고 적었다. 이 집계는 **이미 판본 전환을 반영한 값**이다. 원문으로 분해하면 다음과 같다.

| 기간 | 기관 | 공고 수 | 실제 기준비율 | 조달청 현행(0.90)과 차이 | 차이 2.0%p 건수 |
| --- | --- | ---: | ---: | --- | ---: |
| 2026-05-26 이전 | KDHC | 10 | 88 | 조달청 구판(0.88)과 같다 | 0 |
| 2026-05-26 이전 | IIAC | 18 | 88 | 조달청 구판(0.88)과 같다 | 0 |
| 2026-05-26 ~ 2026-08-17 | KDHC | 37 | 88 | **2.0%p 낮다** | 37 |
| 2026-08-18 이후 | KDHC | 5 | 90 | 같다 | 0 |
| 2026-08-18 이후 | KDHC | 1 | 88 | **2.0%p 낮다** | 1 |
| 2026-05-26 이후 | IIAC | 17 | 88 | **2.0%p 낮다** | 17 |
| **합계** | | **88** | | | **55** |

검산은 이렇다. KDHC 차이 2.0%p = 37 + 1 = **38**, IIAC 차이 2.0%p = **17**, 합계 **55** 다. KDHC 차이 0 = 10 + 5 = **15**. 이는 선행 보고서의 기관별 표(KDHC 15/38, IIAC 18/17)와 정확히 같다.

**따라서 선행 보고서의 55건은 판본 전환을 반영하지 않은 값이 아니라, 이미 반영한 값이다.** 이번 원문 확보로 바뀌는 것은 그 55건의 **원인 규명**이다. 선행 보고서는 이를 "조달청과 2.0%p 벌어진다"고만 적었고, 이제 그 원인이 두 기관 기준원문에 인쇄된 기준비율 88 임을 원문 줄로 확인했다.

남는 확인 과제는 2026-08-18 이후 KDHC 6건 중 1건(`R26BK01705209`, 2026-08-31, 공고 인쇄 87.745)이다. 이 공고는 2026-08-18 시행판이 적용되어야 하는데 88 계열 값을 인쇄했다. 선행 보고서 5절도 이 건을 미확정으로 남겼다. 이번 Task 로는 원인을 확정하지 못했다(6절).
