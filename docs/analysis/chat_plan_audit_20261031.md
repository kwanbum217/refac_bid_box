### 1.3 조사 사이의 관계

- `definition_inst` 가 원인을 확정하고 수정이 병합된 뒤, `definition_residual` 이 같은 계열의 잔여 누수를 합성 108건으로 다시 측정했다. 잔여 수정은 아직 병합 대기다.
- `real_utterance` 는 실사용 전량을 훑어 유형을 나눴다. 유형 A·B 대표 사례는 `definition_inst` 수정과 중복이어서 신규 작업에서 제외했고, 유형 D(지난 한 달)와 A(공고번호) 수정은 이미 main 에 병합됐으며 A(지역 부분 문자열)는 리뷰 pass 로 병합 대기 중이다. 유형 C(유찰)는 수정 브랜치가 없고 데이터가 없어 라우팅을 바꾸면 안 된다. 유형 F 중 사정률·경쟁률은 코드 결함이 아니라 데이터 공백이며 가드가 처리하고, 금액대별은 사용자 결정 사항이다.
- `fail_bid` 는 `real_utterance` 의 유형 C·F 를 데이터 경로 수준에서 다시 확인해, 유찰은 라우팅이 아니라 수집 문제이고 사정률·경쟁률은 가드가 막고 있음을 확정했다.
- `time_compare` 가 제안한 형태 제한안의 비용을 `inst_suffix` 가 운영 DB 커버리지로 측정했다. 두 조사는 같은 수정안의 앞뒤 단계다.
- `kb_sql_reason` 이 합성으로 재현한 조합을 `kb_status_marker` 가 실사용 빈도로 재평가해 우선순위를 낮췄다. `amount_band` 는 다른 조사와 독립이다.

- 기간 비교는 질문 세트에 1건뿐이라 회귀 방어가 사실상 없다. 합성 155건이 현재 유일한 근거다.
