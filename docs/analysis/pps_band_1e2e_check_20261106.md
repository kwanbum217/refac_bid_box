## 1. 요약

### 1.1 결론

조달청 일반용역 적격심사 세부기준의 공고 적용판인 제2025-257호(시행 2025-09-01)와 현행 제2026-390호(시행 2026-07-27) 원문에는 **추정가격 2억원 미만 1억원 이상 띠가 없다.** 가격 축은 다음 둘뿐입니다.

1. 비가격 배점한도: `추정가격 5억원 이상` / `추정가격 5억원 미만`
2. 입찰가격 계산식: `추정가격 고시금액 이상`(평점계수 k=2) / `추정가격 고시금액 미만`(k=4)

따라서 이 띠를 위한 신규 PPS 규칙을 등록할 원문 근거는 없습니다. 첨부가 지목한 별표(학술연구용역 등)의 **기존 고시금액 띠 규칙**으로 계산하는 것이 원문상 맞습니다. 세 건 모두 첨부 판별이 `PPS` 이고 공고문이 조달청 [별표 1] 학술연구용역을 지목하므로, 추정가격 1.09억~1.55억은 `고시금액 미만`(고시금액 2.3억)에 해당합니다.

현재 `RULE_NOT_FOUND` 는 원문에 없는 띠를 찾지 못해서가 아니라, **낙찰방법명 문자열만으로 별표를 매칭하는 코드 경로**(`src/app/services/evaluation_rules.py:3746-3756`)가 `적격심사제-추정가격 2억미만 1억이상` 을 어떤 PPS 규칙 패턴과도 맞추지 못하고, 첨부 기반 구제 분기(`:3478-3506`)는 `MOIS_ACADEMIC`·`MOIS_TECH` 만 대상으로 하기 때문입니다.

### 2.2 띠 구조

제2025-257호 [별표 1] 학술연구용역 적격심사 원문입니다.

- 심사항목 및 배점한도: `추정가격 5억원 이상` / `추정가격 5억원 미만` 두 열이고, `Ⅱ. 입찰가격` 배점한도가 각각 `60` / `70` 입니다.
- 입찰가격 계산식:
  - `추정가격 고시금액 이상`: `평점(점) = 배점한도 - 2 × |(88/100 - 입찰가격/예정가격) × 100|`
  - `추정가격 고시금액 미만`: `평점(점) = 배점한도 - 4 × |(88/100 - 입찰가격/예정가격) × 100|`
- 낙찰자 결정: `제10조(낙찰자 결정) ①최저가 입찰자에 대한 심사결과 종합평점이 85점(다만, 소프트웨어용역의 중소기업자간 경쟁제품, 여객 육상운송용역은 88점)이상이면 낙찰자로 결정한다.`
- [별표 2] 시설분야용역도 같은 방식입니다. `추정가격 5억원 이상` / `5억원 미만` 이고, 입찰가격 계산식은 `평점(점) = 배점한도 - 5 × |(91/100 - 입찰가격/예정가격) × 100|` 입니다.

제2026-390호도 [별표 1] 학술연구용역의 비가격 배점한도를 `추정가격 5억원 이상` / `5억원 미만` 으로 나누고, 입찰가격 계산식은 `추정가격 고시금액 이상`(k=2) / `고시금액 미만`(k=4)으로 유지합니다.

### 4.3 수정 제안

코드는 이번 작업에서 고치지 않았습니다. 후속 작업 후보는 다음과 같습니다.

1. **A안(권고): PPS 첨부 별표를 세분화해 기존 규칙에 매핑한다.** 첨부 텍스트에서 `[별표 1] 학술연구용역`·`[별표 2] 시설분야용역` 같은 별표 표지를 읽어, `PPS` 라벨과 함께 별표 식별자를 판정 함수에 넘깁니다. `2억미만`·`1억이상` 표기이면서 `contract_regime != "NATIONAL"` 이고 `RULE_NOT_FOUND` 인 경우에만, 별표 식별자와 추정가격(고시금액 대비)으로 기존 `SERVC_QUAL_*_ATTACH_06/07`(학술연구) 또는 `ATTACH_01`(시설분야)을 고릅니다. `:3478-3506` 의 행안부 분기와 같은 모양입니다.
2. **B안(비권고): 1억~2억 PPS 띠 규칙을 신규 등록한다.** 원문에 없는 띠를 만드는 것이므로 권고하지 않습니다. 고시금액·5억원 두 축을 깨고, 다른 공고에도 없는 구간을 추정하게 됩니다.
3. **C안(임시): 대상 3건의 낙찰방법명과 첨부 별표를 직접 매핑한다.** 빠르지만 공고마다 별표가 달라지면 다시 막힙니다. A안이 일반적입니다.
4. **기존 사용자 결정은 유지한다.** 조달청 대행 배제, 별표 시행일 불일치 차단(`RULE_REGIME_MISMATCH`), 전남만 준용, 산림청 미등록을 뒤집는 제안은 하지 않습니다.

### 4.4 예상 영향

A안을 적용하면 세 건은 `RULE_NOT_FOUND` 에서 `SERVC_QUAL_PRE_20250901_ATTACH_06` 으로 풀립니다. 다만 `:3779-3785` 는 공고에 하한율이 있으면 별표 기본값보다 우선하므로, R25BK01248793 은 공고의 `88%`, R25BK01255918 은 공고의 `80.495%` 가 그대로 쓰입니다. R25BK01255918 의 `80.495%` 는 원문의 고시금액 미만 산식(84.245%)과 다르므로, 값 우선순위 결정이 함께 필요합니다.

## 5. 사용자 결정 항목

1. **PPS 첨부 별표 세분화 여부**: A안(별표 식별자 추가 후 기존 규칙 매핑)으로 갈지, C안(대상 3건 임시 매핑)으로 갈지 결정이 필요합니다.
2. **R25BK01255918 의 하한율**: 공고 인쇄값 `80.495%` 를 우선할지, 원문 고시금액 미만 산식값 `84.245%` 를 우선할지 결정이 필요합니다. 공고값 우선은 현행 `:3779-3785` 동작과 일치하지만, 원문 구간과는 어긋납니다.
3. **R25BK01248793 의 88% 해석**: 공고문의 `낙찰하한율 88%` 가 산식 기준비율 표기인지 실제 하한율 표기인지 확인이 필요합니다. 원문 산식으로 유도한 값은 `84.245%` 입니다.
4. **1억~2억 PPS 띠 신규 등록 금지 동의**: 원문에 띠가 없으므로 신규 등록하지 않는 방향(현 상태 유지 + 별표 매핑)에 동의하는지 확인이 필요합니다.

기존 사용자 결정(조달청 대행 배제, 시행일 불일치 차단 유지, 전남만 준용, 산림청 미등록)은 이 문서에서 뒤집지 않습니다.
