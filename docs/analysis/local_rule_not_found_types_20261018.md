# LOCAL_RULE_NOT_FOUND 차단 공고의 지역·용역 유형별 원문 별표 유무 조사

> **작성일**: 2026-10-18

> **범위**: 조사 문서 한 건. 코드·규칙·원장은 변경하지 않았다.

## 1. 요약

1. `.cache/blocks.json` 의 179건은 모두 `LOCAL_RULE_NOT_FOUND` 다. 지역·용역 유형 조합은 22개(미상 4개 포함)이고, 시·도 7곳(전남광주통합특별시, 전라남도, 충청남도, 대구광역시, 광주광역시, 세종특별자치시, 미상)으로 갈린다.
2. 등록된 `LOCAL_RULES` 에 그 시·도·세부유형이 없는 조합이 179건 전부다. 즉 지역 규칙 자체가 없는 것이 아니라, 그 시·도 세부기준 원문에 해당 유형 별표가 없거나 등록되지 않은 세부유형으로 떨어진 경우다.
3. 원문에 해당 유형 별표가 **있는** 조합은 0건이다. 별표 부재 라벨은 둘로 나뉜다. `원문 별표 없음(원문 확인)` 6개 조합 69건(전남광주통합특별시 5개 유형 65건 + 광주광역시 보험 4건)은 그 시·도 세부기준 원문을 직접 읽어 해당 유형 별표가 없음을 확인한 경우다. `원문 별표 없음(목록 근거, 원문 미확인)` 16개 조합 110건은 수집 문서의 등급·별표 목록에 의존하며 본 조사에서 원문을 직접 확인하지 않았다. 조달청 기준 준용 근거도 같은 분기다. `준용 근거 확인`은 위 6개 조합뿐이다(광주 예규 제377호와 전남광주통합특별시 예규 제3호에서 준용 조항을 원문으로 직접 인용한 곳). 나머지 16개 조합은 `준용 근거 미확인`이다. `조달청 기준으로 넘기는 것이 원문상 맞다`는 일반 결론은 쓰지 않는다. 조달청 기준으로 넘길지는 사용자 결정 사항이다.
4. `추정가격 2억미만 1억이상` 36건(지역업체참여 변형 2건 포함, 총 38건)은 `docs/analysis/band_2to1_basis_20261018.md` 결론을 인용하여 원문 조사 대상에서 제외하고 집계만 한다. 그 문서의 결론: 같은 낙찰방법명 안에서도 적용 기준이 행안부 예규 제2장의2 별표 4 (56건), 미확인 (36건), 지자체 자체 기준 (4건), 조달청 일반용역 학술연구 (2건), 행안부 예규 제4장 물품 (1건)으로 갈리며, 갈래는 첨부·표준 공고문 원문의 지정 문구로만 판별 가능하다(첨부 원문으로만 판별 가능).

## 2. 집계 기준과 재계산

- 공고 자료는 `.cache/blocks.json` 179건만 쓴다. DB·docker·mysql 은 쓰지 않았다.
- 세부유형은 `resolve_local_service_type(낙찰방법명)` 으로 정한다. 미상 21건은 `dminstt_nm` 으로 지역을 추정했다.

재계산 스크립트(그대로 실행):

```python
import json
from collections import Counter
from src.app.services.evaluation_rules import resolve_local_service_type, LOCAL_RULES
d=json.load(open('.cache/blocks.json'))
reg={}
for r in LOCAL_RULES:
    reg.setdefault(r.region_name, set()).add(r.service_type)
missing=Counter()
for r in d:
    st, basis, _ = resolve_local_service_type(r, r['sucsfbidMthdNm'])
    region = r['region_name'] or '미상'
    present = reg.get(r['region_name'], set())
    if st not in present:
        missing[(region, st)] += 1
print('total', len(d))
print('combos', len(missing))
for k,v in sorted(missing.items()):
    print(v, k)
```
