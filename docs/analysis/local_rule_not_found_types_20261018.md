# LOCAL_RULE_NOT_FOUND 차단 공고의 지역·용역 유형별 원문 별표 유무 조사

> **작성일**: 2026-10-18
> **기준 원장**: `.cache/blocks.json` (179건, 코디네이터 확인 사실)
> **판정 코드**: `src/app/services/evaluation_rules.py` (`_select_local_rule`, `resolve_local_service_type`)
> **범위**: 조사 문서 한 건. 코드·규칙·원장은 변경하지 않았다.

## 1. 요약

1. `.cache/blocks.json` 의 179건은 모두 `LOCAL_RULE_NOT_FOUND` 다. 지역·용역 유형 조합은 35개(미상 9개 포함)이고, 시·도 7곳(전남광주통합특별시, 전라남도, 충청남도, 대구광역시, 광주광역시, 세종특별자치시, 미상)으로 갈린다.
2. 등록된 `LOCAL_RULES` 에 그 시·도·세부유형이 없는 조합이 179건 전부다. 즉 지역 규칙 자체가 없는 것이 아니라, 그 시·도 세부기준 원문에 해당 유형 별표가 없거나 등록되지 않은 세부유형으로 떨어진 경우다.
3. 원문에 해당 유형 별표가 **있는** 조합은 0건이다. 전남광주통합특별시·충청남도·세종·대구·광주광역시 원문의 별표 목록에 빠진 유형(보험·임대차·수리점검·학술·일반 등)은 원문에도 없고, 조달청 기준으로 넘기는 근거는 시·도 세부기준의 "정하지 않은 사항은 조달청 일반용역 적격심사 세부기준을 준용" 류 조항(또는 삭제된 별표의 대체)에 의존한다. 본 조사에서 원문 준용 조항을 직접 인용한 곳은 광주광역시 예규 제377호 폐기물·육상운송 별표와 전남광주통합특별시 예규 제3호 1~6 별표뿐이며, 나머지는 수집 문서의 등급과 별표 목록에 의존했다.
4. `추정가격 2억미만 1억이상` 36건(및 지역업체참여 변형 2건)은 `docs/analysis/band_2to1_basis_20261018.md` 결론에 따라 원문 조사 대상에서 제외하고 집계만 한다. 이들은 조달청 띠 표기(GENERAL)로 보이며 지역 규칙과 무관하다.

## 2. 집계 기준과 재계산

- 공고 자료는 `.cache/blocks.json` 179건만 쓴다. DB·docker·mysql 은 쓰지 않았다.
- 세부유형은 `resolve_local_service_type(낙찰방법명)` 으로 정한다. 미상 21건은 `dminstt_nm` 으로 지역을 추정했다.

재계산 스크립트(그대로 실행):

```python
import json
from collections import Counter
from src.app.services.evaluation_rules import resolve_local_service_type, LOCAL_RULES
d=json.load(open('.cache/blocks.json'))
reg={r.region_name: {x.service_type for x in LOCAL_RULES if x.region_name==r.region_name} for r in LOCAL_RULES}
# unique regions
regs=sorted({r.region_name for r in LOCAL_RULES})
missing=Counter()
for r in d:
    st, basis, _ = resolve_local_service_type(r, r['sucsfbidMthdNm'])
    region = r['region_name'] or '미상(기관명 추정)'
    present = reg.get(r['region_name'], set())
    if st not in present:
        missing[(region, st)] += 1
print('total', len(d))
print('combos', len(missing))
for k,v in sorted(missing.items()):
    print(v, k)
```

- 원문: 자치법규정보시스템 `alrNo=12000042005020`, `histNo=001` (수령 2026-10-04, sha256 미기록).
