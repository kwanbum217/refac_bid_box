## 1. 배경 및 문제

`arq_calibration_design_20260824.md` 구버전 6.2/6.3의 기준선 도출식은 분위수와 최악값 마진을 `max`로 결합했다. 이 두 식은 수학적으로 퇴화하여 두 항 중 한 항이 **항상** 지배한다. 10회 정식 캘리브레이션을 실행하기 전에 이 산식을 고쳐야 한다. 지금 실행하면 통계적으로 그럴듯하지만 의도와 다른 기준선이 만들어진다.

## 2. 퇴화 증명과 대안 설계

### 2.1 처리량식 퇴화

구버전 처리량 기준선:

```
throughput_baseline = max(Q_p(T, 0.05), min(T) * 0.95)
```

대소 관계를 보면 항상 다음이 성립한다.

- `Q_p(T, 0.05) >= min(T)` : 5% 분위수는 표본의 최소값 이상이다.
- `min(T) > min(T) * 0.95` : 0.95배는 항상 원래 값보다 작다.

따라서 `Q_p(T, 0.05) >= min(T) > min(T) * 0.95` 이므로, 이 식은 **항상 `Q_p(T, 0.05)`로 축약**되고 둘째 항은 절대 선택되지 않는다.

### 2.2 P95식 퇴화

구버전 P95 지연 기준선:

```
p95_baseline = max(Q_p(P, 0.95), max(P) * 1.05)
```

- `max(P) * 1.05 > max(P)` : 1.05배는 항상 원래 값보다 크다.
- `max(P) >= Q_p(P, 0.95)` : 최대값은 95% 분위수 이상이다.

따라서 `max(P) * 1.05 > max(P) >= Q_p(P, 0.95)` 이므로, 이 식은 **항상 `max(P) * 1.05`로 축약**되고 첫째 항은 절대 선택되지 않는다.

### 2.3 n=10에서 꼬리 분위수의 문제

계획 회차 수는 n=10이다. n=10에서 5%/95% 꼬리 분위수는 사실상 표본의 최소값·최대값에 붙는다. 최소값·최대값은 outlier에 취약하므로, 꼬리 분위수를 기준선으로 쓰면 단일 회차의 이상 측정이 기준선을 왜곡할 수 있다.

### 2.4 대안: 중앙값 기반 + 분리 판정

두 항을 `max`로 섞는 형태를 폐기하고, **중앙값 기반** 접근으로 대체한다. 기준선 추정, 회귀 게이트, 반복 안정성 판정을 서로 다른 기준으로 분리한다.

| 판정 | 방식 | 선택 이유 |
| --- | --- | --- |
| 기준선 추정 | `median(T)`, `median(P)` | outlier 강건, n=10에서 꼬리 분위수(최소·최대) 왜곡 회피 |
| 회귀 게이트 | 상대 허용 비율 `rt = max(3 * CV, 0.06)`, `rp = max(3 * CV, 0.06)` | 기준선 대비 열화 폭을 관측 변동성에서 유도, 절대 상수 아님 |
| 반복 안정성 | `CV` + `MAD/median` | 회차 간 변동성을 기준선과 독립적으로 판정 |

이 설계는 "중앙값을 기준선으로 두고 회귀 허용 범위를 별도 비율로 정의하는 단순 방식"과 "중앙값과 MAD/부트스트랩 신뢰구간으로 변동성 판정을 회귀 게이트와 분리하는 통계 방식" 중 **통계 방식**을 채택한 것이다. MAD 기반 반복 안정성 판정을 추가해 회귀 게이트와 기준선 추정을 서로 독립된 임계값으로 운영한다.

## 3. 새 산식 정의

### 3.1 기준선 추정 (중앙값)

```
throughput_baseline = median(T)
p95_baseline        = median(P)
failure_baseline    = 0
```

- `failure_baseline = 0`은 전제 조건이다. 정상 경로 캘리브레이션이므로 실패율 기준선을 0으로 고정하며, `max(F) > 0`이면 기준선 도출 자체가 무효여서 런 전체를 기각한다.

### 3.2 회귀 게이트 (상대 허용 비율)

```
rt = max(3 * CV(T), 0.06)
rp = max(3 * CV(P), 0.06)

throughput_regression_fail : t_measured < throughput_baseline * (1 - rt)
p95_regression_fail        : p_measured > p95_baseline * (1 + rp)
```

- 회귀 허용 비율은 관측 변동성에서 유도한다. **원칙: 회귀 허용 폭은 반드시 반복 안정성 임계값(`cv_max = 0.05`)보다 엄격히 커야 한다(`rt > cv_max`, `rp > cv_max`).** CV 상한 0.05를 정상 변동으로 허용하면서 기준선 대비 5% 열화를 회귀로 판정하면 정상 변동 범위 안의 측정이 회귀로 잡혀 오탐이 잦아진다. `3 * CV` 항과 하한 0.06이 이 엄격 부등식을 항상 성립시킨다. 하한을 0.06으로 둔 이유는 CV가 아주 작아 `3 * CV < 0.05`가 되는 경우 하한 0.05가 `cv_max`와 등호가 되어 원칙을 위반하기 때문이다.

### 3.3 반복 안정성 판정 (변동성)

```
안정: CV(T) <= 0.05, CV(P) <= 0.05
      MAD(T) / median(T) <= 0.03, MAD(P) / median(P) <= 0.03
```

- `m_ratio = 0.03`: 정규분포에서 MAD는 표준편차의 약 0.67배이므로 `MAD/median ≈ 0.67 * CV`이다. `cv_max = 0.05`일 때 `MAD/median ≈ 0.034`이므로 `m_ratio = 0.05`는 CV 판정보다 느슨해 보조 지표 역할을 못 한다. `0.03`으로 조여 CV보다 엄격하게 만들어 outlier를 잡는 보조 지표로 유지한다.

## 4. 수치 예시 (예시 계산용, 정식 기준선 승격 아님)

기존 3회 synthetic 실측값(예시 계산용)에 새 산식을 적용한다.

| 지표 | 회차값 | median | mean | stdev | CV | MAD | MAD/median |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 처리량 (jobs/sec) | 1681, 1710, 1764 | **1710** | 1718.33 | 42.12 | 0.0245 | 29 | 0.0170 |
| P95 지연 (ms) | 325, 333, 342 | **333** | 333.33 | 8.50 | 0.0255 | 8 | 0.0240 |

### 4.1 기준선 추정 결과

```
throughput_baseline = median(1681, 1710, 1764) = 1710 jobs/sec
p95_baseline        = median(325, 333, 342)    = 333 ms
failure_baseline    = 0 (전제 조건)
```

### 4.2 회귀 게이트 (관측 변동성에서 유도)

```
rt = max(3 * CV(T), 0.06) = max(3 * 0.0245, 0.06) = 0.0735
rp = max(3 * CV(P), 0.06) = max(3 * 0.0255, 0.06) = 0.0765

처리량 회귀 판정선 = 1710 * (1 - 0.0735) = 1584.3 jobs/sec 미만이면 회귀
P95 회귀 판정선    = 333 * (1 + 0.0765)  = 358.5 ms 초과면 회귀
```

- `rt`, `rp`가 관측 CV의 3배로 `cv_max = 0.05`보다 크므로, 정상 변동 범위 안의 측정이 회귀로 오판되지 않는다.

### 4.3 반복 안정성 판정

```
CV(T) = 0.0245 <= 0.05 (통과)
CV(P) = 0.0255 <= 0.05 (통과)
MAD(T)/median(T) = 0.0170 <= 0.03 (통과)
MAD(P)/median(P) = 0.0240 <= 0.03 (통과)
```

이 3회 synthetic 표본은 변동성 판정을 통과하므로, 위 예시 기준선과 회귀 게이트는 유효한 예시로 성립한다. **이 값들은 예시 계산용이며 정식 기준선으로 승격하지 않는다.** 정식 기준선은 n=10 캘리브레이션 런 결과로만 도출한다.

### 4.4 구버전 대비 의미 차이

구버전식(퇴화)으로는 처리량 기준선이 항상 `Q_p(T, 0.05)`, P95 기준선이 항상 `max(P) * 1.05`가 되어, P95 지연 기준선은 최악 회차보다 항상 5% 높게, 처리량 기준선은 하위 5% 지점으로 고정됐다. 새 중앙값 방식은 분포의 대표 위치를 기준선으로 두고, 열화 폭을 회귀 게이트로 분리해 "기준선 자체"와 "허용 열화"를 혼동하지 않는다.
