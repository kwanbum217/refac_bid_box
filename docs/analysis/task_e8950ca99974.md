# Chart.js / marked CDN 로컬화 분석 보고서

> **작성일**: 2026-08-26
> **태스크 ID**: task_e8950ca99974
> **대상**: `bids/dashboard.html`, `bids/compare.html`, `chatbot/chat.html`

---

## 1. 개요

2026-08-25 `base.html` 로컬화 이후 잔여 외부 CDN 참조 4건(Chart.js 3곳, marked 1곳)을 `src/app/static/vendor/` 로 이관하여 애플리케이션 Jinja2 템플릿의 외부 자산 참조를 0건으로 만들었다.

---

## 2. 로컬화된 벤더 자산

| 자산 | 버전 | 원본 URL | 로컬 경로 | SHA-256 |
| --- | --- | --- | --- | --- |
| Chart.js UMD | 4.5.1 | `https://cdn.jsdelivr.net/npm/chart.js@4.5.1/dist/chart.umd.min.js` | `vendor/chartjs/4.5.1/chart.umd.min.js` | `48444a82d4edcb5bec0f1965faacdde18d9c17db3063d042abada2f705c9f54a` |
| marked | 15.0.12 | `https://cdn.jsdelivr.net/npm/marked@15.0.12/marked.min.js` | `vendor/marked/15.0.12/marked.min.js` | `3e7e7d7feb3e5d58cb6c804f68ab5c24cc7e5eb6270fd6e5cbb9124739217d0c` |

버전은 기존 무버전 CDN URL(`cdn.jsdelivr.net/npm/chart.js`, `cdn.jsdelivr.net/npm/marked/marked.min.js`)이 jsdelivr에서 해석하는 최신 안정 배포본과 동일하다.

---

## 3. 템플릿 변경

| 템플릿 | 변경 내용 |
| --- | --- |
| `bids/dashboard.html` | Chart.js CDN -> `url_for('static', path='vendor/chartjs/4.5.1/chart.umd.min.js')` |
| `bids/compare.html` | 동일 |
| `chatbot/chat.html` | Chart.js + marked CDN -> 로컬 vendor 참조 (`extra_js` 블록, 인라인 스크립트 이전 유지) |

스크립트 로드 순서: Chart.js -> marked -> 인라인 `$(document).ready` (기존과 동일).
