## 3. 전수 판정 회귀

### 3.1 방법

`scripts/report_rule_coverage.py` 의 `collect_records(months=12, category="Servc",
method_code="낙030001", today=date(2026, 11, 7))` 를 메모리에서 두 번 실행했습니다.
DB 세션은 `collect_records` 가 여는 READ ONLY 트랜잭션만 썼습니다.

- 현재: 신규 규칙 5건 포함 `LOCAL_RULES`
- 기준: 신규 규칙 5건을 제외한 `LOCAL_RULES`

저장소 파일은 고치지 않았습니다.
