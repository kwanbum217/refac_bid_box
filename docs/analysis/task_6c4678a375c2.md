# task_6c4678a375c2: Kimi 런처 종료 후 터미널 가시성

> **작성일**: 2026-08-28
> **Task ID**: task_6c4678a375c2

## 문제

`scripts/orca_kimi_launch.py` 가 `os.execvpe` 로 현재 프로세스를 kimi 에 넘기고, kimi `-p` 단발 모드가 끝나면 터미널 창까지 함께 닫혔습니다. cursor·Antigravity 워커는 대화형이라 완료 후에도 출력을 볼 수 있었지만 kimi 만 불가했습니다.

## 변경

| 항목 | 이전 | 이후 |
| --- | --- | --- |
| kimi 실행 | `os.execvpe` (프로세스 대체) | `subprocess.run` (자식 프로세스, stdio 상속) |
| 종료 후 | 창 닫힘 | 완료 메시지 + 종료 코드 출력 후 `SHELL`(없으면 `/bin/bash`) 로 이어받기 |
| 옵트아웃 | 없음 | `--no-keep-open` 시 kimi 종료 코드만 반환 |

순수 함수 `build_completion_message(exit_code, model)` 에 세션 이어가기 안내(`kimi -m <model> -c`)를 포함했습니다.
