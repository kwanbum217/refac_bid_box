## 4. 구간 경계 `지역제한 금액` 처리

원문 별표 1-3·1-5 주 ①은 경계를 이렇게 정의합니다: `배점한도 금액은 ‘추정가격’을 기준으로 하며, ‘지역제한 금액’이란 「지방계약법 시행규칙」제24조 제2호 나목의 규정에 따라 행정안전부장관이 고시한 금액을 말한다.`

등록은 전남 구판 규칙과 같은 방식으로 **5억원** 경계로 했습니다.

- 전남 구판 규칙(`SERVC_LOCAL_JEONNAM_20230302_*`)은 같은 구조의 전신 기준에서 `지역제한 금액` 경계 자리를 5억원으로 인쇄한 판을 근거로 등록돼 있습니다(`docs/analysis/jngj_predecessor_apply_20261017.md` 2.2·3.1·3.2절).
- 조사 문서 7.4절은 2015년 판 전남 별표에 광주와 같은 `지역제한 금액` 경계가 있었고 전남이 개정에서 그 경계를 5억원으로 바꾼 것으로 정리합니다. 즉 `지역제한 금액` 의 수치 대응은 5억원입니다.
- 경계값은 상한 미만/이상 판정에서 상위 구간에 속합니다(추정가격이 정확히 5억원이면 `지역제한 금액 이상`). 시험 `tests/test_gwangju_predecessor.py` 가 1억원·5억원 경계값을 함께 고정합니다.

## 6. 풀리는 건수 (DB)

### 6.1 조회 조건

`category='Servc'`·`2022-11-15 ≤ bid_ntce_dt < 2026-07-16`·낙찰방법명이 `%폐기물처리용역 적격심사%` 또는 `%육상운송용역 적격심사%`·수요기관 LOCAL 계약 체제(`jrsdctn_div_nm` 지방자치단체·지방공기업, 교육행정조직, 공립 학교)·수요기관 기준정보 조인(`g2b_demand_institutions.dminstt_cd = raw_data.dminsttCd`) 조건으로 `uv run python scripts/db_readonly_query.py` 로 셌습니다.

```sql
SELECT SUBSTRING(i.rgn_cd, 1, 2) AS sido,
       CASE WHEN JSON_UNQUOTE(JSON_EXTRACT(b.raw_data, '$.sucsfbidMthdNm')) LIKE '%폐기물처리용역 적격심사%'
            THEN '폐기물' ELSE '육상운송' END AS kind,
       CASE WHEN (i.toplvl_instt_nm = '광주광역시'
                  OR (i.toplvl_instt_nm = '전남광주통합특별시' AND SUBSTRING_INDEX(i.rgn_nm, ' ', 1) = '광주광역시')
                  OR (COALESCE(i.toplvl_instt_nm, '') = '' AND SUBSTRING_INDEX(i.rgn_nm, ' ', 1) = '광주광역시'))
            THEN 'sido29' ELSE 'other' END AS lineage,
       COUNT(*) AS cnt
FROM bid_announcements b
JOIN g2b_demand_institutions i
  ON i.dminstt_cd = JSON_UNQUOTE(JSON_EXTRACT(b.raw_data, '$.dminsttCd'))
WHERE b.category = 'Servc'
  AND b.bid_ntce_dt >= '2022-11-15' AND b.bid_ntce_dt < '2026-07-16'
  AND (JSON_UNQUOTE(JSON_EXTRACT(b.raw_data, '$.sucsfbidMthdNm')) LIKE '%폐기물처리용역 적격심사%'
    OR JSON_UNQUOTE(JSON_EXTRACT(b.raw_data, '$.sucsfbidMthdNm')) LIKE '%육상운송용역 적격심사%')
  AND (i.jrsdctn_div_nm IN ('지방자치단체', '지방공기업')
    OR (i.instt_ty_lrgclsfc_nm = '교육행정조직'
        AND i.instt_ty_midclsfc_nm IN ('시, 도교육청', '지역교육청', '시, 도교육청 직속기관'))
    OR (i.instt_ty_lrgclsfc_nm IN ('초등학교', '중학교', '고등학교', '특수학교', '유치원')
        AND i.instt_ty_smlclsfc_nm = '공립'))
  AND i.rgn_cd LIKE '29%'
GROUP BY sido, kind, lineage
ORDER BY kind, lineage
```
