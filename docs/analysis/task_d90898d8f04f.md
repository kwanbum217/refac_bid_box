## 변경 사항

- `src/ml/promotion.py`에 `compute_artifact_checksum()` 단일 체크섬 함수를
  추가했습니다. `model.bin`과 `metadata.json`을 고정 순서·framing으로 묶어
  SHA-256을 계산하며, 판정 생성과 승격 검증이 같은 함수를 사용합니다.
- `approved` 판정은 다섯 증거 필드, `challenger_version` 일치, champion
  디렉터리 존재 및 양쪽 아티팩트 체크섬 일치를 모두 요구합니다. 증거 결속
  실패는 `force`로 우회할 수 없고, `rejected` 즉시 차단은 유지됩니다.
- 승격 성공과 거부를 `data/promotion_audit.log`에 JSON Lines append 방식으로
  기록합니다. 이 경로는 기존 `*.log` 무시 규칙을 사용합니다.
- `scripts/promote_model.py create-verdict` 서브커맨드가 양쪽 체크섬과
  증거 필드를 채운 `paired_verdict.json`을 생성합니다.
