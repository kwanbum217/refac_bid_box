### 3.2 공고명의 `산림사업` 37종은 적격심사제가 아니다

공고명에 `산림사업` 을 포함한 공고는 37종(51건)이지만, 낙찰방법 코드가 모두 비적격심사입니다.

| 낙찰방법 코드 | 계열 | 공고 수 |
| --- | --- | ---: |
| 낙030005 | 협상에의한계약 | 36 |
| 낙030009 | 수의시담 | 10 |
| 낙030029 | 소액수의견적 | 5 |
| 없음(None) | 물품(Thng) | 2 |

- 공고명에 `산림사업` 이 있으면서 낙찰방법 코드가 적격심사제(`낙030001`)인 공고는 **0건**입니다.
- 따라서 패턴으로 `산림사업` 을 쓰더라도 기관 규칙이 조회되는 적격심사제 공고에서 선택되지
  않습니다. 규칙을 넣어도 동작하지 않으므로 코드·시험·명세에 산림청 규칙을 넣지 않습니다.

  0건과 달리, 공백을 제거해 대조하면 적격심사제 233건이 대상입니다.

  `registry_status` 한 칸만 `unregistered` 에서 `confirmed` 로 바꿨습니다. 발행 총계·다른 행·
  `announcements`·`block_codes`·`scope_counts`·`rule_ids`·`investigation` 은 그대로입니다.
  산림청 행은 `unregistered` 로 둡니다.

## 7. 남은 사항

| 항목 | 내용 |
| --- | --- |
| 산림청 등록 불가 | 적격심사제 공고에 `산림사업` 토큰이 0건이라 규칙을 넣어도 선택되지 않습니다. 산림청이 적격심사로 발주하는 산림사업 공고의 낙찰방법·공고명 표기가 확보되면 그때 등록합니다. |
| 메타 문구 `10곳` | `src/app/api/v1/evaluations.py` 의 `SERVC_RULE_META_SCOPE_NOTE` 는 확인 기관 `10곳` 으로 적혀 있습니다. 이번 Task 의 allowed_write_files 밖이라 고치지 않았고, 후속 정리가 필요합니다. |
| 지사 코드 공고 | 지사 공고 일부는 수요기관 코드가 `Z0xxxxx` 대역이라 규칙 코드(B553931)와 달라 코드 불일치로 매칭되지 않습니다. 정확 일치 별칭은 코드가 없는 지사 공고에서만 동작합니다. |
| 원장 재생성 | `registry_status` 한 칸은 수동 반영했습니다. 다음 원장 재생성 때 다른 수치와 함께 재확인해야 합니다. |
