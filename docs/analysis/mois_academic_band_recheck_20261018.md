## 5. 불일치 항목

없음. B·k·기준비율·적격통과점수 네 값은 두 판 모두에서 동일하게 인쇄되어 있고 코드 값과 모두 일치한다.

시행일에 대한 비고: 코드의 `effective_date = 2025-07-01`은 제325호 시행일과 일치한다. 제373호(시행 2026-07-01)는 같은 열 값을 유지한 개정판이며, 제개정이유에 "적정대가 보장을 위해 적격심사 입찰가격 평가 시 산식 일부 조정"이 기재되어 있으나 학술연구 열(30/60/65, k=2, 88, 85)은 두 판에서 변동이 없다. 따라서 규칙 객체는 두 판을 모두 `source`에 적시하고 `effective_date`는 최초 적용 판(제325호)의 시행일을 쓰는 구조로 일관된다. 코드 변경은 필요하지 않다.

하한율 80.495: 원문에 인쇄되지 않는 역산값(`88 − (100 − 85) / 2 = 80.5 → 80.495`)이므로 대조 대상에서 제외했다 (capsule 지시).
