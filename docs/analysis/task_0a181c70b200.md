# MySQL 통합 테스트 범위 확대 보고

> **작업일**: 2026-09-02
> **대상**: `mysql_integration` 테스트 범위 및 MySQL CI job

## 대상 선정 기준

SQLite와 MySQL에서 결과 또는 실행 가능성이 실제로 달라지는 SQL 의미만 선정했습니다.
콜레이션, 숫자 나눗셈, `ONLY_FULL_GROUP_BY`, 날짜 버킷 함수, JSON 스칼라 추출을 각각 한 건씩 검증합니다.

## 추가한 테스트

`tests/test_mysql_integration_queries.py`에 5개를 추가했습니다.

| 영역 | 검증 내용 |
| --- | --- |
| 콜레이션 | 운영 `utf8mb4_unicode_ci`에서 대소문자 무시 비교 |
| 숫자 나눗셈 | MySQL의 `5 / 2`가 소수값을 보존하는지 확인 |
| 그룹 집계 | 모호한 비집계 열을 `ONLY_FULL_GROUP_BY`가 거부하는지 확인 |
| 날짜 함수 | 공고 날짜의 월 버킷을 `DATE_FORMAT`으로 산출 |
| JSON | JSON 객체에서 따옴표 없는 스칼라 추출 |

단순 CRUD, 양쪽 엔진에서 동일한 SQLAlchemy 컴파일, ChromaDB용 SQLite 파일 검증은 대상에서 제외했습니다. 기존 SQLite 테스트는 이동하거나 삭제하지 않았고, CI의 기존 실패 조건과 skip 검사도 유지했습니다.

## 실행 여부

로컬 환경에 `MYSQL_TEST_URL`이 없어 MySQL 테스트는 명시적 skip 상태로 실행했습니다. CI에서는 기존 격리 MySQL 8 서비스와 `tests/fixtures/ngram_mysql_init.sql`을 그대로 사용하며 새 파일도 같은 job에서 실행됩니다.
