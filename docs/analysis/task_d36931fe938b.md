## 1. 개요 및 배경

기존 리뷰어 실행기([`../../scripts/orca_run_reviewer.py`](../../scripts/orca_run_reviewer.py))는 CLI 실행 명령어가 `agy`로 하드코딩되어 있어, `TIER_POLICY`에서 리뷰어 주 모델로 지정한 `qwen-plus`(`qwen3.7-plus`)를 포함한 Qwen Code 계열 모델을 실행할 수 없는 문제가 있었습니다.

이로 인해 빌더와 리뷰어 간 다른 모델 계열을 배정하여 독립적인 교차 검증을 수행하려는 정책이 정상적으로 동작하지 못했습니다.

본 작업에서는 모델 ID로부터 적절한 CLI 및 인자 배열을 조립하는 순수 함수를 도입하고, 지원하는 모델 제공자(Gemini, Claude, Cerebras, Qwen)에 맞춰 올바른 CLI(`agy`, `qwen`)로 명령어를 분기하도록 수정하였습니다.

## 2. 주요 변경 사항

### 2.1 모델 CLI 명령어 조립 순수 함수 추가

[`../../scripts/orca_run_reviewer.py`](../../scripts/orca_run_reviewer.py)에 `build_model_command`(및 별칭 `build_cli_command`)를 추가하였습니다.

- **제공자 판정**: [`../../scripts/orca_model_router.py`](../../scripts/orca_model_router.py)의 `provider_for_model(model, strict=True)` 함수를 재사용하여 판정 로직 중복을 제거하였습니다.
- **지원 제공자 목록(`SUPPORTED_REVIEWER_PROVIDERS`)**:
  - `gemini`, `claude`, `cerebras`: `agy --model <id> --print <prompt> --print-timeout <timeout>s`
  - `qwen`: `qwen -m <id> -p <prompt>` (단발 실행 플래그 `-p` 사용, 대화형 플래그 `-i` 배제)
- **미지원 및 판정 불가 예외 처리**:
  - 미지원 제공자(예: `codex`, `cursor`, `opencode`, `kimi-openrouter`) 및 판정 불가 모델 ID는 조용히 `agy`로 폴백하지 않고 명시적으로 `ReviewerToolError` 예외를 발생시키며, 오류 메시지에 모델 ID, 판정된 제공자, 지원 목록을 포함하도록 구현하였습니다.

### 2.2 일회성 모델 실행기(`run_model`) 오류 메시지 정밀화

- `run_model`에서 `build_model_command`를 호출하도록 수정하였습니다.
- `FileNotFoundError` 발생 시 고정된 `agy`가 아닌 실제 호출된 CLI 이름(`cmd[0]`)을 에러 메시지에 반영하도록 개선하였습니다 (`실행 파일을 찾을 수 없음 ({cli_name}): ...`).
