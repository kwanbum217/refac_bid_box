## 1. 사용 방법

### 1.1 화면에서 찾는 절차

1. 나라장터(www.g2b.go.kr) 통합검색에 대조표의 **공고번호**를 넣어 조회합니다.
2. 검색 결과에서 해당 공고의 **입찰공고 상세**를 엽니다. 차수가 여러 개인 공고는 2.2절의 차수를 확인해 해당 차수를 엽니다.
3. **개찰결과**에서 다음을 확인합니다.
   - 개찰결과가 공개되어 있는지(개찰일시·개찰결과 상태)
   - 낙찰자가 있는지(낙찰자명·낙찰금액)
   - 유찰·재공고·취소 표시가 있는지
4. 확인 결과를 대조표의 `화면 결과` 열에 `있음`/`유찰`/`없음` 중 하나로 적고, 특이사항은 `비고` 에 적습니다.

> 우선 확인 5건은 3절 표의 링크로 공고 상세 화면을 바로 열 수 있습니다. 링크는 2026-09-29 조달청 입찰공고정보서비스(`getBidPblancListInfoServc`, 공고게시일 기준 `inqryDiv=1`) 응답의 `bidNtceDtlUrl` 값이며, 형식은 `https://www.g2b.go.kr/link/PNPE027_01/single/?bidPbancNo=<공고번호>&bidPbancOrd=<차수>` 입니다. 나머지 20건도 같은 형식으로 열 수 있으나 API 응답으로 확인하지는 않았습니다.

### 2.1 재현 질의

대조표의 DB 값(공고명·수요기관·추정가격·개찰일시·입찰방식·공고종류)은 아래 질의로 재현합니다.

```sql
SELECT bid_ntce_no, bid_ntce_ord, bid_ntce_nm, dminstt_nm, presmpt_prce,
       openg_dt, bid_methd_nm, ntce_kind_nm, category
FROM bid_announcements
WHERE category='Servc'
  AND bid_ntce_no IN (
    'R26BK01589082','R26BK01589060','R26BK01648907','R26BK01659726','R26BK01661664',
    'R26BK01525356','R26BK01542725','R26BK01560546','R26BK01578790','R26BK01596250',
    'R26BK01603425','R26BK01608611','R26BK01609854','R26BK01610200','R26BK01610608',
    'R26BK01611118','R26BK01614566','R26BK01617332','R26BK01618954','R26BK01623575',
    'R26BK01625929','R26BK01625940','R26BK01627871','R26BK01628279','R26BK01628720'
  )
ORDER BY bid_ntce_no, bid_ntce_ord;
```

표의 `추정가격(원)` 은 `presmpt_prce`, `수요기관` 은 `dminstt_nm`, `공고종류` 는 `ntce_kind_nm` 입니다.
