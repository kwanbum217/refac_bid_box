## 3. 저하로 보이는 두 지표는 전부 q21 한 문항이며, 실제로는 개선입니다

citation 누락 2건과 과잉응답 3건은 **모두 q21** 입니다. 다른 문항에는 하나도
없습니다. numeric 미검출 6건(2사실 x 3회)도 전부 q21 입니다.

q21 은 "2026년 조림지 풀베기사업 2차(**동부지구**)" 를 묻습니다. 그런데 두 측정
모두 기대 근거 `bid_10169448` 을 **한 번도 검색하지 못했습니다**(recall 0.0,
검색 결과 5건 동일).

행동만 달라졌습니다.

| | 이전 `d9a0536` | 신 `6210ee1` |
| --- | --- | --- |
| 답변 | "**영암지구**" 공고의 공고번호·기관·낙찰업체·금액을 사실처럼 제시 | "동부지구에 대한 정보가 검색 컨텍스트에 없어 알려드릴 수 없다" |
| 채점 | 비거부 + citation 있음 | 과잉응답 + citation 없음 |
| numeric | 0/2 | 0/2 |

**이전 동작은 다른 공고를 답한 환각입니다.** 사용자가 요청한 동부지구가 아니라
영암지구 정보를 근거 표기까지 붙여 제시했습니다. 새 동작은 없는 것을 없다고
말합니다. 채점기는 fixture 가 `context_sufficient=true` 로 선언했다는 이유로
후자를 과잉응답으로 깎습니다.

### 3.1 채점 규약의 결함 (기록)

fixture 의 `context_sufficient` 는 **검색이 성공한다는 전제** 위에 있습니다. 검색이
기대 문서를 못 가져오면 실제 컨텍스트는 불충분한데, 채점기는 그 상황의 정직한
거부를 과잉응답으로, 거부 답변에 인용이 없는 것을 citation 누락으로 처리합니다.
**두 지표가 환각을 보상하고 정직을 벌합니다.**

이 측정에서는 영향 범위가 q21 하나라 판정을 뒤집지 않지만, 지표를 그대로 읽으면
반대 결론이 납니다. 채점기가 `evidence_recall == 0` 인 요청을 과잉응답·citation
집계에서 분리하도록 고치는 것이 옳습니다.

### 3.2 남은 실제 결함: q21 검색 실패

T7 과 무관하게 **"동부지구" 질의가 기대 문서를 못 찾는 문제는 그대로입니다.**
lexical 과 vector 어느 쪽도 `bid_10169448` 을 후보에 올리지 못합니다. 지구명이
다른 동명 공고가 다수 존재하는 것이 원인으로 보이나 확인하지 않았습니다.
별도 과제로 남깁니다.

끝났습니다. 반면 q08 1회차가 120초로 악화됐습니다. **최대값은 회차 간 편차가
크고 표본이 1회뿐이라 이 값만으로 회귀를 판정하지 않습니다.** 구간별 정본은
