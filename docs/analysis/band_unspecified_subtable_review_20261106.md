## 3. 판별기 패턴 개선 후보

아래는 제안이며 코드를 고치지 않았습니다. 수치는 이번에 내려받은 13건 텍스트에만 적용해 측정했습니다.

### 3.1 후보 C1: 행안부 세부표 확정 신호 R15

- 추가 정규식: `(?<!기술[·ㆍ.,․])학술(?:[·ㆍ.]?\s*연구)?\s*용역\s*적격심사\s*(?:세부\s*)?기준`
- 확정 조건(같은 결정 창 ±160자 안): `행정안전부|행안부|지방자치단체\s*입찰시\s*낙찰자\s*결정\s*기준` 이 있어야 하고, `87\.745|별표\s*2|P\.?Q|기술\s*용역` 이 없어야 합니다.
- 위치: `_resolve_mois_branch` 에서 `87.745` 확인과 기존 `_MOIS_ACADEMIC_SUBTABLE_RULES` 확인 뒤, `technical` 확인 앞.
- 판독 근거: 이번 13건 중 9건이 이 조건을 만족합니다. `적격심사 기준`(광양), `적격심사 세부기준(행정안전부 예규)`(하동·보령·순천), `학술용역 적격심사 세부기준(행정안전부 예규)`(제주 4건)를 모두 포괄합니다.
- 부정 lookbehind 가 필요한 이유: `기술·학술연구 용역 적격심사 세부기준` 안의 `학술연구 용역 …` 부분 문자열을 잡으면 대전 1건이 학술로 확정됩니다. 이번 구현 1.1.0 이 R3 로 장을 잡고도 세부표를 남겨 둔 판단을 유지하려면 이 배제가 필수입니다.
- 발행기관 조건이 필요한 이유: 완주 1건은 `[별표1]` 과 `학술연구용역 적격심사 세부기준` 은 있으나 발행기관이 없습니다. 조건이 없으면 이 건이 학술로 확정되어 설계 사람 라벨(`UNSPECIFIED`)과 충돌합니다.

### 3.2 후보 C2: 참고 문구 하드 드롭에서 R6·R7 예외

- 변경: `_accepted_matches` 의 `_NOISE` 드롭을 R6·R7 에만 적용하지 않습니다. 나머지 규칙(R2·R3·R5·R8·R9·R10·R12)의 하드 드롭은 유지합니다.
- 판독 근거: 이번 13건에서 R6·R7 매치가 있는 행은 영월의료원 1건뿐이고, 그 문장의 실제 적용 기준은 조달청 [별표 1] 입니다.
- 설계 원안(0.25배)으로 되돌리는 대신 R6·R7 만 예외로 두는 이유: 0.25배로 전체를 되돌리면 홀드아웃에서 확인된 물품 장 참고 문장 오탐 2건이 다시 살아납니다(`docs/analysis/band_2to1_classifier_holdout_20261106.md:120`). R6·R7 은 설계 2.1절에서 100건 중 3건 매치·3건 적중·0건 오탐, 홀드아웃 87건에서는 매치 0건으로 오탐 이력이 없습니다.

### 3.3 후보별 측정 결과(13건)

현재 판별기 결과를 먼저 그대로 재현한 뒤 후보를 적용했습니다. 재현값은 DB 와 13건 모두 일치했습니다.

| 후보 | 갈래가 바뀌는 건 | 바뀌지 않는 건 |
| --- | ---: | --- |
| C1 | 9건 → `MOIS_ACADEMIC` | 완주(발행기관 없음)·대전(부정 lookbehind) 유지, 나머지 2건 무영향 |
| C2 | 1건 → `PPS` (R25BK01255918) | 나머지 12건 무영향 |
| C1 + C2 | 10건 확정(학술 9·PPS 1) | 미확정 3건 유지 |

### 3.4 기존 판별 결과를 바꾸지 않는다는 근거

1. C1 은 `_resolve_mois_branch` 안에서만 동작합니다. 1단 갈래 점수에 참여하지 않으므로 `PPS`·`LOCAL`·`MOIS4`·`UNSPECIFIED`·`EXTRACT_FAIL`·`NO_ATTACH` 행의 라벨은 코드 경로상 바뀔 수 없습니다.
2. `MOIS_OTHER` 는 `87.745` 조기 반환이 C1 보다 먼저이고, C1 가드가 `87.745`·`별표2`·`P.Q`·`기술 용역` 을 배제하므로 뒤집히지 않습니다.
3. 이미 `MOIS_ACADEMIC` 인 행은 C1 이후에도 라벨이 `MOIS_ACADEMIC` 그대로입니다. 달라지는 것은 `evidence` 와 `matched_rules` 보강뿐입니다.
4. C2 는 R6·R7 에만 적용합니다. `_NOISE` 하드 드롭은 R8·R9 등에 그대로 남으므로 2026-11-06 운영 판별에서 억제된 참고 문장 오탐은 재발하지 않습니다.
5. 회귀 한계: 이번 작업 캐시에는 13건 첨부만 있습니다. 나머지 `CLASSIFIED` 75건 첨부 텍스트로 전수 재판별을 돌리지 못했습니다. 병합 전에 동일 첨부를 재판별해 라벨 변경이 0건인지 확인해야 합니다.
