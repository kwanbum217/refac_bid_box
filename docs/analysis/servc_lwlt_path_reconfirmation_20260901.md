# Servc 낙찰하한율 경로 재확인과 문서 정정 (2026-09-01)

> **작성일**: 2026-09-01
> **결론**: 새 발견 없음. **기존 판정이 옳았고 문서 세 곳이 어긋나 있었습니다**
> **정정 대상**: `CURRENT_STATE` 2.5 절, `servc_lwlt_missing_20260830.md`, 기각 목록

---

## 1. 왜 이 문서가 필요한가

`CURRENT_STATE` 2.5 절이 개선 경로를 **"낙찰하한율 결측 보전"** 으로 적고 있었습니다.
그 서술을 근거로 2026-09-01 에 조사를 다시 시작했으나, 같은 주제가 **2026-08-30 에
이미 완결**돼 있었습니다.

**착수 전에 `docs/analysis/` 를 검색했다면 피할 수 있었습니다.** 이 문서는 중복 조사의
기록이자 문서 정합성 정정의 근거입니다.

---

## 2. 이번 조사가 재확인한 것 (새 발견 아님)

운영 DB `servc_inst_verify` 전량(1,077,789행)에서 다시 쟀습니다.

| 항목 | 값 |
| --- | ---: |
| 결측(NULL·빈 문자열·0 이하) | **361,745행 (33.6%)** |
| 결측률 추세 | 2015년 27.0% -> 2026년 **46.7%** (단조 증가) |

낙찰방법별로 보면 결측이 제도와 정확히 갈립니다.

| 낙찰방법 | 결측률 |
| --- | ---: |
| 수의시담, 협상에의한계약, 규격가격동시입찰, 최저가낙찰제, 설계공모 | **100%** |
| 공고서참조 | 31.4% |

**결측률 100% 인 방식들은 낙찰하한율 개념 자체가 없습니다.** 2026-08-30 판정과 같습니다.

### 2.1 규칙 기반 보전은 이번에도 기각입니다

`(연도, 계약방법, 용역구분, 금액구간)` 315개 그룹으로 값 수렴을 쟀습니다.

| 지표 | 값 |
| --- | ---: |
| 그룹 내 최빈값 순도 | **70.5%** |
| 90% 이상 순수한 그룹이 덮는 행 | **12.2%** |

**최빈값으로 채우면 약 30%가 틀립니다.** 값 자체는 소수 제도값에 집중돼 있으나
(88.000 45.9%, 87.745 25.2%, 90.000 13.0%) 이 네 축으로는 결정되지 않습니다.
2026-08-30 이 추정 대입에서 오차 7~12%p 폭증을 실측한 것과 같은 방향입니다.

## 3. 문서 세 곳이 어긋나 있었습니다

| 위치 | 종전 서술 | 실제 |
| --- | --- | --- |

| `servc_lwlt_missing_20260830.md` 결론·6.2 절 | 대응 경로로 "계약방식별 분리 모델링" 권고 | **2026-08-03 실측 기각** |

두 번째가 특히 위험했습니다. 그 문서가 권고한 분리 모델링은 이렇게 기각돼 있습니다.

## 5. 남은 유효 경로

**결측 집단 전용 예측구간 관리 하나입니다.** 두 집단은 별도 모집단입니다.

| 집단 | 실제 낙찰률 평균 (SD) | 피복률(90% 목표) |
| --- | ---: | ---: |
| `with_lwlt` | 88.67% (2.62) | 89.16% |
| `missing_lwlt` | **94.95% (5.19)** | 92.04% |

산포가 2배지만 피복률은 양쪽 다 목표 90% 에 근접해 **현재 크게 어긋나 있지 않습니다.**
정확도를 올리는 방향이 아니라 불확실성을 정직하게 표시하는 방향이며, 시급하지 않습니다.

**Servc 모델은 사전 순위 축이 전부 닫혔습니다. 남은 것은 새 정보 수집입니다.**
