## 4. 열 귀속 재검증 (핵심)

### 4.1 원시 XML grep 은 합계는 맞지만 열을 구분하지 못한다

> 2026-10-09 코디네이터 정정: 이 절의 최초 서술("section0.xml 에 문서 전체가 평탄화된 사본 문단이 있고 원시 grep 은 그 사본만 매칭한다")은 틀렸습니다. 독립 리뷰(M1R)와 코디네이터 재현으로 확인했습니다.

`Contents/section0.xml` 의 두 번째 문단(인덱스 1)은 직속 텍스트가 0자이고, 첫 `hp:run` 아래에 대비표 최상위 표를 자식으로 품은 **래퍼 문단**입니다. 별도의 사본이 아닙니다. `iter()` 로 문단 텍스트를 모으면 이 래퍼가 하위 표 문단 텍스트를 다시 포함해 부모와 자식이 이중으로 계수됩니다(래퍼 iter 길이 88,559자).

원시 바이트에는 중복이 없습니다. `낙찰하한율 XX%` 12곳(80.495% 4, 84.245% 3, 87.995% 5)은 각각 하나의 `hp:t` 안에 온전히 들어 있고, 직속 `hp:t` 만 이어 붙인 텍스트(최장 문단 323~377자)에서도 같은 12곳이 나옵니다. 사본이 있다면 원시 grep 수치가 두 배여야 합니다.

따라서 원시 grep 숫자(4/3/5)는 **정확한 문서 전체 합계**이고, 우연의 일치가 아닙니다. 다만 그 문자열이 현행·개정·개정이유 중 어느 열에 속하는지는 알려 주지 않으므로, 열별 귀속은 대비표 최상위 셀의 `colAddr` 로 판정합니다(4.2). 셀 단위 계수에는 래퍼 이중 계수가 없도록 최상위 셀 서브트리만 셉니다.

| 열 | colAddr | 셀 텍스트 길이 | `낙찰하한율` 80.495% | 84.245% | 87.995% | `낙찰하한율` 문자열 |
| --- | --- | --- | --- | --- | --- | --- |
| 현행 | 0 | 42,588 | 0 | 0 | 0 | 0 |
| 개정 | 1 | 43,902 | 4 | 3 | 4 | 11 |
| 개정이유 | 2 | 1,971 | 0 | 0 | 1 | 7 |

- 원 문서 3.3 의 "개정 열 80.495% 4곳, 84.245% 3곳, 87.995% 4곳", "현행 열 `낙찰하한율` 문자열 0회", "87.995% 5회 중 1회가 개정이유"가 그대로 재현됩니다.
- 개정 열의 `낙찰하한율 XX%` 11곳 = 별표 1(286행), 별표 2(478·484행), 별표 2의1(644행), 별표 3(832·838행), 별표 3 두 번째 표(917행), 별표 4(1114·1120행), 별표 5(1301·1312행)입니다.
- 개정이유 열의 1곳은 `※ 예시 : … (낙찰하한율 87.995%, 근로조건 이행계획의 적정성 평가)` 입니다.

### 4.3 수식 개체

| 열 | `hp:equation` 수 | 계수·상수 |

| 현행 | 6 | 모두 상수 88, 계수 2/4 |

수식 개체는 별표 2·3·4 의 `평점산식` 칸(중첩표 `colAddr=1`)에 있습니다. script 원문 예: `BIGCIRC `평점(점)`=`배점한도-`2` TIMES |( {88} over {100} - {입찰가격} over {예정가격} ) TIMES 100|`. 원 문서 3.3 서술과 일치합니다.

### 4.4 방법 검증 (거짓 음성 가설)

- `t.text` 만 쓰면 `hp:fwSpace` 꼬리 텍스트를 놓칩니다. 실제로 `미만 적용`/`이상 적용` 은 원시 XML 에 2회씩 있으나 `t.text` 기반 단순 덤프에는 0회로 나타납니다. 이번 재검증은 `itertext()` 로 이 경로를 없앴습니다.
- 그럼에도 `최저평점` 등 6개 검색어는 3방식 모두 0이므로, 원 문서의 **부재 판정은 거짓 음성이 아닙니다**.
- 다만 원 문서 3.1 의 "전 텍스트를 fwSpace 까지 포함해 추출한 뒤 3개 열을 전수 검색" 서술과 3.5 의 원시 grep 재현 명령은 서로 어긋납니다. 원시 grep 은 열별 검색이 불가능합니다. 이 점을 원 문서에서 보강·정정했습니다.

## 7. 부록: 추출·검증 스크립트 전문

스크립트 파일 자체는 `.orca/` 아래에 두며 커밋하지 않습니다. 표준 라이브러리만 사용합니다.

```python
#!/usr/bin/env python3
"""충남 2026-1235 HWPX 원문 독립 재검증 스크립트 (표준 라이브러리만 사용).

표준 라이브러리 zipfile, xml.etree, re 만 사용한다.
- hp:t 의 itertext() 로 텍스트를 이어붙여 hp:fwSpace 등 인라인 요소의 꼬리 텍스트를 포함한다.
- 열 귀속(현행/개정/개정이유)은 대비표 최상위 셀의 hp:cellAddr colAddr 로 판정한다.
"""
import re
import sys
import zipfile
import xml.etree.ElementTree as ET
from collections import Counter

HWPX = ("data/sources/qualification/files/chungnam/"
        "11c48edac4f7_충청남도 일반용역 적격심사 세부기준(신구대비표).hwpx")
HP = "{http://www.hancom.co.kr/hwpml/2011/paragraph}"
COLS = {0: "현행", 1: "개정", 2: "개정이유", None: "표밖"}


def ln(tag):
    return tag.split("}")[-1]


def tt(t):
    return "".join(t.itertext())


def pt(p):
    return "".join(tt(t) for t in p.iter(HP + "t"))


def dca(tc):
    for c in tc:
        if ln(c.tag) == "cellAddr":
            return (c.get("colAddr"), c.get("rowAddr"))
    return None


def build():
    with zipfile.ZipFile(HWPX) as z:
        xml = z.read("Contents/section0.xml").decode("utf-8")
    root = ET.fromstring(xml)
    parent = {}
    for e in root.iter():
        for c in e:
            parent[c] = e
    return xml, root, parent


def has_tbl_anc(t, parent):
    n = parent.get(t)
    while n is not None:
        if ln(n.tag) == "tbl":
            return True
        n = parent.get(n)
    return False


def top_cell(node, parent):
    """node 를 감싸는 대비표 최상위 셀(colAddr). 표 밖이면 None."""
    chain = []
    n = node
    while n is not None:
        chain.append(n)
        n = parent.get(n)
    top_idx = None
    for i, e in enumerate(chain):
        if ln(e.tag) == "tbl" and not has_tbl_anc(e, parent):
            top_idx = i
            break
    if top_idx is None:
        return None
    for e in reversed(chain[:top_idx]):
        if ln(e.tag) == "tc":
            if dca(e):
                return e
    return None


def main():
    xml, root, parent = build()
    plist = list(root.iter(HP + "p"))
    paras = [pt(p) for p in plist]
    joined = "\n".join(paras)
    nospace = re.sub(r"\s+", "", joined)

    print("### 1. 부재 판정 6개 검색어 x 3방식")
    for t in ["최저평점", "2점", "탈락", "커트", "최소평점", "상한"]:
        print(f"  {t:<8} 원시XML={xml.count(t)} 문단이어붙임={joined.count(t)} 공백제거={nospace.count(t)}")

    print("\n### 2. 낙찰하한율 XX% - 원시XML 정규식")
    print("  ", dict(Counter(re.findall(r"낙찰하한율\s*([0-9.]+)%", xml))))

    print("\n### 3. 낙찰하한율 XX% - 열별(대비표 최상위 셀 서브트리)")
    tops = [t for t in root.iter(HP + "tbl") if not has_tbl_anc(t, parent)]
    rows = [r for r in tops[0] if ln(r.tag) == "tr"]
    cells = [c for c in rows[1] if ln(c.tag) == "tc"]
    for c in cells:
        col = int(dca(c)[0])
        tx = "".join(tt(t) for t in c.iter(HP + "t"))
        pcts = dict(Counter(re.findall(r"낙찰하한율\s*([0-9.]+)%", tx)))
        label = tx.count("낙찰하한율")
        print(f"  {COLS[col]:<5} len={len(tx):>6} 낙찰하한율%={pcts} '낙찰하한율'문자열={label}")

    print("\n### 4. hp:equation 수식 개수/열")
    eqs = list(root.iter(HP + "equation"))
    print("  총:", len(eqs), dict(Counter(COLS[int(dca(top_cell(e, parent))[0])] for e in eqs)))
    print("  예시 script:", repr("".join("".join(s.itertext()) for s in eqs[0].iter(HP + "script"))))

    print("\n### 5. 대비표 열 헤더")
    for r in rows[:1]:
        for tc in (c for c in r if ln(c.tag) == "tc"):
            print(f"  col{dca(tc)[0]}: {''.join(tt(t) for t in tc.iter(HP+'t'))!r}")

    return 0


if __name__ == "__main__":
    sys.exit(main())
```
