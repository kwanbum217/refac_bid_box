### 4.2 주의 사항

1. **기타용역은 "별표 없음" 문제가 아니다.** 조달청 현행 별표 1~11 에는 기타용역 별표가 없고, 해당 별표는 한국지역난방공사 자체 기준 [별표 9] 다. 규칙 등록만으로 풀리지 않고 기관 축(코드 또는 지사명)을 넓혀야 한다. `_axis_matches`([evaluation_rules.py:2816](../../src/app/services/evaluation_rules.py:2816))는 규칙과 공고 양쪽에 코드가 있으면 코드 일치로만 판정하므로, 이름 접두만으로는 지사 공고가 매칭되지 않는다.
2. **기타용역 3건은 판본 경계다.** 공고일이 2026-01-01 이전이면 현행 규칙이 `_narrow_to_current_regime` 에서 제외된다. 직전판 규칙을 따로 등록해야 하며, 2023-07-19판 별표 9 원문(`R25BK01166116` seq6, sha256 일치)에 두 띠와 값이 모두 있다.
3. **기타용역 별표 9 의 두 열은 5억원이 아니라 고시금액 기준이다.** 371,311,000원·391,180,000원 공고문도 `입찰가격(50점)` 이라고 적는다. 별표 9 의 B 를 5억원 경계로 옮겨 적으면 안 된다.
4. **`R26BK01708025` 는 공고문과 별표가 어긋난다.** 공고문은 낙찰하한율 82.495%, 적용 별표는 `[별표 9] … 고시금액 이상` 이다. 별표 9 산식(B 50, k 2, 기준 88, T 85)으로 계산하면 80.495% 다. 규칙 값은 별표 원문을 따르는 것이 원칙이나, 공고 인쇄 하한율을 우선하는 정책이 있는지 사용자 확인이 필요하다.
5. **SW 비대상은 두 축이 겹친다.** 배점한도 B 는 5억원 경계(70/60), 평점계수 k 는 고시금액 경계(2/4), 기준비율은 90:100 이다. `5억원 미만-추정가격 고시금액이상` 은 "B 70 + k 2" 조합이므로 기존 `고시금액 미만`(B 70 + k 4, 하한 86.245%)과 같은 규칙에 넣으면 값이 섞인다. 학술연구·폐기물·화물이 쓰는 `고시금액 미만`/`고시금액 이상` 두 규칙 구조를 그대로 따르는 편이 안전하다.
6. **SW 비대상 값은 260판과 390판이 같다.** 이번 11건 중 2026-07-24 공고까지는 260판, 2026-10-01 이후는 390판인데 별표 3 이 바뀌지 않아 하나의 규칙으로 덮을 수 있다.
7. **여객은 판본을 섞으면 안 된다.** 260판 여객은 기준비율 91:100·하한 87.995%, 390판은 93:100·하한 89.995% 다. 5억원 이상 패턴을 390판 규칙에 넣어야 이번 4건이 맞는다. 260판 여객 5억원 이상이 나중에 필요하면 87.995%/0.91 로 별도 규칙이 필요하다.

```sh
        import pdfplumber
        with pdfplumber.open(p) as pdf:

    else:
        doc = extract_document_text(data)
        text = doc.flat if getattr(doc, 'flat', None) else str(doc)
    print(p.name, len(text))
PY
```
