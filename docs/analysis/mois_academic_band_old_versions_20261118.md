### 4.2 시행일 및 폐지일(적용 상한) 관리 방안

### 4.3 묶음 16 (`LOCAL_RULE_NOT_FOUND`) 연계 구제 방안

- 현재 [evaluation_rules.py:4753-4755](../../src/app/services/evaluation_rules.py:4753)의 띠 표기 구제 분기 조건:
  ```python
  if _is_band_only_method(method_name):
      if result.block_reason_code == BLOCK_CODE_RULE_NOT_FOUND:
          academic_band_rule = select_mois_academic_band_rule(...)
  ```
- 위 코드는 `BLOCK_CODE_RULE_NOT_FOUND` 만 검사하고 있어, 충남·세종 등 시·도 일반 별표가 없어 `BLOCK_CODE_LOCAL_RULE_NOT_FOUND`로 떨어진 공고 13건이 구제 분기를 타지 못하고 차단됩니다.
- 구제 조건을 `result.block_reason_code in (BLOCK_CODE_RULE_NOT_FOUND, BLOCK_CODE_LOCAL_RULE_NOT_FOUND)` 로 정합화하면, 묶음 16(13건)도 행안부 학술 띠 구판본 규칙으로 자동 구제됩니다.

### 4.4 영향 건수 및 기대 효과
