## 1. 개요 및 배경

Antigravity 등 터미널 기반 워커 CLI는 첫 파일 편집 또는 생성 시 확인 대화창(`Accept this file edit?`, `Allow creation of this file?`)을 띄워 사용자 입력을 대기합니다.
기존 절차에서는 워커 기동 후 코디네이터 또는 사용자가 직접 `shift+tab`(`\x1b[Z`) 시퀀스를 전송해야 했으며, 이 절차가 누락될 경우 워커들이 동시에 정체되는 문제가 발생했습니다.
반면 **Cursor CLI(`cursor-agent`)에서 `shift+tab`은 Plan Mode(읽기 전용, 파일 편집 금지) 전환**이므로 무조건 전송 시 워커가 파일 편집 불가 상태로 빠지는 결함이 발생합니다.

또한 `orca terminal show --json`의 `preview`는 최근 300자 내외의 커맨드 요약만 반환하여 하단 상태줄(`accept-edits · Gemini 3.7 Flash · high` 등)이 누락되는 문제가 있었으며, `orca terminal read` 출력의 메타 헤더(`cursor: 50894`)로 인한 Cursor 오탐 위험이 존재했습니다.

본 작업은 `scripts/orca_taskctl.py`에 `terminal_read` 및 `strip_terminal_metadata_header`를 도입하고, 대상 CLI 화면을 정확하게 검사하여 Antigravity 계열인 경우에만 `shift+tab` 파일 편집 자동 승인 모드 전환(`enable_file_edit_auto_approve`)을 전송하고, Cursor 및 미식별 CLI는 fail-closed 원칙에 따라 전송을 차단하도록 구현했습니다.

## 2. 주요 변경 사항

### 2.1 `scripts/orca_taskctl.py`
- `terminal_read(handle: str, timeout: int = 30) -> str | None`:
  - `orca terminal read --terminal <handle> --json`을 통해 전체 화면/버퍼 라인을 읽어옵니다.
- `strip_terminal_metadata_header(text: str) -> str`:
  - `handle:`, `status:`, `source:`, `cursor:`, `oldest cursor:`, `latest cursor:`, `warning:` 등 `orca terminal read`의 머리말 메타 줄을 제거하여 `cursor: <offset>`에 의한 오탐을 원천 차단합니다.
- `CURSOR_PLAN_MODE_MARKERS`:
  - 단독 `"cursor"` 문자열을 제거하고 `"cursor-agent"`, `"cursor agent"`, `"composer"`, `"plan mode"`, `"enable plan mode"`, `"hit shift+tab to enable plan mode"`, `"run everything"`, `"cursoragent@"` 등 고유 시그니처로 한정.
- `ACCEPT_EDITS_CLI_MARKERS`:
  - `"accept-edits"`, `"antigravity"`, `"gemini 3."`, `"gemini 3.7"`, `"thought for "`, `"● read("`, `"● edit("`, `"● bash("`, `"shift+tab to auto-approve"`, `"auto-approve file edits"`, `"agy"` 정의.
- `classify_file_edit_auto_approve_support(text: str) -> tuple[bool, str]`:
  - 메타 헤더 제거 후 TUI 상태줄 및 본문 시그니처를 검사하여 Antigravity는 `True`, Cursor 및 미식별은 `False`(fail-closed) 반환.
- `enable_file_edit_auto_approve`:
  - `terminal_read`를 우선 조회하고 실패 시 `terminal_tail` fallback.
  - `--enable-file-edit-auto-approve` CLI 플래그로 opt-in 지원.
