## 1. 개요 및 배경

Antigravity 등 터미널 기반 워커 CLI는 첫 파일 편집 또는 생성 시 확인 대화창(`Accept this file edit?`, `Allow creation of this file?`)을 띄워 사용자 입력을 대기합니다.
기존 절차에서는 워커 기동 후 코디네이터 또는 사용자가 직접 `shift+tab`(`\x1b[Z`) 시퀀스를 전송해야 했으며, 이 절차가 누락될 경우 워커들이 동시에 정체되는 문제가 발생했습니다.
`scripts/orca_auto_approve.py` 감시기는 셸 명령 대화창을 처리하지만 파일 편집 대화창은 설계상 의도적으로 보류(`hold`)로 판정하므로 감시기만으로는 해소되지 않습니다.

본 작업은 `scripts/orca_taskctl.py`의 `dispatch` 경로에서 권한 자동 승인 감시기(`start_auto_approve`) 부착 직후 `shift+tab` 파일 편집 자동 승인 모드 전환(`enable_file_edit_auto_approve`)을 1회 자동 전송하도록 구현하고, 회귀 테스트 및 운영 문서를 갱신했습니다.
