"같은 규칙으로 묶을 수 있다"는 것은 두 판 중 어느 것을 적용해도 **가격점수·하한율·통과점수가 같아** 동일한 `EvaluationRule`(현재 코드 계약: `lwlt_rate`, `base_rate`, `patterns`)로 계산할 수 있다는 뜻입니다. 수행능력·신인도 배점처럼 종합평점을 바꾸는 요소는 현재 `EvaluationRule` 필드에 없으므로, 그것까지 반영하는 단계에서는 별도 판정이 필요합니다.

### 5.2 판정 결과

| 별표 | 대비표 변경 | 가격점수·하한율·통과점수 | 현재 코드 계약에서 묶음 | 종합평점 축 |
| --- | --- | --- | --- | --- |
| 별표 1 학술연구 | 있음(수행능력 배점·기술능력 신설) | 동일(88, 통과 85) | **묶을 수 있음** | **따로 선언 필요**(이행실적 30->20, 기술능력 신설) |
| 별표 2 시설분야 | 문구(노임->임금)만 | 동일(91, 통과 85) | 묶을 수 있음 | 동일 |
| 별표 3 / 3의2 SW | 없음 | 동일(88 / 91) | 묶을 수 있음 | 동일 |
| 별표 4 폐기물 | 없음 | 동일(88) | 묶을 수 있음 | 동일 |
| 별표 5 여객 | 없음 | 동일(91) | 묶을 수 있음 | 동일 |
| 별표 5의2 화물 | 없음 | 동일(88) | 묶을 수 있음 | 동일 |
| 별표 6 보험 | 주 ④ 신설(평가기준) | 동일(88, 계수 0.375) | 묶을 수 있음 | 동일 배점, 지급여력비율 선택규칙만 추가 |
| 별표 7 수리·점검 | 없음 | 동일(88) | 묶을 수 있음 | 동일 |
| 별표 8 임대차 | 없음 | 동일(88) | 묶을 수 있음 | 동일 |

| 별표 10 경영상태 | 없음 | 영향 없음 | 묶을 수 있음 | 동일 |
| 별표 11 신인도 | 있음(가점 값 전면 개편) | 영향 없음 | 묶을 수 있음 | **따로 선언 필요**(가점 표가 다름) |

### 5.3 실무 권고

- **하한율·가격점수만 계산하는 단계**에서는 제2023-53호용 규칙을 `effective_date="2023-05-01"` 로 별도 선언하되, 값이 제2025-257호와 같은 별표는 패턴·하한율·기준값을 공유해도 됩니다. 차이는 `effective_date` 하나입니다.
- **종합평점까지 계산하는 단계**에서는 별표 1과 별표 11을 반드시 판별해야 합니다. 2025-01~08 공고는 이행실적 30점 체계와 제2023-53호 신인도 가점 표를 써야 하며, 2025-09-01 이후 공고와 점수가 달라집니다.
- 별표 2·6은 배점·계산식이 같아 규칙은 묶되, 별표 6은 지급여력비율 경과조치 선택 규칙만 평가 로직에 추가하면 됩니다.

  `SELECT COUNT(*) AS total_rows, COUNT(DISTINCT bid_ntce_no) AS total_notices, SUM(CASE WHEN JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidMthdNm')) LIKE '%수기심사%' THEN 1 ELSE 0 END) AS manual_rows, COUNT(DISTINCT CASE WHEN JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidMthdNm')) LIKE '%수기심사%' THEN bid_ntce_no END) AS manual_notices FROM bid_announcements WHERE bid_ntce_dt >= '2025-01-01' AND bid_ntce_dt < '2025-09-01' AND category='Servc' AND JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidMthdNm')) LIKE '적격심사제%'`
  -> 23597 / 19448 / 4489 / 3745
- **Q2.** 상위 20종 낙찰방법명과 공고 수
  `SELECT JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidMthdNm')) AS m, COUNT(*) AS rows_cnt, COUNT(DISTINCT bid_ntce_no) AS notices FROM bid_announcements WHERE <Q1 조건> GROUP BY m ORDER BY rows_cnt DESC LIMIT 20`
  -> 4.2 절 표의 행 수·공고 수
- **Q3.** 낙찰방법명별 하한율 최빈값
  `WITH q AS (SELECT JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidMthdNm')) AS m, CAST(JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidLwltRate')) AS DECIMAL(6,3)) AS lw FROM bid_announcements WHERE bid_ntce_dt >= '2025-01-01' AND bid_ntce_dt < '2025-09-01' AND category='Servc' AND JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidMthdNm')) LIKE '적격심사제%' AND JSON_UNQUOTE(JSON_EXTRACT(raw_data,'$.sucsfbidLwltRate')) IS NOT NULL), t AS (SELECT m, lw, COUNT(*) c, SUM(COUNT(*)) OVER (PARTITION BY m) tot, ROW_NUMBER() OVER (PARTITION BY m ORDER BY COUNT(*) DESC, lw) rn FROM q GROUP BY m, lw) SELECT m, lw, c, tot FROM t WHERE rn=1 ORDER BY tot DESC`
  -> 4.2·4.3 절의 하한율 최빈값·표본
- **Q4.** 일반 띠 대응 문자열 부재 확인(본문 검색)

  -> 0건 (별표 1 의 "추정가격 5억원 이상/미만" 열 머리글만 존재)
