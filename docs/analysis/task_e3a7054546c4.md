- 후보가 0개 또는 2개 이상이면 자동 선택 없이 `BuildProvenanceError`.
- 조회 예외를 unknown 성공으로 흡수하지 않음.
- strict 모드에서 `redis_url` 과 컨테이너 발행 포트 대응 검증.
- `--redis-container` CLI 인자 추가 (컨테이너 이름/ID 또는 compose 서비스명).
