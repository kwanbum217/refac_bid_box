## 2. 핵심 설계 및 규약 준수

| 항목 | 설계 및 구현 내용 |
| --- | --- |
| **읽기 전용 (Read-only)** | 저장소 파일을 수정하거나 git 을 조작하지 않으며, 유일한 파일 쓰기는 `--out`으로 지정된 감사 결과 JSON 파일입니다. |
| **Fail-Closed 종료 코드** | 정상 판정(위반 없음): `0`, 위반 발견: `1`, 도구 오류(버퍼 미취득, Capsule 파싱 실패 등): `2`로 명확히 분기합니다. |
| **기존 헬퍼 재사용** | `scripts/orca_contract.py`의 `load_capsule`, `parse_capsule_list`, `matches_any`를 import하여 glob 대조 정합성을 단일화했습니다. |
| **이중 허용 범위 결합** | Capsule 의 `allowed_read_files`(평면 리스트)와 `search_scope.allowed_globs`(중첩 매핑)를 함께 추출하여 허용 목록으로 대조합니다. |
| **경로 추출 및 정제** | ANSI 색상 이스케이프(`\x1b[...]`) 제거, URL(`http://`, `https://`, `file://`) 스킴 제외, 라인 번호(`:line:col`) 정리, 중복 제거 및 정렬을 수행합니다. |
| **시스템 경로 잡음 억제** | 모듈 상수(`SYSTEM_ALLOWLIST_PREFIXES`, `SYSTEM_ALLOWLIST_CONTAINS`)를 통해 `/usr`, `/bin`, `/tmp`, `.venv`, `node_modules` 등을 기본 판정에서 제외하며, `--no-system-allowlist` 옵션 지정 시 엄격 판정합니다. |
| **한계 명시** | 화면 버퍼의 스크롤 밀림 및 잘림 현상으로 인해 '증거가 남아 있는 범위'에서만 유효하며 'clean'이 완전한 무위반 증명은 아니라는 점을 모듈 독스트링에 명시했습니다. |
