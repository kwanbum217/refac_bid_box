## 1. 과업 개요 및 목적

### 1.1 배경 및 문제 정의
- 기존 CI 환경(`.github/workflows/ci.yml`)에는 Playwright Chromium 브라우저 설치 단계가 존재하지 않아 E2E 테스트가 조용히 skip 되었습니다.
- 또한 E2E 백그라운드 서버(`live_server_url`)가 환경변수의 `DATABASE_URL`을 그대로 참조하여, 테스트 시 사용자 생성 및 상태 변경이 로컬 개발 DB(`procurement`)에 기록되는 위험(G1 데이터 무손실 위반)이 있었습니다.

### 1.2 핵심 해결 과제
1. **임시 SQLite 파일 DB 격리**: 테스트 세션 전용 임시 SQLite DB를 생성하고 `app.dependency_overrides[get_db]`를 통해 백그라운드 Uvicorn 서버에 주입하여 개발 DB 오염을 100% 원천 차단.
2. **세션 쿠키 직접 주입 Fixture**: UI 로그인 화면 반복을 제거하기 위해 `create_session()` 기반 세션 토큰을 브라우저 컨텍스트(`bidbox_session` 쿠키)에 직접 주입하는 Fixture 제공.
3. **인증 화면 진입 검증**: 세션 쿠키가 주입된 브라우저가 인증 필요 화면(`/bids/dashboard/`)에 200 OK로 정상 진입함을 단언하는 테스트 작성.
4. **CI 워크플로 최적화**: 배포 기준 플랫폼인 Ubuntu 3.11 러너에만 최소 범위로 Chromium 설치 단계를 추가하여 전체 매트릭스 오버헤드 차단.
5. **브라우저 부재 시 자동 Skip 유지**: 바이너리가 없는 환경(macOS, Windows, Ubuntu 3.12/3.13)에서는 실패가 아닌 skip으로 안전하게 처리.

## 2. 세부 구현 내용

### 2.1 임시 SQLite 기반 DB 격리 (`tests/e2e/conftest.py`)
- `tempfile.mkdtemp`를 사용하여 세션 전용 디렉터리와 `e2e_isolated.db` SQLite 파일 DB를 생성합니다.
- `Base.metadata.create_all(bind=engine)`을 호출하여 13개 전체 ORM 모델 테이블을 초기화합니다.
- `app.dependency_overrides[get_db]`에 격리 DB 세션 생성기를 등록하여 Uvicorn 백그라운드 스레드의 모든 요청이 격리 DB로 라우팅되도록 합니다.
- 테스트 세션 종료 시 의존성 오버라이드를 제거하고 임시 디렉터리를 삭제합니다.

### 2.2 세션 쿠키 직접 주입 Fixture (`tests/e2e/conftest.py`)
- `e2e_test_user`: 격리 DB에 테스트 사용자(`CustomUser`)를 등록하고 정보를 반환합니다.
- `e2e_session_token`: `create_session(user_id, username)`을 직접 호출하여 세션 토큰을 생성합니다.
- `authenticated_context`: Playwright `BrowserContext`에 `bidbox_session` 쿠키를 등록하여 반환합니다.
- `authenticated_page`: 인증 컨텍스트 기반의 `Page` 인스턴스를 제공하여 보호된 화면으로 즉시 진입할 수 있도록 합니다.

### 2.3 E2E 검증 테스트 작성 (`tests/e2e/test_ssr_auth_session.py`)
- `test_e2e_db_isolation_and_dependency_override`: `app.dependency_overrides[get_db]` 등록 여부, 격리 엔진이 SQLite 드라이버임을 확인하고 글로벌 DB 엔진과 분리되어 있음을 명시적으로 단언합니다.
- `test_authenticated_access_to_protected_page`: 세션 쿠키가 주입된 브라우저로 `/bids/dashboard/`에 접근하여 200 OK 응답, 대시보드 헤더 렌더링, 사이드바 사용자 닉네임 표시를 검증합니다.
- `test_unauthenticated_access_redirects_to_login`: 비인증 브라우저로 `/bids/dashboard/` 접근 시 `/accounts/login/?next=...`로 303 리다이렉트됨을 검증합니다.

### 2.4 CI 워크플로 갱신 (`.github/workflows/ci.yml`)
- `cross-platform-test` 잡에서 `matrix.os == 'ubuntu-latest' && matrix.python-version == '3.11'` 조건일 때만 `uv run playwright install --with-deps chromium`을 수행하도록 설정했습니다.
- 타 플랫폼(macOS, Windows, Ubuntu 3.12/3.13) 러너에서는 브라우저를 설치하지 않아 불필요한 네트워크/시간 소모를 방지하며, `pytest_runtest_setup`에 의해 E2E 테스트가 자동 skip 처리됩니다.
