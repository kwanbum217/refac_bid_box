## 1. 요약

원문(별표)에 낙찰하한율이 인쇄되지 않아 코드가 서비스 유형별 기본값(87.995 / 84.245 / 47.995)을 쓰던 14개 규칙에 대해, 같은 시·도·용역 구분의 실제 나라장터 공고가 싣고 있는 `sucsfbidLwltRate` 분포를 실측했습니다.

핵심 결과 5건입니다.

1. **코드 기본값 87.995 는 12개 규칙 중 어느 것에서도 2억원 미만 구간 실측값과 일치하지 않습니다.** 일반용역 적격심사 공고의 최빈 하한율은 2억원 미만 87.745, 2억~5억 86.745, 5억~10억 85.495 로 세 시·도 이상에서 일관되게 나타납니다.
2. **서울(`SEOUL_20240812_ATTACH_01`)은 5구간이 모두 또렷합니다.** 2억 미만 87.745(947건), 2~5억 86.745(335건), 5~10억 85.495(104건), 10~30억 77.995(74건), 30억 이상 72.995(24건) 입니다.
3. **경기 보험(`GG_20250808_ATTACH_1_5`)의 47.995 는 실측과 일치합니다.** 시·도·구간을 가리지 않고 47.995 만 관측됩니다(전환 전 27건).
4. **단순노무 규칙 5개(인천·제주·강원·경북 01·서울)와 경북 소프트웨어(02)는 낙찰방법명 기준 표본이 0건입니다.** 낙찰방법명에 "단순노무" 표기가 전무하고(대상 5개 시·도 0건), 경북 일반용역 소프트웨어 공고도 0건입니다.
5. **경북 폐기물(03)은 6건뿐이고 값이 갈립니다**(87.745:2, 80.495:2, 84.245:1, 80.495:1). 표본 부족입니다.

## 2. 조사 방법

### 2.1 모집단 정의

규칙별 모집단은 코드(`src/app/services/evaluation_rules.py::_select_local_rule`, `src/app/services/demand_institutions.py::institution_sido`)와 같은 축으로 잡았습니다.

| 축 | 값 |
| --- | --- |
| 공고 분류 | `category = 'Servc'` (일반용역) |
| 용역 구분 | `raw_data.srvceDivNm = '일반용역'` |
| 낙찰방법명 | `raw_data.sucsfbidMthdNm LIKE '적격심사%'` |
| 하한율 존재 | `raw_data.sucsfbidLwltRate IS NOT NULL` |
| 시·도 | `g2b_demand_institutions` 를 `raw_data.dminsttCd` 로 조인해 `toplvl_instt_nm`(없으면 `rgn_nm` 첫 토큰) 판정 |
| 서비스 세부유형 | 낙찰방법명 표기로 분리(폐기물·보험·소프트웨어·시설분야·육상운송·임대차·단순노무) |

시·도 판정은 코드의 `institution_sido` 와 동일합니다. `toplvl_instt_nm` 이 시·도 본청이 아니면(예: `경기도교육청`) 코드가 `(None, None)` 으로 제외하는 것과 같게, 본청명이 시·도 목록에 없으면 집계에서 빠집니다.

### 2.2 규칙별 서비스 축

| --- | --- |

### 2.3 판정 기준

캡슐 3.2 규정을 그대로 적용했습니다. 집계 단위는 **규칙 × 추정가격 구간 × 레짐**이며, 건수는 공고번호 기준(`COUNT(DISTINCT bid_ntce_no)`, 재공고 차수 중복 제거)입니다.

| 판정 | 조건 |
| --- | --- |
| 공고 실측 | 관측 3건 이상이고 최빈값이 3건 이상이며 그 값이 유일하게 3건 이상 |
| 공고 상이(혼재) | 관측 3건 이상인데 3건 이상인 값이 둘 이상(값이 갈림). 분포 표기 |
| 표본 부족 | 관측 3건 미만 |

추정·역산한 값은 싣지 않았습니다. 행정안전부 예규 값을 시·도 값으로 단정하지 않았고, 관측된 공고 값만 적었습니다.

### 2.4 추정가격 구간

`bid_announcements.presmpt_prce`(추정가격, 원) 기준입니다. 2억원 미만 / 5억원 미만 2억원 이상 / 10억원 미만 5억원 이상 / 30억원 미만 10억원 이상 / 30억원 이상 5구간입니다.

### 2.5 레짐 전환

2026-05-26 낙찰하한율 레짐 전환 전후를 나눴습니다. 전환 후 표본은 기간이 짧아(2026-05-26~2026-10-04) 전환 전보다 작습니다. 전환 후에도 87.745 계열이 다수를 유지하지만, 일부 공고에서 89.745·89.995·86.245(값 +2%p 계열)가 나타납니다.

| 공고 낙찰하한율의 성격 | 여기 값은 나라장터 공고가 실은 `sucsfbidLwltRate` 이며, 시·도 별표가 인쇄한 값이 아닙니다. 별표 값과의 일치 여부는 별도 확인 대상입니다. |
| 경북 폐기물 | 일반용역 폐기물 공고 자체가 6건뿐이라 판정 불가입니다. |

### 8.1 시·도별 서비스·낙찰방법 분포

```sql
SELECT
  COALESCE(NULLIF(di.toplvl_instt_nm,''), SUBSTRING_INDEX(di.rgn_nm,' ',1)) AS sido,
  JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.srvceDivNm')) AS srvce,
  JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidMthdNm')) AS mthd,
  COUNT(*) AS n
FROM bid_announcements ba
JOIN g2b_demand_institutions di
  ON JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.dminsttCd')) = di.dminstt_cd
WHERE ba.category='Servc'
  AND ba.bid_ntce_dt >= '2026-01-01'
  AND COALESCE(NULLIF(di.toplvl_instt_nm,''), SUBSTRING_INDEX(di.rgn_nm,' ',1))
      IN ('인천광역시','제주특별자치도','강원특별자치도','경상북도','경상남도','경기도','서울특별시')
GROUP BY sido, srvce, mthd
ORDER BY n DESC
```

### 8.2 규칙별 하한율 분포·대표 공고번호 (상세 표 3장 생성 질의)

```sql
SELECT
  COALESCE(NULLIF(di.toplvl_instt_nm,''), SUBSTRING_INDEX(di.rgn_nm,' ',1)) AS sido,
  CASE
    WHEN JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidMthdNm')) LIKE '%단순노무%' THEN 'SIMPLE_LABOR'
    WHEN JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidMthdNm')) LIKE '%생활폐기물%' THEN 'WASTE_HOUSEHOLD'
    WHEN JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidMthdNm')) LIKE '%폐기물%' THEN 'WASTE'
    WHEN JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidMthdNm')) LIKE '%보험%' THEN 'INSURANCE'
    WHEN JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidMthdNm')) LIKE '%소프트웨어%' THEN 'SW'
    WHEN JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidMthdNm')) LIKE '%시설분야%' THEN 'FACILITY'
    WHEN JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidMthdNm')) LIKE '%육상운송%' THEN 'LAND_TRANSPORT'
    WHEN JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidMthdNm')) LIKE '%임대차%' THEN 'LEASE'
    ELSE 'GENERAL' END AS bucket,
  CASE WHEN ba.bid_ntce_dt >= '2026-05-26' THEN 'POST' ELSE 'PRE' END AS regime,
  CASE
    WHEN ba.presmpt_prce IS NULL THEN 'NULL'
    WHEN ba.presmpt_prce < 200000000 THEN 'A_lt2'
    WHEN ba.presmpt_prce < 500000000 THEN 'B_2to5'
    WHEN ba.presmpt_prce < 1000000000 THEN 'C_5to10'
    WHEN ba.presmpt_prce < 3000000000 THEN 'D_10to30'
    ELSE 'E_ge30' END AS band,
  JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidLwltRate')) AS lwlt,
  COUNT(DISTINCT ba.bid_ntce_no) AS n,
  SUBSTRING_INDEX(GROUP_CONCAT(ba.bid_ntce_no ORDER BY ba.bid_ntce_dt DESC), ',', 15) AS samples
FROM bid_announcements ba
JOIN g2b_demand_institutions di
  ON JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.dminsttCd')) = di.dminstt_cd
WHERE ba.category='Servc'
  AND ba.bid_ntce_dt >= '2025-01-01'
  AND JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidLwltRate')) IS NOT NULL
  AND COALESCE(NULLIF(di.toplvl_instt_nm,''), SUBSTRING_INDEX(di.rgn_nm,' ',1))
      IN ('인천광역시','제주특별자치도','강원특별자치도','경상북도','경상남도','경기도','서울특별시')
  AND JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.srvceDivNm'))='일반용역'
  AND JSON_UNQUOTE(JSON_EXTRACT(ba.raw_data,'$.sucsfbidMthdNm')) LIKE '적격심사%'
GROUP BY sido, bucket, regime, band, lwlt
ORDER BY sido, bucket, regime, band, n DESC
```
