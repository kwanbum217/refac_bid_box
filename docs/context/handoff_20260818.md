## 4. 이 세션에서 얻은 판단 기준

- **0 은 "값 없음" 의 표기가 아니다.** 숫자 자리에 실패를 0 으로 채우면 계산 결과와 구별되지 않는다 (12.4)
- **"상태 미지정 = 성공" 기본값을 만들지 않는다.** 빠뜨린 것과 선언한 것이 같아진다 (12.5)
- **하위 프로세스를 mock 한 테스트는 인자 호환성을 증명하지 않는다.** 상대 파서를 임포트해 실제로 파싱시킨다 (12.2)
- **빈 허용 목록의 의미는 읽기와 쓰기가 정반대다** (12장 표)
- **워커의 빈 응답을 결과로 세지 않는다** (12.6)
