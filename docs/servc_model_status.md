## 5. 판정 기준 (바꾸지 마십시오)

1. 홀드아웃 차이가 **0.0074 이내**면 분할 변동입니다. 운영 검정으로 보내지 않습니다
2. 분할마다 부호가 갈리면 기각입니다
3. 운영 쌍대 검정을 통과해야 승격입니다
4. 성능 주장에는 실측이 따릅니다. 추정치로 개선됐다고 쓰지 않습니다
