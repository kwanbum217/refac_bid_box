| Cursor 리뷰어 소진 | E1 리뷰어는 원문을 읽은 뒤 턴 종료 상태로, G1 리뷰어는 지시문이 입력창에 남은 채로 멈췄다. 화면에 명시적인 한도 문구가 없었다. `worker-stop` 으로 두 Dispatch 를 멈추고 Task 를 `ready` 로 되돌려 다시 투입했다 |
| grok-4.7 기동 | 라우터 MODEL_POOL 에 grok-4.7 이 없어 `taskctl dispatch` 를 못 쓴다. 워크트리에 `grok --model grok-4.7 --reasoning-effort medium --always-approve` TUI 터미널을 만든 뒤 `orca orchestration worker-start --task <id> --terminal <handle> --worktree path:<워크트리>` 로 이어받았다. 전역 설정 `~/.grok/config.toml` 의 `default_reasoning_effort = "high"` 는 건드리지 않았다. `worker-release` 뒤에도 이어받은 터미널은 남으므로 탭을 확인하고 닫는다 |
| Grok 주간 한도 | 기동 시 상태줄에 `Weekly limit left: 5%` 가 떴다. 다음 세션 전에 한도를 확인할 것 |
| 보고 언어 | 이 세션 중반부터 코디네이터 보고가 영문으로 흘러 사용자가 지적했다. 워커 출력 언어가 아니라 코디네이터 보고 언어의 문제였다 |
