## 1. 개요 및 원시 데이터 스키마

본 분석은 동일한 서빙 코드에서 표본 수($n$)에 따라 `/predict` c10 P95 측정치가 34~38ms(통과권)와 65~76ms(변동권)로 엇갈리는 현상을 기존 22개 원시 벤치마크 파일(총 5,640회 요청) 데이터만을 활용해 규명하고, 표본 크기에 의존하지 않는 안정적인 성능 지표를 산출하기 위해 수행되었습니다.

### 1.1 JSON 원시 스키마 확인

모든 벤치마크 JSON 파일의 `requests` 배열 원소는 다음 키를 포함하며, 개별 요청 지연 시간은 `latency_ms` 필드로 기록되어 있습니다.

```json
{
  "request_index": 0,
  "latency_ms": 31.4075205,
  "trace_id": "...",
  "error": null,
  "trace": { ... }
}
```

- **지연 시간 필드명**: `latency_ms` (단위: 밀리초, ms)
- **추적 헤더 필드명**: `trace_id`, `trace` (비활성 파일에서는 `null` 또는 미기록)

### 1.2 백분위수(Percentile) 선형 보간 방식 정의

본 분석 및 저장소의 벤치마크 스크립트([`scripts/benchmark_predict_tail.py`](scripts/benchmark_predict_tail.py), [`scripts/analyze_predict_p95_samplesize.py`](scripts/analyze_predict_p95_samplesize.py))에서 사용하는 백분위수 산출 공식은 **Type 7 선형 보간 방식(Linear Interpolation, R/NumPy 기본 방식)**입니다.

- 정렬된 지연 배열 $X = [x_0, x_1, \dots, x_{N-1}]$에 대해 목표 백분위 $q \in [0, 100]$의 가상 인덱스 위치는 다음과 같이 정의됩니다.
  $$\text{position} = (N - 1) \times \frac{q}{100}$$
- 하한 인덱스 $i = \lfloor \text{position} \rfloor$, 상한 인덱스 $j = \min(i + 1, N - 1)$, 가중치 $w = \text{position} - i$일 때 백분위수 값은 다음과 같이 보간됩니다.
  $$P_q = x_i \times (1 - w) + x_j \times w$$

## 3. 표본 크기($n$)에 따른 P95 추정치 변동 규명

가장 큰 계측 비활성(Uninstrumented) 표본인 `phase8_predict_tail_uninstrumented_c10_r600_20260814.json` ($N=600$)의 원시 요청 지연 배열을 대상으로, 표본 크기 $n \in [100, 300, 600, 1000]$에 대해 각각 1,000회 부트스트랩 복원 추출(Bootstrap Resampling with Replacement, 난수 시드 42)을 수행하여 P95의 분포를 산출했습니다.

### 3.1 원본 데이터 지연 분포 요약 ($N=600$)

- **중앙값 (P50)**: 31.93ms
- **90% 백분위수 (P90)**: 36.90ms
- **95% 백분위수 (P95)**: 40.27ms
- **99% 백분위수 (P99)**: 71.47ms
- **최대 지연 (Max)**: 73.76ms
- **임계치별 발생 빈도**:
  - $> 70.0\text{ms}$: 15건 (2.50%)
  - $> 60.0\text{ms}$: 19건 (3.17%)
  - $> 50.0\text{ms}$: 20건 (3.33%)
  - $> 40.0\text{ms}$: 32건 (5.33%)

### 3.2 부분표본 크기별 P95 부트스트랩 시뮬레이션 결과 (1,000회 반복)

| 표본 크기 ($n$) | P95 평균 (ms) | P95 표준편차 (ms) | P5 (5% 백분위, ms) | P95 중앙값 (ms) | P95 (95% 백분위, ms) | 90% 신뢰구간 폭 (ms) | P95 > 60ms 확률 (%) |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| **100** | 43.10 | **9.61** | 37.07 | 39.32 | **69.86** | 32.79 | 10.2% |
| **300** | 41.55 | **6.03** | 37.94 | 40.12 | **55.53** | 17.59 | 3.5% |
| **600** | 40.74 | **2.94** | 38.40 | 40.27 | **42.92** | 4.52 | 0.6% |
| **1000** | 40.48 | **1.40** | 38.67 | 40.27 | **42.32** | 3.65 | 0.0% |

### 3.3 현상 분석 및 원인 규명

1. **희소 GC 이벤트의 표본 내 점유율 변동**:
   - 운영 환경에서 발생하는 Generation-2 GC 이벤트(지연 시간 약 35~45ms, 배치 직렬화 결합 시 약 70~76ms)는 전체 요청의 약 **2.50%**(600건 중 15건) 비율로 발생합니다.
   - 백분위수 P95는 상위 5% 경계선에 위치합니다. 따라서 100건 표본($n=100$)에서는 상위 5번째 요청에 해당합니다.
2. **작은 표본($n=100\sim 120$)에서의 불안정성**:
   - $n=100$ 표본 추출 시, 이항 분포에 의해 100건 중 5건 이상의 이상치(약 70ms)가 포함될 확률이 약 **10.2%**에 달합니다. 이 경우 P95는 즉시 65~70ms 수준으로 치솟습니다.
   - 반대로 이상치가 0~3건만 포함되면 P95는 37ms 안팎으로 측정됩니다.
   - 결과적으로 $n=100$ 환경의 P95 90% 신뢰구간은 $[37.07\text{ms}, 69.86\text{ms}]$로 그 변동 폭이 **32.79ms**에 달하며, 단일 측정 회차에 따라 합격/불합격 판정이 무작위로 뒤집히는 원인이 됩니다.
3. **대규모 표본($n \ge 600$)에서의 안정적 수렴**:
   - $n \ge 600$ 표본에서는 대수의 법칙(Law of Large Numbers)에 의해 2.5% 빈도의 GC 이상치가 상위 1%~3% 영역(P97~P99)에 확정적으로 배치됩니다.
   - 그 결과 상위 5% 경계인 P95는 GC의 영향을 직접 받지 않는 **40.27ms** 영역에 안착하며, 표준편차는 **2.94ms**(90% 신뢰구간 폭 4.52ms)로 급격히 축소됩니다.
   - $n=1000$에서는 표준편차가 **1.40ms**까지 감소하여 표본 오차에 의한 판정 왜곡이 사라집니다.

## 5. 표본 수에 흔들리지 않는 성능 지표 제안

표본 크기가 작을 때 백분위수 지표(P95)가 가지는 높은 분산 문제를 해결하고, 실제 서비스의 안정성을 객관적으로 평가하기 위해 다음 3가지 지표 체계를 제안합니다.

### 5.1 지표 1: SLA 임계치 초과율 (Tail Violation Rate, $>100\text{ms}$)

- **정의**: 전체 요청 중 100ms를 초과하여 처리된 요청의 비율과 95% Wilson 점수 신뢰구간 상한.
- **측정 실적**: 전체 5,640건 중 0건 발생 (초과율 **0.00%**, 95% 신뢰구간 $[0.00\%, 0.07\%]$).
- **특징**: 백분위수 순위 산출 방식에 의존하지 않고 전체 표본의 비율 검정을 수행하므로, 표본 크기에 상관없이 신뢰구간을 통해 일관된 통계적 엄밀성을 확보할 수 있습니다.

### 5.2 지표 2: 충분 표본 크기($n \ge 600$) 기준 P95 지표

- **정의**: 벤치마크 1회 측정 시 최소 600회 이상의 요청 표본을 수집하여 산출한 P95.
- **측정 실적**: Uninstrumented 600회 기준 P95 = **40.27ms** (부트스트랩 $\sigma = 2.94\text{ms}$).
- **특징**: 희소 GC 이상치($\approx 2.5\%$)가 P95 자리를 점유하지 않고 P98~P99 영역으로 자연스럽게 분리되도록 보장합니다.

### 5.3 지표 3: 절사 평균 (Trimmed Mean, 상위 5% 제외)

- **정의**: 극단적인 이상치 영향을 제거하기 위해 상위 5%를 제외한 95% 요청의 평균 지연 시간.
- **측정 실적**: Uninstrumented 600회 기준 절사 평균 = **29.53ms** (전체 단순 평균: **31.11ms**).
- **특징**: 상위 5%에 위치한 GC 스파이크에 영향을 받지 않고 서빙 시스템의 정규 처리 성능을 안정적으로 대변합니다.
