## 4. AH1: 원인은 "화면을 안 보고 있었다" 였습니다

감시기가 정상 작업 중인 워커를 `Antigravity 부팅이 인증 단계에서 정체` 로
표시한 오판의 원인입니다.

`scripts/orca_worker_watch.py` 의 `terminal_tail` 이 `orca terminal read` 를
**`--screen` 없이** 불렀습니다. 이 형태는 렌더링된 화면이 아니라 **누적 스트림
출력**을 돌려줍니다. 그래서 부팅 시점에 한 번 찍힌 문자열이 워커가 조용한 동안
마지막 N줄 안에 계속 남아 현재 차단으로 읽혔습니다.

**함수 이름과 `detect_block` 의 인자 이름이 `screen_tail` 이라 화면인 줄
알기 쉬운 자리였습니다.** 이름이 사실을 가린 사례입니다.

시정은 다음과 같습니다.

| 상황 | 판정 |
| --- | --- |
| `source` 가 `screen` | 그 화면만으로 판정. 지나간 출력은 대상 아님 |
| `screen-unavailable` 또는 `source` 없음 또는 호출 실패 | 스트림으로 fallback 하되 **같은 신호가 3초 간격으로 2회 연속** 관측될 때만 차단 |

fallback 으로 판정한 차단에는 **근거가 화면이 아니라는 표시**가 사람 출력과
JSON 에 함께 나옵니다. 표시가 없으면 다음 코디네이터가 같은 오판을 신뢰합니다.

## 5. AH2: 편입을 막던 한계가 실제로는 없앨 수 있는 것이었습니다

AG3 인수인계 5장은 `orca_read_scope_audit.py` 를 `worker_done` ack 절차에
편입하지 못한 이유로 "화면 버퍼는 잘리고 밀려나므로 증거가 불완전하다" 를
들었습니다. **그 전제가 도구의 한계가 아니라 읽는 방식의 한계였습니다.**

`orca terminal read` 는 `--cursor` 와 `--limit` 로 보관된 스크롤백을
페이지네이션하고, 응답의 `oldestCursor` 로 **오래된 줄이 실제로 버려졌는지**
알려 줍니다.

이제 도구는 커서 0부터 끝까지 읽어 이어 붙이고 결과에 `evidence` 를 담습니다.

    evidence: { oldest_cursor, latest_cursor, lines_read, complete }

`complete` 는 `oldestCursor` 가 0 일 때만 참입니다. **증거 불완전은 판정이
아니라 판정의 신뢰도이므로 종료 코드를 바꾸지 않습니다.** 종료 코드는 그대로
0 위반 없음, 1 위반 발견, 2 도구 오류이며, 페이지 읽기가 중간에 한 번이라도
실패하면 2 입니다.

**편입 여부는 여전히 열려 있습니다.** 이제 `evidence.complete` 가 참인
케이스가 얼마나 되는지 실사용에서 몇 번 관측한 뒤 결정하십시오. 근거 없이
게이트로 올리지 마십시오.

## 7. 이번 세션의 코디네이터 과실

### 7.1 병합 대상 브랜치를 확인하지 않고 병합했습니다

AH2 를 **`main` 이 아니라 문서 작업 브랜치 위에 병합**했습니다. 스킬 6장은
`git merge` 직전마다 `git branch --show-current` 로 확인하라고 규정하는데,
확인 명령을 같은 호출에 묶어 실행해 **출력을 읽기 전에 병합이 이미 실행**
됐습니다. 확인의 형식만 지키고 목적은 지키지 않은 것입니다.

복구는 그 브랜치를 병합 이전 커밋으로 되돌리고(`git reset --hard`, 원본은
작업 브랜치가 보유), `main` 으로 옮겨 두 건을 각각 병합했습니다. 이력에
잘못된 병합은 남지 않았습니다.

**확인 명령과 파괴적 명령을 한 호출에 묶지 마십시오.** 왕복을 줄이려다
확인을 무효로 만듭니다.

### 7.2 워커의 커밋 메시지 이탈을 되돌리지 못했습니다

AH1 빌더가 커밋 제목을 영어로 썼습니다(`fix: verify block signals from
rendered screen with stream fallback`). Capsule 의 `ground_truth` 에 한국어
규약을 명시했는데도 이탈했습니다. `git commit --amend` 로 고치려 했으나
**환경의 권한 정책이 이력 재작성을 거부**해 그대로 두고 병합 커밋에 사실을
적었습니다.

**Level 1 게이트는 커밋 메시지 언어를 검사하지 않습니다.** 기계 검사가 없는
규약은 이탈해도 통과합니다.
