## 3. 가장 중요한 정정

어제 "최대 발견" 으로 보고한 **하한율 값 존재율 96.3% -> 38.3% 계단 하락은 측정 착시였습니다.**

| 월 | `'0'` | 빈 문자열 | 양수 |
| --- | ---: | ---: | ---: |
| 2024-06 | 53.36% | 0.00% | 46.64% |
| 2025-01 | 0.23% | 43.16% | 56.61% |
| 2026-07 | 0.00% | 59.69% | 40.31% |

원천이 결측을 `'0'` 으로 적다가 빈 문자열로 바꿨을 뿐입니다. 실제 값 보유율은 46.6% -> 38.4% 의 완만한 하락이고 계절 변동 폭 안입니다.

`dataset.py:238` 과 `features.py:259` 가 둘 다 `'0'` 과 빈 값을 같은 결측으로 접으므로 **train/serve 가 함께 불변**이고 모델에는 영향이 없었습니다.

근거: [`servc_lwlt_missing_remechanism_20260811.md`](../design/servc_lwlt_missing_remechanism_20260811.md) 4.4

### 5.1 S5 를 최우선으로 두는 이유

S4 가 남긴 위험 4번입니다.

> `features.py` 의 `_coerce_category` 는 빈 문자열과 None 을 함께 접으므로 서빙 경로는 규칙을 만족하나, `dataset.py` 쪽은 빈 문자열이 NaN 과 다른 수준으로 남을 수 있습니다.

접는 코드가 없는 필드가 있다면 모델은 부재를 실제 값으로 학습하고 있는 것이고, 원천이 표기를 바꾸는 날 조용히 틀리기 시작합니다. **오류도 안 나고 테스트도 통과합니다.** 하한율에서는 우연히 막혔을 뿐입니다.

### 5.2 기대값을 낮춰 잡으십시오

제도 플래그 계열은 3종이 이미 음성입니다. `rbidPermsnYn` 도 같은 계열이므로 표기 이동으로 판명됐다고 해서 기여를 기대하지 마십시오.
