| 원인 | 근거 |

| `.env` 의 `G2B_SERVICE_KEY` 가 비어 있음 | 팀원 에이전트 진단. 낮 시간 수집이 API 요청 0회로 끝남. 데이터는 2026-11-07 에서 멈춤 |

| 따라잡기 기본값 꺼짐 | `AUTOMATION_SCHEDULE_CATCHUP_ENABLED=False` (`src/app/core/config.py:77`) |

사용자에게 팀원 에이전트용 프롬프트 두 개를 전달했다. 두 번째는 키 붙여 넣기 한 번만 사람에게 맡기고, 나머지(설정 변경, 컨테이너 재생성, 20일치 수집, 색인 확인)는 에이전트가 승인 없이 끝까지 하도록 썼다. 팀원 쪽 실행 결과는 이 문서 시점에 받지 못했다.

근본 수정 후보: 따라잡기 판정을 `schedule_run_log` 의 마지막 야간 작업 성공 시각 기준으로 바꾸면 기준 시간 우회 설정이 필요 없다. 사용자 결정 전이라 과업으로 등록하지 않았다.
