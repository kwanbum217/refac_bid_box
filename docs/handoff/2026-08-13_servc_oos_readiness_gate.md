## 3. feature store 재생성 — 가능하지만 실익이 없습니다

### 3.1 가능 여부

| 조건 | 판정 | 근거 |
| --- | --- | --- |
| DB 에 데이터가 있는가 | 예 | 전 구간 필터 통과 **917,632행** |
| 현 parquet 대비 손실이 있는가 | 없음 | 917,632 >= 917,629 |
| 경로가 동작하는가 | 예 | `retrain_task.py:134` 가 `build_training_dataset` 호출 |

**증가분 3행의 정체가 전부 설명됩니다.**

    917,629 (현 parquet)
      +2  2026-08-04 개찰분 (컷 이후)
      +1  R26BK01641657 (개찰 2026-07-29, 수집 2026-08-09 - 컷 이전이라 지연 반영)
    ------
    917,632

### 3.2 실익이 없는 이유

재생성이 만드는 OOS 후보는 **2건**입니다. 나머지 1건은 컷 이전 개찰이라 학습
구간에 들어가지, 검증 표본이 되지 않습니다.

**주의: 재생성은 `data/feature_store/dataset_Servc.parquet` 을 덮어씁니다.**
`build_training_dataset` 이 `output_dir` 에 그대로 씁니다(`dataset.py:259`).
실익 2행을 위해 운영 feature store 를 덮는 것은 손익이 맞지 않습니다. 실행할
때는 `output_dir` 을 분리하십시오(스킬 가드레일).

재생성 소요 시간은 **재지 않았습니다.** 이 Task 는 읽기 전용 판정이라 전량
SELECT 를 돌리지 않았습니다. 참고값으로 선행 문서의 특징 프레임 생성 335.6초가
있으나 DB 읽기 시간은 포함돼 있지 않습니다.

## 4. 판정 — 현행 서빙 OOS 검증은 아직 착수할 수 없습니다

### 4.1 표본이 몇 건 있어야 하는가

선행 문서 3.3 절의 신제도 구간 잔차 RMSE **2.7827** 을 잔차 표준편차로 쓰고,
평균 편향을 `t = 2.0` 으로 판별하는 데 필요한 행 수입니다.

    n = (2 x 2.7827 / 판별하려는 편향)^2

| 판별 목표 편향(%p) | 필요 행 수 | 하루 약 220행 기준 소요 |
| ---: | ---: | ---: |
| 0.20 | 773 | 약 4일 |
| 0.10 | 3,091 | 약 14일 |
| 0.05 | 12,365 | 약 56일 |
| 0.0079 (기각 축 오라클 상한) | 495,335 | 비현실적 |

하루 220행은 2026-05(6,394/31=206), 2026-06(6,991/30=233) 실측 평균입니다.

**현재 확보분 2건은 가장 느슨한 0.20%p 목표의 0.26% 입니다.**

### 4.2 세 명제의 상태

선행 문서 4.4 절의 표를 그대로 이어받아 갱신합니다.

| 명제 | 상태 |
| --- | --- |
| 컷 이전 학습 모델이 컷 이후에서 계통 편향을 보이는가 | **아니오.** 선행 문서가 답함 |
| 재개 조건 두 개가 충족되었는가 | **아니오.** 선행 문서가 답함 |
| 현행 서빙 champion 이 신 제도 구간에서 계통 편향을 보이는가 | **여전히 판정 못 함.** 표본 2건 |

**선행 문서 대비 달라진 것은 차단 사유입니다.** 그때는 "DB 접근이 금지되어
확인 못 함" 이었고, 지금은 **DB 를 열어 본 결과 표본 자체가 없음**입니다.
이것은 진전입니다. 더 이상 DB 권한으로 풀 수 있는 문제가 아니라는 것이
확정됐습니다.

### 4.3 기각 축 재개 조건도 함께 판정합니다

`scripts/eval_servc_regime_lwlt_levels.py` 를 다시 돌릴 이유가 **없습니다.**
그 스크립트는 parquet 만 읽는데 parquet 이 갱신되지 않았고, 재생성해도 +3행
입니다. 선행 문서가 2026-08-10 결과와 소수점까지 같았던 조건이 그대로입니다.

스킬 기각 목록의 지침 "재개 조건을 재기 전에 feature store 가 언제 갱신됐는지
부터 보십시오" 를 적용한 결과이며, **7분을 쓰지 않고 판정했습니다.**
