## 3. 다음 과제: 하한율 결측 집단 전용 진단

### 3.1 이미 아는 사실

| 집단 | 과거 측정 MAE | 해석 |
| --- | ---: | --- |
| 하한율 보유 | 약 0.76~0.79 | 제도상 하한율이 있는 방식이 주류 |
| 하한율 결측 | 약 2.36~2.48 | 수의시담 등 어려운 방식이 집중 |

오차의 대부분이 결측 집단에 있지만 `lwlt_rate`를 복원할 수 있다는 뜻은 아닙니다.
최근 결측 행에서 규칙 복원 적용률은 0.0%p였습니다. 결측은 상당 부분 제도상 값이
없는 상태이며 `lwlt_rate_missing`이 그 사실을 이미 표현합니다.

### 3.2 첫 실험의 질문

첫 질문은 “분리 모델이 좋아지는가”가 아니라 다음 세 가지입니다.

1. 결측 집단의 큰 오차가 특정 낙찰방법의 **안정적인 편향**인지 확인합니다.
2. 그 편향이 과거 학습 구간과 미래 평가 구간에서 같은 방향인지 확인합니다.
3. 보유 집단을 악화시키지 않으면서 결측 집단의 오차를 줄일 후보가 있는지
   확인합니다.

먼저 읽기 전용 진단 스크립트로 현재 champion의 잔차를
`lwlt_rate_missing`, `sucsfbid_mthd_nm`, 표본 수 구간별로 나누십시오. 이력이 필요한
특징은 **전량 프레임에 붙인 뒤 연도별로 잘라야** 합니다.

### 3.3 평가 설계

| 항목 | 요구사항 |
| --- | --- |
| 학습·평가 분리 | 시간순 분리. 무작위 분할 금지 |
| 학습 상한 | 후보와 champion을 동일하게 고정 |
| 평가 모집단 | 필터 없는 전체와 하한율 결측 집단을 모두 보고 |
| 비교 방식 | 같은 공고의 절대오차·제곱오차 쌍대 비교 |
| 판정 | 평균 차이, 표준오차, t, 최소 감지 차이를 함께 기록 |
| 회귀 방지 | 하한율 보유 집단, 0.5%p 적중, 구간 피복률도 확인 |
| 특징 구현 | 채택할 경우 `src/ml/features.py` 단일 경로만 사용 |

결측 집단에서만 좋아져도 전체 모집단에서 방향을 판별할 수 없으면 승격 근거가
부족합니다. 반대로 전체 평균만 보고 결측 집단의 악화를 숨겨서도 안 됩니다.

### 3.4 중단 기준

다음 중 하나면 구현·재학습으로 넘어가지 말고 진단 결과만 문서화하십시오.

- 구간별 잔차 방향이 연도에 따라 뒤집힙니다.
- 관측 개선이 출력된 최소 감지 차이보다 작습니다.
- 하한율 보유 집단이나 전체 모집단이 유의하게 악화합니다.
- 서빙 시점에 알 수 없는 값을 요구합니다.
- 최종 특징을 `src/ml/features.py` 밖에서 따로 만들어야 합니다.
